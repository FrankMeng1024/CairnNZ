# STORY-00069: MapHistoryScreen — session expand + route view flow

**Epic**: E-005 Active-State Excellence
**Sprint**: Sprint 25
**Sprint Goal**: Active-state excellence — HikingScreen tracking bar, flag plant modal, and MapHistoryScreen route-view flow upgraded to Sprint-24 quality. Post-session summaries polished. Core user journey complete end-to-end at premium quality.
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a hiker reviewing past sessions, I want to tap a session card in the Routes tab and see the route drawn on the map above, so that I can visually explore where I've been.

## Expected Result
Tapping a session card in the Routes tab (a) expands an inline stats panel with km, time, elev, flag count using Sprint-24 stat capsule styling, and (b) the "View on Map" pill button is prominent. The expanded panel uses consistent card styling. The map area above shows the track polyline for the selected session.

## Acceptance Criteria
- [ ] Session card tap expands an inline panel (accordion, animated height 200ms)
- [ ] Expanded panel shows 4 stats in capsule row: km, time, elev, flags — each with colored left-border accent (green/blue/orange/flag-color) matching Sprint-24 QuickStats style
- [ ] "View on Map" pill button: `Colors.primary` background, white text, Map icon, `Radius.pill`
- [ ] Tapping "View on Map" selects that session — map area above updates to show the track polyline
- [ ] Tapping the same card again collapses it (accordion toggle)
- [ ] Only one card expanded at a time — expanding a second collapses the first
- [ ] Expanded stats card has `Shadow.card` and `Radius.card` — visually elevated
- [ ] Route tab placeholder ("Route Map" area) only shows when no session is selected
- [ ] All interactions smooth at 390px viewport; no console errors after expand/collapse navigation

## Dependencies
- None
