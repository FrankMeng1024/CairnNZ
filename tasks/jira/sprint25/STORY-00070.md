# STORY-00070: UX Low-item bundle — empty state labels + amber test data

**Epic**: E-005 Active-State Excellence
**Sprint**: Sprint 25
**Sprint Goal**: Active-state excellence — HikingScreen tracking bar, flag plant modal, and MapHistoryScreen route-view flow upgraded to Sprint-24 quality. Post-session summaries polished. Core user journey complete end-to-end at premium quality.
**Points**: 2

**Status**: Done

## Description
As a Cairn user, I want session stats to show clear labels when GPS data is unavailable, and I want the system to be verifiably tested for all friend status states, so that the app feels polished and complete.

## Expected Result
(1) Session cards showing "--" for distance display "No GPS" label instead of ambiguous dashes. (2) MOCK_FRIENDS data includes a friend with lastSeen in the 0-60 minute window so amber status dot (`Colors.warning`) is covered by test data.

## Acceptance Criteria
- [ ] In MapHistoryScreen session card secondary line: when `formatDistance` returns `'--'`, display "No GPS" text in `Colors.textMuted / FontSize.small` instead of "-- km"
- [ ] In HomeScreen RecentActivityStrip: when distance is `'--'`, the secondary line shows "No GPS" instead of "-- km"
- [ ] MOCK_FRIENDS in `app/src/data/mockData.ts` has at least one friend with `lastSeen: '45m ago'` and `online: false` — this friend appears in FriendsScreen with an amber status dot
- [ ] FriendsScreen amber status dot renders as `Colors.warning` for the '45m ago' friend (visible in QA screenshot)
- [ ] No regressions on existing session cards or friends display at 390px viewport

## Dependencies
- None

## Notes
"-- km" is ambiguous to new users — they may think it's a bug. "No GPS" is clear and informative. The amber friend test data gap was documented in Sprint 24 lessons.md as a coverage gap. Both fixes are low complexity, bundled per micro-story bundling rule (≤0.5 pts each, same feature area, 3 items max).
