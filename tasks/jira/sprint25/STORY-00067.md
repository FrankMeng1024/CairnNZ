# STORY-00067: RunningScreen "Run Complete" — premium post-session summary

**Epic**: E-005 Active-State Excellence
**Sprint**: Sprint 25
**Sprint Goal**: Active-state excellence — HikingScreen tracking bar, flag plant modal, and MapHistoryScreen route-view flow upgraded to Sprint-24 quality. Post-session summaries polished. Core user journey complete end-to-end at premium quality.
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a runner finishing a session, I want the "Run Complete" summary screen to feel like a reward — a cohesive, premium celebration state that matches the visual quality of the pre-start screen, so that the end of my run feels satisfying and complete.

## Expected Result
The stopped/complete state uses a dedicated styled container (not the dark running background), displays session stats prominently with Sprint-24 card quality, and a celebratory icon. The Share button is polished and the Back button is clearly a secondary action.

## Acceptance Criteria
- [ ] "Run Complete" screen uses `Colors.bg` as background (light mode, consistent with pre-start)
- [ ] A checkmark-in-circle icon (`CircleCheck`, size 56, `Colors.primary`) displayed above the stats
- [ ] Stats displayed in a card (white bg, `Shadow.card`, `Radius.card`) with 3 columns: km, elapsed, pace — using `FontSize.h2/fontWeight: '800'` for values and `FontSize.small/Colors.textSecondary` for labels
- [ ] "Session saved" subtitle below "Run Complete" title uses `FontSize.small / Colors.textSecondary`
- [ ] Share pill button: border `Colors.primary`, icon + text `Colors.primary` (not `Colors.running`)
- [ ] Back button is `preStyles.startBtn`-styled (green solid) labeled "New Run" with ChevronLeft icon
- [ ] No visual use of dark `runStyles` styles (statsBar dark background) on the complete screen
- [ ] Viewport 390px: all elements visible without scrolling

## Dependencies
- None

## Notes
Current issue: `runState === 'stopped'` renders inside `preStyles.container` (correct bg) but uses `runStyles.statsBar` which has dark background (#0a1a0a border, rgba dark bg). This creates a visual mismatch. Fix: create a `summaryCard` style for the stopped state stats display, distinct from the dark running `statsBar`.
