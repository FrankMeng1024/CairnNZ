# STORY-00068: HikingScreen — tracking bar visual upgrade

**Epic**: E-005 Active-State Excellence
**Sprint**: Sprint 25
**Sprint Goal**: Active-state excellence — HikingScreen tracking bar, flag plant modal, and MapHistoryScreen route-view flow upgraded to Sprint-24 quality. Post-session summaries polished. Core user journey complete end-to-end at premium quality.
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a hiker actively tracking a session, I want the tracking stats bar to feel premium and clearly readable at a glance, so that I can check my progress without interrupting my hike.

## Expected Result
The tracking bar (shown when `isTracking = true`) is visually distinguished: primary stat (km) rendered at `FontSize.h2/fontWeight: '700'` with a colored left-border accent; secondary stats (elapsed, elevation) in `FontSize.caption/fontWeight: '700'`; Stop CTA in `Colors.danger`; the overall bar has elevated `Shadow.elevated` styling matching the Sprint-24 card system.

## Acceptance Criteria
- [ ] Tracking bar visible when "Start Hiking" is tapped (isTracking state)
- [ ] Primary stat (distance km): `FontSize.h2` / `fontWeight: '700'` / `Colors.textPrimary`
- [ ] Secondary stats (elapsed, elevation): `FontSize.caption` / `fontWeight: '700'` / `Colors.textPrimary`; unit labels `FontSize.tiny / Colors.textSecondary`
- [ ] Tracking bar has a `Colors.primary` left border accent (3px) to visually anchor it
- [ ] Stop button: `Colors.danger` background, white text, "Stop" label, Square icon — already correct but must remain
- [ ] Tracking bar background: `rgba(255,255,255,0.98)` with `Shadow.elevated` (not just `Shadow.card`)
- [ ] Expert mode (Navigator): bearing stat shows `--` text in `Colors.textMuted` when GPS data unavailable
- [ ] All changes visible at 390px viewport

## Dependencies
- None
