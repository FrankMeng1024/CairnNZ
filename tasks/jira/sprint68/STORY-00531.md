# STORY-00531: Mark visual treatment by tier (self / friend / stranger)

**Epic**: E-Friend (Friend System v1)
**Sprint**: Sprint 68
**Sprint Goal**: Land the Mark surface for Friend System v1.
**Points**: 5
**Owner**: Frontend + UX
**Status**: Done

## Description

As a Cairn user looking at the map, I want each mark's visual style to instantly tell me who created it — me, a friend, or a stranger — so I can scan the map by trust tier without reading labels.

## Expected Result

Three mark visual treatments, applied automatically based on `viewer_id` vs `mark.user_id` + permission tier:
- **Self** (creator == viewer): light sepia fill, no ring (consistent with existing Cairn aesthetic)
- **Friend** (creator is in viewer's friends AND mark.permission='friend' or 'group'): colored ring around the icon (color per friend's identity hash → consistent across map)
- **Stranger** (anyone else; mark.permission='public' from non-friend): grayed icon, slightly desaturated, no ring

## Acceptance Criteria

- [ ] Self marks render with the existing sepia fill — visually unchanged from pre-v1
- [ ] Friend marks render with a 2-3px colored ring (color derived from `mark.user_id` via stable hash → same friend always same color across session)
- [ ] Stranger marks render with `opacity ≈ 0.6` + grayscale-shift filter
- [ ] Visual treatment is a pure function of (viewer, mark) — no global flag toggles needed
- [ ] Mark visual change does NOT require new map data fetch — uses Sprint 67 `GET /api/circle/markers` payload (already includes `user_id`, `permission`, `author_name`)
- [ ] When viewer un-subscribes from a friend → that friend's marks disappear (handled by Sprint 67 backend filter; this Story confirms client doesn't cache stale visuals)
- [ ] UX AC: in user testing, 90% of taps on a colored-ring mark correctly anticipate "this is a friend's mark" before opening the detail sheet
- [ ] Light + dark theme both render correctly (Cairn supports both per `TECH_SPEC.md`)
- [ ] Performance: rendering 50 mixed marks at z=14 keeps frame rate ≥ 55fps

## Dependencies

- Blocks: STORY-00532 (Detail Sheet visual header inherits this treatment)
- Depends on: Sprint 67 STORY-00528 (`GET /api/circle/markers` payload)

## Notes

- Friend ring color stable hash: same hash function used across UI for friend identity. If no existing helper, create one local to `app/src/features/friends/utils/colorFromUserId.ts`.
- Stranger gray uses Cairn's existing inactive-icon token, not a new color.
