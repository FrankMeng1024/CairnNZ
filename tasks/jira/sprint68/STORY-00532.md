## Description

Tap on a mark opens the Mark Detail Sheet. Per v4 §4.11 the sheet has **4 distinct forms**, selected by the (creator × visited × visibility) tuple per v4 §3 three iron laws.

## Expected Result

Tap any visible mark → sheet renders the correct form. Tap a "far + outside fog" mark = no sheet (form D = silent). Action surface respects iron laws.

## Acceptance Criteria

- [ ] Iron law 1 wired: `visible(mark) = in_my_fog(mark) OR (in_subscribed_friend_fog AND visibility_grants_me)`. Personal-from-friend → not visible (NO sheet, see scenario §9 #13).
- [ ] **Form A** (mine, any visibility): shows tier icon header + Edit + Delete (true DELETE). Like/Report appears only if visibility='public' (per §4.11 actual rule). Edit opens existing mark-edit flow.
- [ ] **Form B** (other-mark + I visited): tier icon + author_name (only if Friend tier — Public tier anonymized per v4 row Q) + visited badge ✓ + Like 💛 + Report 🚩 + Delete (from-view).
- [ ] **Form C** (other-mark + friend's fog + NOT visited): tier icon + author_name (Friend tier only) + helper text "(Walk here to like/report)" + Delete-from-view ONLY.
- [ ] **Form D**: tap = no-op. Mark renders as dim gray icon (covered by Story 531 stranger-style). No sheet, no toast, no haptic.
- [ ] Header tier label uses locked icons: 🔒 Personal / 👥 Friend / 🌍 Public (Public only appears when displaying a public mark — never user-creatable)
- [ ] `author_name` field rendered ONLY for Friend tier marks. Public marks display NO name regardless of creator's friend status (v4 row Q).
- [ ] Close button (✕) restores map without re-running any data query
- [ ] All 6 scenarios from v4 §9 scenarios 8/10/11/12/13/14 produce the correct form (Carol Public, LDY Friend visited, LDY Friend not-visited, own Public, friend Personal hidden, stranger blurred)
- [ ] Static visual fidelity: render each form at 375×812 viewport (iPhone target), screenshot, side-by-side against the §4.11 ASCII mockups — no visual deviations beyond Cairn token mapping
- [ ] Empty / null text content handled (some marks have no `text` field)
