## Description

When viewer toggles Memory tab to Friends scope (Story-539), the FogLayer should render the UNION of viewer's own fog + each subscribed friend's fog (Sprint 67 `GET /api/circle/fog` raw points → client-side turf.union per existing FogLayer pipeline).

**This Story is DEFERRED to Sprint 71 (F5 hardening) per SPIKE-67-1 verdict.**

## Why deferred

SPIKE-67-1 (Sprint 67) concluded `VIABLE_WITH_CONDITIONS` for Mapbox iOS fog UNION with up to 5 friends, **conditional on a live FPS measurement on the user's iPhone**. The workflow environment is Windows-only — no iOS device, no macOS host, no simulator. Per `feedback_user_reports_are_truth` + `feedback_unity_visual_test`, faking the perf measurement here would be dishonest evidence.

The visual UI surface for this is already complete:
- Memory tab Mine|Friends toggle (Story-539) — works
- 5-friend pick modal (Story-540) — works
- Paywall (Story-542) — works
- Backend `GET /api/circle/fog` (Sprint 67 STORY-00528) returns raw points grouped by friend_id

What remains: extend `FogLayer.tsx` to call `loadCircleFog()` action + run turf.union across all subscribed friends' point sets when `memoryScope === 'friends'`, then live-measure FPS at z=12/14/16/18 + memory delta on user iPhone.
