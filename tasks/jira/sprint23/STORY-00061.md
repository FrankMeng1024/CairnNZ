# STORY-00061: SettingsScreen Mode Selector Visual Refinement

**Epic**: E-006 UI/UX
**Sprint**: Sprint 23
**Sprint Goal**: HomeScreen card polish, HikingScreen map placeholder premium feel, SettingsScreen visual hierarchy
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the Explorer/Navigator mode selector in Settings to feel like a premium card-selection component with clear visual feedback, not just bordered boxes.

## Expected Result
Mode selector cards have visual depth via shadow, selected state uses a stronger visual treatment (filled badge + border accent), and the overall section feels like a deliberate design choice rather than a form element.

## Acceptance Criteria
- [ ] Selected mode card: `borderWidth: 2`, `borderColor: Colors.primary`, `backgroundColor: Colors.primaryBg`, plus `Shadow.card` shadow — creates a "lifted" selected feel
- [ ] Unselected mode card: `borderWidth: 1`, `borderColor: Colors.border`, `backgroundColor: Colors.surface`, no shadow or subtle shadow
- [ ] Mode card icon area: 40×40 rounded square badge (borderRadius 12) — Hiking icon gets `Colors.primaryLight` bg, Compass icon gets `rgba(200,121,65,0.12)` (flagLight) bg for Navigator
- [ ] Selected mode check: the existing checkmark badge on the Explorer card is positioned correctly (top-right of card, not inline)
- [ ] Section headers (SHARING, DISPLAY, etc.): `letterSpacing: 1`, `FontSize.tiny`, `Colors.textMuted`, `fontWeight: '700'` — consistent typographic treatment
- [ ] Settings row items: each row has `minHeight: 54` for comfortable tap targets
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 22 audit: Explorer card has icon + check mark overlapping in a small space. Navigator card lacks an icon badge. Section headers are all-caps small text but lack proper letter-spacing. These are polish details that significantly impact premium feel.
