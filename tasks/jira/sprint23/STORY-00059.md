# STORY-00059: HomeScreen Activity Card & QuickStats Visual Upgrade

**Epic**: E-006 UI/UX
**Sprint**: Sprint 23
**Sprint Goal**: HomeScreen card polish, HikingScreen map placeholder premium feel, SettingsScreen visual hierarchy
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the HomeScreen activity cards and QuickStats to feel visually premium and engaging, with richer gradients, better information hierarchy, and more inviting card compositions.

## Expected Result
Activity cards (Hiking/Running) have a richer gradient icon badge area. QuickStats capsules have visual weight and cleaner number typography. The overall HomeScreen feels like a premium outdoor app (AllTrails/Strava quality).

## Acceptance Criteria
- [ ] Hiking activity card: icon badge area uses a multi-stop gradient (light green center → slightly deeper at edges) for depth
- [ ] Running activity card: icon badge area uses blue-toned gradient consistent with `Colors.running`/`Colors.runningLight`
- [ ] QuickStats capsules: number value uses `FontSize.h2` (20px/700) weight, unit label uses `FontSize.tiny` (9px/600) — clear hierarchy between number and label
- [ ] QuickStats capsules: add a subtle left-border accent (2px, matching icon color) or icon tint that visually ties the icon to the number
- [ ] Activity card chevron (`>`) replaced with a styled arrow circle badge (20×20, bg=Colors.primaryLight for Hiking, bg=Colors.runningLight for Running, icon=ChevronRight size=12)
- [ ] HomeScreen section divider ("TOOLS" label) has consistent weight/spacing with the rest of the screen
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 22 audit: activity cards are functional but plain. Competitive reference: AllTrails uses bold color blocks for category cards, Strava uses vivid gradients. Our tokens have the right colors — need to apply them with more compositional confidence.
