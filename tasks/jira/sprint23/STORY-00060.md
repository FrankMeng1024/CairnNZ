# STORY-00060: HikingScreen Map Placeholder — Premium Offline Illustration

**Epic**: E-006 UI/UX
**Sprint**: Sprint 23
**Sprint Goal**: HomeScreen card polish, HikingScreen map placeholder premium feel, SettingsScreen visual hierarchy
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the HikingScreen's offline map placeholder to feel intentional and premium — like a well-designed offline state, not like a broken loading screen.

## Expected Result
The map placeholder has a topo-inspired SVG illustration (concentric elevation contours, trail line, location pin) with warm colors matching the design system. It communicates "offline map available after download" clearly with a CTA, rather than feeling broken.

## Acceptance Criteria
- [ ] Map placeholder background: `Colors.primaryBg` (soft green tint) — replaces the pure white/light grey
- [ ] Topo illustration: concentric circle rings using `Colors.primaryLight` at varying opacity (outermost 20%, innermost 60%) — creates elevation contour look
- [ ] Trail line: a gentle S-curve SVG path in `Colors.primary` at 40% opacity overlaid on the contours
- [ ] Location pin: a circle marker at the trail's midpoint in `Colors.primary`
- [ ] Placeholder text: "Trail Map" in `FontSize.h3`/600 and "Download an offline pack to get started" (not "Real map loads with offline pack") — clear user action language
- [ ] A small "Download Map" pill button below the subtitle in `Colors.primary` outline style
- [ ] GPS status pill (top-left "GPS Offline") styled with `Colors.danger` text and `Colors.dangerBg` background — more informative visual
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 22 audit: current placeholder looks like a generic loading state. Premium outdoor apps (Gaia GPS, AllTrails) show topo-style illustrations in their offline states. We can achieve this with pure React Native SVG-style View composition — no external libraries needed.
