# STORY-00062: RecentActivityStrip — Richer Session Row Typography

**Epic**: E-006 UI/UX
**Sprint**: Sprint 23
**Sprint Goal**: HomeScreen card polish, HikingScreen map placeholder premium feel, SettingsScreen visual hierarchy
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the recent activity row on HomeScreen to feel like a polished session summary — not just a text row — with clear visual hierarchy between the activity type badge, stats, and date.

## Expected Result
The recent activity row has an activity type badge (colored pill: "Run" or "Hike"), a clear primary stat (distance or time), and a secondary line with date and duration — matching the quality of Strava's feed rows.

## Acceptance Criteria
- [ ] Activity type badge: a small colored pill (`borderRadius: Radius.pill`, paddingHorizontal 8, paddingVertical 2) showing "Run" or "Hike" with matching color — Run uses `Colors.running` bg at 15% opacity + `Colors.running` text, Hike uses `Colors.primary` bg at 15% opacity + `Colors.primary` text
- [ ] Primary stat line: if distance > 10m show `"{dist} km"` in `FontSize.body`/700, else show duration in `FontSize.body`/700 — always shows the most meaningful stat first
- [ ] Secondary line: `"{date} · {duration}"` in `FontSize.small`/400 `Colors.textSecondary` — consistent with MapHistoryScreen session format
- [ ] Row left icon: the existing activity icon badge (currently blue circle with runner/hiker icon) keeps its current size but icon color matches the activity token (`Colors.running` for run, `Colors.primary` for hike)
- [ ] "View all" link on the strip is right-aligned with `Colors.primary` color and `FontSize.small` — currently looks fine but verify it has `fontWeight: '600'`
- [ ] Row right chevron: uses `Colors.textMuted` not the default inherited color
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 22 audit: "-- km · 00:32" secondary text is too small to read quickly. The activity type isn't visually distinct from the stats. Strava uses a bold distance + smaller pace/time layout. We should create better visual hierarchy in this one-row summary.
