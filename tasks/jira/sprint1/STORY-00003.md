# STORY-00003: Spike — 语音播报与音乐音量压低

**Epic**: E-004 安全功能
**Sprint**: Sprint 1
**Sprint Goal**: 验证所有系统级依赖的技术可行性
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a developer, I want to verify that expo-speech can announce voice messages while lowering (ducking) background music volume, so that running users hear alerts without their music being paused.

## Expected Result
TTS播报时自动压低系统音乐音量，播报完毕后恢复。不暂停音乐，不中断其他音频app。

## Acceptance Criteria
- [ ] expo-speech基础TTS在iOS上正常发声
- [ ] TTS触发时背景音乐（Apple Music/Spotify）音量自动降低
- [ ] TTS结束后音乐音量自动恢复
- [ ] 记录是否需要Audio Session配置（iOS AVAudioSession ducking）
- [ ] 测试播报延迟（从调用到发声的时间）

## Dependencies
- 需要物理iPhone + 正在播放音乐的环境

## Notes
Spike结论写入 `docs/spike-results/SPIKE-003.md`
如果expo-speech不支持ducking，备选方案：expo-av自定义音频播放。

**2026-05-15 Spike 结论**: VIABLE WITH CONDITIONS
- Web UI 测试：TTS 成功触发，onStart/onDone 回调正常，0 JS 错误
- Web 上启动延迟 2583ms（浏览器特性，不代表 iOS 性能）
- iOS AVAudioSession 默认支持 duck-others（系统级，无需额外代码）
- **待设备验证**：iOS 上实际延迟(<500ms目标)、en-NZ voice 可用性、实际 ducking 效果
