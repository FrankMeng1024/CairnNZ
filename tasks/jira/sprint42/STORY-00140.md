## Description
As a user, I want the app to feel premium and polished with glassmorphism effects, smooth spring animations, and layered shadows.

## Expected Result
Shared component library for blur panels, elevation shadows, and spring animations usable across all screens.

## Acceptance Criteria
- [ ] `GlassPanel` component: BlurView wrapper with configurable intensity + tint + border
- [ ] `elevation` style utility: 4 levels (elevation-1 through elevation-4) per UI_SPEC
- [ ] Spring animation hooks: `useSpringScale`, `useSpringTranslate` using react-native-reanimated
- [ ] Tab bar uses GlassPanel (blur behind, semi-transparent)
- [ ] FAB button uses elevation-4 + press animation (scale 0.97 on press)
- [ ] Dark mode variants for all glass/elevation tokens
- [ ] Respects system Reduce Motion setting (disables spring overshoot)

## Dependencies
- Depends on: STORY-00136 (expo-blur + react-native-reanimated installed)

## Notes
- GlassPanel props: { intensity: number, tint: 'light'|'dark', children }
- Spring defaults: { damping: 15, stiffness: 150, mass: 1 }
- All existing screens don't need to adopt immediately — foundation only
