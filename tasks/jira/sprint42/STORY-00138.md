# STORY-00138: Map Markers on Real Map

**Epic**: E-001 Map
**Sprint**: Sprint 42
**Sprint Goal**: Phase 1 Foundation — Real Mapbox + GPS precision
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want to see my planted markers (flags) displayed at their real GPS coordinates on the map, with the upgraded visual style (glow ring + elevation shadow).

## Expected Result
All markers from useMarkerStore render at correct lat/lng on Mapbox map. Visual style matches UI_SPEC marker upgrade (circular base + icon + glow ring).

## Acceptance Criteria
- [ ] Markers from useMarkerStore render as Mapbox PointAnnotation or SymbolLayer
- [ ] Each marker shows correct type icon (danger/scenic/supply/junction)
- [ ] Marker visual: 32px circular base + inner icon + outer glow ring (type color)
- [ ] Tap marker → detail card appears with blur background (elevation-3)
- [ ] Marker detail shows: type, note text, time ago, distance from user
- [ ] Clustering when zoomed out: numbered circle for dense areas
- [ ] Spring animation on marker appear (scale 0→1 with overshoot)

## Dependencies
- Depends on: STORY-00137 (real map rendering)

## Notes
- Use Mapbox ShapeSource + SymbolLayer for performance with many markers
- Cluster: use Mapbox built-in clustering (clusterRadius: 50, clusterMaxZoom: 14)
