# STORY-00139: GPS Kalman Filter + Dynamic Sampling

**Epic**: E-002 GPS

**Points**: 5

## Description
As a user, I want my GPS track to be smooth and accurate (no random jumps or drift) while minimizing battery drain through smart sampling frequency.

## Expected Result
GPS tracking produces a smooth polyline without erratic jumps. Sampling frequency adjusts automatically based on movement speed. Battery impact reduced vs constant 1Hz polling.

## Acceptance Criteria
- [ ] Kalman filter implemented in `utils/geo.ts` — smooths lat/lng/altitude
- [ ] Speed-direction consistency check: discard points with >90° direction change at low speed
- [ ] Dynamic sampling: static(0.1Hz) → walking(1Hz) → running(2Hz)
- [ ] Speed detection: <0.5m/s for 10s = static, 0.5-2.5m/s = walking, >2.5m/s = running
- [ ] Battery threshold response: <20% → force 0.5Hz regardless of speed
- [ ] useTrackingStore updated to use filtered coordinates (not raw GPS)
- [ ] Track polyline displayed on Mapbox map during activity (smooth line, primary green color)
- [ ] Unit tests for Kalman filter (known input → expected smoothed output)

## Dependencies
- Depends on: STORY-00136 (EAS setup for expo-location native)

## Notes
- Kalman filter reference: 1D Kalman per axis (lat, lng, alt separately)
- Process noise Q = 0.01, Measurement noise R from GPS accuracy field
- expo-location provides `coords.accuracy` — feed into R parameter
