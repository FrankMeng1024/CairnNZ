# STORY-00010: 好友页 + 路线历史页骨架

**Epic**: E-001 账号与好友 / E-002 地图与导航
**Sprint**: Sprint 2
**Sprint Goal**: 完成全APP UI骨架，双模式明显可感知
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want to see my friends list and past routes, so that I understand the social and history features.

## Expected Result
好友页列出mock好友，路线历史页列出mock路线记录。双模式在列表密度和信息量上有明显差异。

## Acceptance Criteria
**好友页**
- [ ] 页面标题（说明模式："好友 — 分享路况的人"，简易模式："好友"）
- [ ] mock好友列表：3条（头像字母 + 名字 + 最后在线时间 + 共同标记数）
- [ ] 说明模式：每条好友下方有"点击查看Ta标记的路况"提示文字
- [ ] 简易模式：紧凑列表，仅头像+名字+绿点（在线）或灰点（离线）
- [ ] "添加好友"按钮（说明模式："+ 添加好友（通过邮箱邀请）"，简易模式："+"）
- [ ] 添加好友页：邮箱输入框 + 发送邀请按钮（mock，点击后toast"邀请已发送"）

**路线历史页**
- [ ] mock路线列表：3条（路线名 + 日期 + 距离 + 时长 + 标记数）
- [ ] 说明模式：每条路线显示"距离 | 用时 | X个标记"标签，带单位说明
- [ ] 简易模式：紧凑卡片，仅关键数字
- [ ] 点击路线卡片进入路线详情页（仅显示基本信息，无真实地图回放）

## UX AC
- [ ] 列表滚动流畅（FlatList，非ScrollView+map）
- [ ] 空状态处理：如果无好友/路线，显示引导文字

## Dependencies
- STORY-00006（模式state）

## Notes
全部mock数据，无真实API调用。
