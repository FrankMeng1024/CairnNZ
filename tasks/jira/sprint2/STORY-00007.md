# STORY-00007: 主地图页骨架

**Epic**: E-002 地图与导航
**Sprint**: Sprint 2
**Sprint Goal**: 完成全APP UI骨架，双模式明显可感知
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want to see the main map screen with navigation and key actions, so that I understand the core interaction model.

## Expected Result
主地图页显示占位地图（绿色背景+网格线，无真实Mapbox），底部导航栏，FAB插旗按钮，顶部状态栏，以及若干mock标记。双模式差异在此页明显可见。

## Acceptance Criteria
- [ ] 占位地图区域占据全屏（绿色背景 #e8f0e0 + 网格，标注"地图区域 - 离线包加载后显示"）
- [ ] 底部导航：地图/好友/路线/设置 4个tab（说明模式有文字，简易模式仅图标）
- [ ] FAB插旗按钮（右下角，绿色圆形，说明模式有"标记"文字标签）
- [ ] 顶部：左上GPS状态（说明模式："GPS已连接 ±5m"，简易模式：绿点图标）
- [ ] 顶部：右上运动模式切换（说明模式："徒步模式"chip，简易模式：靴子/跑鞋图标）
- [ ] 地图上显示3个mock标记（各类型一个：Danger/Scenic/Supply）
- [ ] 说明模式下标记有类型标签文字
- [ ] 简易模式下标记仅圆形图标

## UX AC
- [ ] 底部导航高度 ≥ 56pt（拇指易触达）
- [ ] FAB按钮直径 ≥ 56pt
- [ ] 地图区域不被任何UI遮挡超过25%
