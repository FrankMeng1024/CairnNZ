# STORY-00011: 路线追踪中页 + 运动模式骨架

**Epic**: E-005 运动模式
**Sprint**: Sprint 2
**Sprint Goal**: 完成全APP UI骨架，双模式明显可感知
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a trail runner or hiker, I want to see what the active tracking UI looks like in both hiking and running modes, so that I understand the different experience.

## Expected Result
点击主地图页"开始追踪"，进入追踪覆盖层。徒步/跑步两种模式UI差异明显。无真实GPS，显示mock数据。

## Acceptance Criteria
**徒步模式追踪overlay**
- [ ] 底部数据条：距离 + 时长 + 海拔（说明模式有单位说明，简易模式仅数字）
- [ ] "停止追踪"按钮（红色，说明模式有"点击结束本次路线记录"）
- [ ] "标记" FAB保持可见
- [ ] mock数据每3秒更新一次（距离+0.01km，时长+3s）

**跑步模式追踪overlay**
- [ ] 全屏简洁：大号当前配速居中（说明模式："当前配速 5:30/km"，简易模式："5:30"）
- [ ] 底部一行：距离 + 时长（极简）
- [ ] "稍后标记"按钮（单个，锁屏友好，大按钮）
- [ ] 无FAB（跑步时不创建详细标记）

**模式切换**
- [ ] 主地图页顶部运动模式chip点击，弹出选择（徒步/跑步），选择后切换overlay样式

## UX AC
- [ ] 跑步模式：关键数字字号 ≥ 48pt（跑步中可瞥见）
- [ ] 所有可点按钮 ≥ 44pt触控区域
