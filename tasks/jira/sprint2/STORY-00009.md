# STORY-00009: 标记创建 + 详情 Sheet骨架

**Epic**: E-003 标记系统
**Sprint**: Sprint 2
**Sprint Goal**: 完成全APP UI骨架，双模式明显可感知
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want to see how marking and viewing a marker works, so that I understand the core marking interaction.

## Expected Result
点击地图FAB后，底部Sheet滑出，展示标记创建表单。点击mock标记，展示标记详情Sheet。双模式差异在权限选择器处明显。

## Acceptance Criteria
- [ ] 创建Sheet：4个标记类型选择（Danger/Scenic/Supply/Junction + Free），颜色+图标区分
- [ ] 创建Sheet：文本输入框（说明模式有字数提示"最多30字"和示例文字，简易模式仅placeholder）
- [ ] 创建Sheet：权限选择器 — 说明模式显示"仅自己/好友组/公开"+ 每项说明文字；简易模式显示🔒/👥/🌐图标快选
- [ ] 创建Sheet："插旗"确认按钮（绿色，说明模式有"这面旗将帮助后来的人"副文字）
- [ ] 详情Sheet：显示标记类型色块 + 类型名 + 文本内容 + "X分钟前" + 作者（mock "Sam"）
- [ ] 详情Sheet："有帮助" thumbs-up 按钮（说明模式有"告诉作者这个标记帮助了你"）
- [ ] 两个Sheet均可向下滑动关闭
- [ ] Sheet圆角20px，背景白色，handle bar可见

## UX AC
- [ ] FAB点击到Sheet完全展开 ≤ 300ms
- [ ] Sheet不遮挡超过75%地图区域（可查看标记位置）

## Dependencies
- STORY-00007（地图页FAB）
- STORY-00006（模式state）
