# STORY-00008: 登录/注册页骨架

**Epic**: E-001 账号与好友
**Sprint**: Sprint 2
**Sprint Goal**: 完成全APP UI骨架，双模式明显可感知
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a new user, I want to see a clear onboarding flow, so that I understand how to get started with Cairn.

## Expected Result
启动页、登录页、注册页三个屏幕，点击可流转。无真实Auth，点击"登录"直接进入主地图页（mock）。

## Acceptance Criteria
- [ ] 启动页：Cairn logo（石堆图形）+ tagline "Leave a mark. Guide the next." + 两个按钮（"创建账号" / "已有账号，登录"）
- [ ] 登录页：邮箱输入 + 密码输入 + "登录"按钮 + Google/Apple登录选项（mock按钮）
- [ ] 注册页：邮箱 + 密码 + 确认密码 + "创建账号"按钮
- [ ] 注册成功后默认进入说明模式（Zustand初始state = 'guided'）
- [ ] 说明模式：表单字段有placeholder说明文字（"你的邮箱地址，用于找回账号"）
- [ ] 简易模式（已登录后切换）：下次进入登录页标准placeholder（"邮箱" / "密码"）
- [ ] Style B背景色，logo居中，视觉简洁

## UX AC
- [ ] 启动页到注册完成 ≤ 4 tap
- [ ] 键盘弹出时表单不被遮挡（KeyboardAvoidingView）

## Dependencies
- STORY-00006（Zustand state初始化）

## Notes
Auth完全mock：点击任何登录/注册按钮直接navigate到主地图页。
