# STORY-00006: 设置页 + 双模式切换（核心）

**Epic**: E-006 UI/UX
**Sprint**: Sprint 2
**Sprint Goal**: 完成全APP UI骨架，双模式明显可感知
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a new user, I want to access Settings and switch between Guided Mode and Simple Mode, so that I can choose my preferred level of UI assistance.

## Expected Result
设置主页完整展示所有选项分组。双模式切换页有明显的视觉对比预览。切换后全APP立即反映模式变化（通过Zustand全局state）。

## Acceptance Criteria
- [ ] 设置主页展示6个分组：UI模式、运动偏好、播报、隐私、地图、账号
- [ ] 每个设置项在说明模式下有副标题说明（e.g. "控制按钮标签和引导提示的显示"）
- [ ] 说明/简易模式切换页有两个并排的预览卡片，直观展示差异
- [ ] 切换动画：模式切换时有 300ms 淡入过渡
- [ ] 切换后底部导航立即反映：说明模式显示文字标签，简易模式仅图标
- [ ] 当前模式有明显 active 标记（绿色背景 + 勾选）
- [ ] 说明模式下每个设置行有 `>` 跳转箭头 + 当前值说明文字
- [ ] 简易模式下设置行紧凑，仅图标 + 标题 + toggle/值

## UX AC
- [ ] 从主地图页到设置页 ≤ 2 tap
- [ ] 模式切换确认后有 toast 提示（"已切换到简易模式"）
- [ ] 设置项按使用频率排序（UI模式在最顶部）

## Dependencies
- 无（mock数据）

## Notes
这是Sprint 2的核心Story。双模式切换的视觉实现直接决定其他所有页面的布局。
必须首先完成，其他Stories依赖其Zustand state。
