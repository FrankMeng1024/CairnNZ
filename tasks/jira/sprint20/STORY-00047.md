# STORY-00047: HomeScreen — Quick Stats Summary + Empty State Polish

**Epic**: E-006 UI/UX
**Sprint**: Sprint 20
**Sprint Goal**: UI Quality Round 3
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a returning user, I want to see a summary of my total activity at a glance on the home screen — total sessions, distance, and flags — and when I have no activity yet, a welcoming empty state.

## Expected Result
HomeScreen shows a "Quick Stats" row with 3 stat capsules. Greeting includes mode-aware personalization. Empty state replaces stats when no data yet.

## Acceptance Criteria
- [ ] Quick Stats row: 3 capsules (sessions/Route icon, distance/Map icon, flags/Flag icon), each with value + unit
- [ ] Stats use real data from useSessionStore + useMarkerStore
- [ ] Empty state (0 sessions AND 0 markers): illustration + "Your adventure begins here" + subtitle CTA
- [ ] Greeting shows "Good morning, Explorer" or "Good morning, Navigator" based on uiMode
- [ ] Stats capsules have staggered fade-in animation (60ms delay between each)
- [ ] No console errors; 390px viewport verified

## Notes
Read useSessionStore for sessions, useMarkerStore for markers count.
