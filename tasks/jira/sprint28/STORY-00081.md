# STORY-00081: AuthScreen — input field focus state

**Epic**: E-006 UI/UX
**Sprint**: Sprint 28
**Sprint Goal**: Eliminate hardcoded values, improve input/selection feedback, standardize overlays
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user filling in the sign-in or create-account form, I want to clearly see which field I'm currently typing in so I know my input is being captured.

## Expected Result
Email and password fields (both Sign In and Create Account) show a colored border when focused — `Colors.primary` green border replaces the default grey border when the field is active.

## Acceptance Criteria
- [ ] Email field: default state shows `Colors.border` (grey) border; on focus shows `Colors.primary` border
- [ ] Password field: default state shows `Colors.border` (grey) border; on focus shows `Colors.primary` border
- [ ] Name field (Create Account form): same focus behavior
- [ ] Unfocused fields revert to default `Colors.border` color on blur
- [ ] Focus state change is immediate (no delay or animation required — subtle state change)
- [ ] Validation error state (red border) still overrides focus state when field has a validation error
- [ ] Zero new console errors

## Dependencies
None.

## Notes
Currently no focus states on any input fields. First-time users are unsure which field is active, especially when tapping from field to field. This is a basic UX expectation (iOS/web standard).
