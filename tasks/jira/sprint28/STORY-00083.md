# STORY-00083: SettingsScreen — section header font size + night mode color token

**Epic**: E-006 UI/UX
**Sprint**: Sprint 28
**Sprint Goal**: Eliminate hardcoded values, improve input/selection feedback, standardize overlays
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user reading the Settings screen, I want section headers to be legible, and as a developer I want the night mode icon color to use a proper token.

## Expected Result
Section headers ("APPEARANCE", "ACTIVITIES", "ACCOUNT") use `FontSize.small` (11px) instead of `FontSize.tiny` (9px). Night mode toggle icon uses `Colors.night` token.

## Acceptance Criteria
- [ ] Section header `fontSize` changed from `FontSize.tiny` to `FontSize.small` in SettingsScreen
- [ ] Section headers remain uppercase + `fontWeight: '700'` + `letterSpacing: 1` (unchanged visual except size)
- [ ] Night mode icon color hardcode `'#5a4fcf'` replaced with `Colors.night` token (defined in STORY-00080)
- [ ] Mode card description `lineHeight` increased from 16 to 18 for better text breathing
- [ ] No other style changes
- [ ] Zero new console errors

## Dependencies
- Partially blocked by: STORY-00080 (needs `Colors.night`)

## Notes
9px section headers are near the accessibility floor. 11px (`FontSize.small`) is still compact and structured but readable. Small change, high polish value.
