# STORY-00084: Cross-screen overlay opacity standardization

**Epic**: E-006 UI/UX
**Sprint**: Sprint 28
**Sprint Goal**: Eliminate hardcoded values, improve input/selection feedback, standardize overlays
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user looking at any screen with semi-transparent overlays (GPS chip, tracking bar, session stat bar, map controls), I want them to feel visually consistent — the same white opacity rather than slightly different values that look unintentional.

## Expected Result
All white semi-transparent overlay surfaces across the app use a consistent opacity (0.95) instead of the current mix of 0.92, 0.95, 0.97, 0.98.

## Acceptance Criteria
- [ ] HikingScreen GPS chip background (currently `'rgba(255,255,255,0.97)'`) → `'rgba(255,255,255,0.95)'`
- [ ] HikingScreen tracking bar background (currently `'rgba(255,255,255,0.98)'`) → `Colors.surface` (opaque white) since it's an elevated card, not a float overlay
- [ ] HikingScreen "Download Map" button background (currently `'rgba(255,255,255,0.6)'`) → `'rgba(255,255,255,0.85)'` (more visible)
- [ ] MapHistoryScreen session stat bar background (currently `'rgba(255,255,255,0.92)'` and `'rgba(255,255,255,0.98)'`) → both to `'rgba(255,255,255,0.95)'`
- [ ] RunningScreen overlay elements using non-standard opacity → `'rgba(255,255,255,0.95)'` where used as floating overlays
- [ ] All other fully-opaque surfaces (cards, sheets) remain using `Colors.surface` — no change
- [ ] Zero new console errors
- [ ] No visual regressions on any screen

## Dependencies
None.

## Notes
Current state: 5 different opacity levels used for "white overlay" surfaces. This makes the UI feel slightly inconsistent even if users can't articulate why. Standardizing removes the visual noise. 0.95 is the design standard.

Arch review note: downloadBtn at 0.85 (not 0.95) is intentional — it is a map-overlay control, not a floating surface. Needs higher contrast visibility against varied map tile backgrounds. Documented here for Arch confirmation.
