# STORY-00088: RoutesScreen — empty state upgrade + route card download affordance

**Epic**: E-006 UI/UX
**Sprint**: Sprint 29
**Sprint Goal**: Eliminate remaining hardcoded color values, complete Auth form polish, and upgrade RoutesScreen empty state
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user browsing the Routes screen, I want route cards to have a clear "Download" affordance matching the map placeholder's "Download Map" CTA, and I want an empty state if no routes exist, so the screen always feels intentional.

## Expected Result
Each route card has a Download button (outlined, small). If routes list is empty, a designed empty state shows (not blank). Visual language matches the rest of the app.

## Acceptance Criteria
- [ ] Each route card has a "Download" pill button (outline style, Colors.primary border, small size) — positioned bottom-right of card or inline with the stat chips
- [ ] Download button tap shows a toast or visual response (e.g. "Route saved for offline use" or placeholder for now — no crash)
- [ ] Empty state: when routes list is empty, shows a mountain icon + "No routes yet" + "Routes you download will appear here" message — same design language as other empty states
- [ ] Empty state is only shown when routes array length = 0
- [ ] Zero new console errors

## Dependencies
None.

## Notes
HikingScreen map placeholder has "Download Map" CTA as the primary action. RoutesScreen cards should have the same download concept per-route. Currently cards only show stat chips with no action affordance.
