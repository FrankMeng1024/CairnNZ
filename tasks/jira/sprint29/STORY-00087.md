# STORY-00087: AuthScreen — email auto-focus on Sign In screen entry

**Epic**: E-006 UI/UX
**Sprint**: Sprint 29
**Sprint Goal**: Eliminate remaining hardcoded color values, complete Auth form polish, and upgrade RoutesScreen empty state
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user tapping "Sign In" from the splash screen, I want the email field to auto-focus immediately so I can start typing without an extra tap, reducing friction at the most critical entry point.

## Expected Result
When the Sign In form screen mounts, the email input field is auto-focused — green border + green icon visible immediately, keyboard rises (on native). No extra tap required to begin typing.

## Acceptance Criteria
- [ ] Email field is focused on Sign In screen mount — green border visible without any user tap
- [ ] Auto-focus occurs within 300ms of screen transition completing
- [ ] Password field remains unfocused (grey) until manually tapped
- [ ] Auto-focus does not trigger the error state (no premature validation)
- [ ] Zero new console errors

## Dependencies
None. Small enhancement following STORY-00081.
