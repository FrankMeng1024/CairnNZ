## Description
As a developer maintaining the codebase, I want all gradient stops and dark overlay rgba values to be named tokens, so there are no magic color literals scattered across screen files.

## Expected Result
All `rgba(61,122,181,...)` running-blue gradient stops → `Colors.runningGrad` token. All `rgba(200,121,65,...)` flag-orange gradient stops → `Colors.flagGrad` token. MapHistoryScreen map background `#e8f0e0` → `Colors.mapBg` token. MapHistoryScreen trail accent `#b5823d` → `Colors.trail` token. Dark modal overlays `rgba(0,0,0,0.4)` → `Colors.overlay` token. SettingsScreen switch track color `#E0E0E0` → `Colors.switchTrack` token.
