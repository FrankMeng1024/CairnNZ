# STORY-00089: FlagPlantSheet — note input focus state + keyboard-aware layout

**Epic**: E-006 UI/UX
**Sprint**: Sprint 29
**Sprint Goal**: Eliminate remaining hardcoded color values, complete Auth form polish, and upgrade RoutesScreen empty state
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user planting a flag during a hike, I want the note text input in the FlagPlantSheet to show a green focus border when tapped and for the sheet to scroll up when the keyboard appears, so my text input is never obscured.

## Expected Result
FlagPlantSheet note input shows green border on focus (matching Auth screen pattern). Sheet uses KeyboardAvoidingView or equivalent so the note input is visible above the keyboard when typing.

## Acceptance Criteria
- [ ] Note input field: green border + green icon tint (PenLine or Edit icon) on focus; grey unfocused
- [ ] Error state (over 30 char limit) shows red border — distinct from focus state
- [ ] Sheet content scrolls/lifts so note input is visible when keyboard is open
- [ ] Keyboard dismiss: tapping outside the note field dismisses keyboard and returns sheet to normal position
- [ ] Character count indicator is visible when note input is focused
- [ ] Zero new console errors

## Dependencies
None.

## Notes
FlagPlantSheet was added in Sprint 26. Note input currently has no focus styling. On longer notes the keyboard may cover the input. This brings FlagPlantSheet to the same polish level as the Auth forms.
