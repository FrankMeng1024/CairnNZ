## Description

Add a Mine|Friends sub-tab to the Flags tab of `RoutesScreen.tsx`. Mine = existing local marker list (useMarkerStore). Friends = subscribed-friend friend-tier marks loaded from Sprint 67 `GET /api/circle/markers`.

## Expected Result

Sub-tab toggle within Flags tab. Mine shows the viewer's own marks; Friends shows marks from subscribed friends (permission ∈ {friend, group, public}). Anonymized for Public marks. Hidden items (Sprint 68 STORY-00534) filtered server-side.

## Acceptance Criteria

- [ ] Sub-tab control rendered inside Flags tab (Mine|Friends, Mine selected by default)
- [ ] Mine view: existing FlagsTab behavior, unchanged
- [ ] Friends view: triggers `GET /api/circle/markers` on tab activation (or cached if already loaded)
- [ ] Friends view: renders list of friend-tier + public marks; uses MarkDetailSheet on tap (Sprint 68 STORY-00532)
- [ ] Public marks anonymized (no author name); Friend-tier marks show author
- [ ] Empty state: "No marks from your subscribed friends yet." with helpful CTA copy
- [ ] Loading state: skeleton or spinner during fetch
- [ ] Error state: retry button + error message
- [ ] Closes Sprint 68 follow-up "wire loadCircleMarkers" — adds the action to useMarkerStore (or a sibling store) and calls it from this tab

## Dependencies

- Sprint 67 STORY-00528: `GET /api/circle/markers` endpoint
- Sprint 68 STORY-00532: MarkDetailSheet for tap-to-detail
- Sprint 68 STORY-00531: tier-aware visuals (for list item icon)

## Notes

`loadCircleMarkers()` action lives in `useMarkerStore` (parallel to `loadFromBackend()`), cached in a separate slice `circleMarkers` so the Mine path is unaffected.
