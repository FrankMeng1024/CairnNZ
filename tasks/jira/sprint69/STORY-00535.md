**Epic**: E-Friend (Friend System v1)

## Description

Mirror Sprint 68 STORY-00530 for Routes: when creating a Route, the user picks Personal or Friend, default Friend, no Public option. Backend Route.create already persists `permission` (Sprint 67 STORY-00528 fix).

## Expected Result

Route create / save UI (RouteEditorScreen or wherever new routes are committed) has a 2-chip toggle 🔒 Personal | 👥 Friend with Friend selected by default. Tapping Save POSTs to `/api/routes` with the chosen permission. Backend stores it (Route model persists).
