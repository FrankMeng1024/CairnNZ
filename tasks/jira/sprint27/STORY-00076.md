## Description
As a user viewing session history, I want the distance stat chip to be clean and unambiguous when no GPS data exists.

## Expected Result
Expanded session capsule shows "No GPS" without a trailing "km" unit label when session has no GPS distance data.

## Acceptance Criteria
- [ ] When `distStr === 'No GPS'`, the km label is NOT rendered in the expanded capsule stat chip
- [ ] The "No GPS" value still shows with correct styling (left border, stat value text)
- [ ] Sessions WITH GPS distance show "X.X km" as before (value + km label, unchanged)
- [ ] Secondary line in card header (e.g. "Today · No GPS") unchanged
