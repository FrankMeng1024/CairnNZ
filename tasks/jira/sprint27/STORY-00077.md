# STORY-00077: RoutesScreen premium uplift — match Sprint 24+ design language

**Epic**: E-006 UI/UX
**Sprint**: Sprint 27
**Sprint Goal**: Polish every remaining friction point
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user browsing saved routes, I want the Routes screen to feel as polished as MapHistory, HomeScreen, and FriendsScreen — with gradient icon badges, consistent typography, and premium card styling.

## Expected Result
RoutesScreen route cards use the same design language as Sprint 24+ screens: gradient LinearGradient icon badges, consistent h3/700 title treatment, shadow cards, muted secondary text.

## Acceptance Criteria
- [ ] Screen title is h1/800 "Routes" (expert mode) or "Route History" (beginner mode) — same as before but with same typographic weight as other screens
- [ ] Route cards use Shadow.card and borderRadius Radius.card — elevated appearance
- [ ] Each route card has a gradient LinearGradient icon badge (40×40, primaryLight gradient for Hike routes, runningLight gradient for Run routes if distinguishable — default to primary gradient)
- [ ] Route icon in badge uses Mountain icon (same as MapHistory/HikingScreen branding)
- [ ] Route name uses FontSize.h3/fontWeight 700, route date uses FontSize.small muted
- [ ] Stat chips (beginner mode) use same capsule style as HomeScreen QuickStats: small colored left-border, bold value, tiny unit
- [ ] Compact route line (expert mode) uses muted caption text — unchanged
- [ ] Empty state uses same style as other screens: icon in rounded bg circle, muted h3 title, muted caption hint
- [ ] ChevronRight icon present on each card, right-aligned
- [ ] At viewport 390px: no horizontal overflow, cards fill width with horizontal padding

## Notes
RoutesScreen last updated Sprint 13. Significantly behind current design language. Reference: MapHistoryScreen session cards (Sprint 24), HomeScreen activity cards (Sprint 23).
