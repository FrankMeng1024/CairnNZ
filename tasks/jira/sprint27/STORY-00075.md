# STORY-00075: Fix "New Run" button icon — RotateCcw → PlayCircle

**Epic**: E-006 UI/UX
**Sprint**: Sprint 27
**Sprint Goal**: Polish every remaining friction point
**Points**: 1
**Owner**: Frontend Dev

## Description
As a user completing a run, I want the "New Run" button to use an icon that communicates "start fresh" rather than "retry/refresh".

## Expected Result
Run Complete screen "New Run" button uses PlayCircle icon instead of RotateCcw. Label remains "New Run".

## Acceptance Criteria
- [ ] "New Run" button on Run Complete screen shows PlayCircle icon (not RotateCcw circular arrow)
- [ ] Button label "New Run" unchanged
- [ ] Tapping "New Run" still navigates back to pre-start Running screen
- [ ] PlayCircle icon is white, same size as before (IconSize.md)

## Notes
UX friction from Sprint 26 review: RotateCcw conventionally means "refresh/retry" — causes momentary cognitive mismatch. PlayCircle communicates "start a new activity".
