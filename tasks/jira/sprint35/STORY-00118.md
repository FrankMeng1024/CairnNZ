# STORY-00118: Backend Scaffold — Node.js/Express + MySQL + JWT Auth Endpoints

**Epic**: E-001 账号与好友
**Sprint**: Sprint 35
**Sprint Goal**: Real auth foundation
**Points**: 8
**Owner**: Backend Dev
**Status**: Done

## Description
As a developer, I need a production-ready backend service with JWT authentication, so that Cairn user data is stored securely and each user has isolated data.

## Expected Result
Backend at `Cairn/backend/` runs on port 3001, provides `/health`, `/api/auth/register`, `/api/auth/login` endpoints, persists users in MySQL, issues JWT tokens.

## Acceptance Criteria
- [ ] `Cairn/backend/` directory contains: `package.json`, `src/index.js`, `src/routes/auth.js`, `src/middleware/auth.js`, `src/models/User.js`, `src/config/db.js`, `.env.example`
- [ ] `GET /health` returns `{ status: 'ok', version: '1.0' }` with < 100ms response time
- [ ] `POST /api/auth/register` accepts `{ name, email, password }`, hashes password with bcrypt (rounds=12), stores in MySQL `users` table, returns `{ token, user: { id, name, email } }`
- [ ] `POST /api/auth/login` accepts `{ email, password }`, returns `{ token, user: { id, name, email } }` or 401 on wrong credentials
- [ ] JWT tokens have 7-day expiry, signed with `JWT_SECRET` env var
- [ ] Passwords never returned in any API response
- [ ] Duplicate email on register returns 409 with `{ error: 'Email already registered' }`
- [ ] MySQL schema: `users` table with `id` (UUID), `name`, `email` (UNIQUE), `password_hash`, `created_at`, `updated_at`
- [ ] `GET /api/auth/me` with valid Bearer token returns current user (verifies JWT middleware works)
- [ ] CORS configured to allow Expo dev server origins (localhost:8082, 19006, exp://)
- [ ] `backend/scripts/migrate.sql` contains CREATE TABLE statements runnable on existing MySQL server

## Architecture Notes
Backend handles: auth, user profile, future: session sync, marker sync, friend relationships
Frontend handles: all UI, GPS tracking, local state, offline-first caching via WatermelonDB
