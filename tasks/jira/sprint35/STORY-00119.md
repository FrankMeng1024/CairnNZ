# STORY-00119: Frontend Auth — Wire to Real Backend API

**Epic**: E-001 账号与好友
**Sprint**: Sprint 35
**Sprint Goal**: Real auth foundation
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want my account registration and sign-in to actually store my data, so that my trail history and flags persist across sessions.

## Expected Result
`AuthScreen` `handleAuth()` calls the real backend `/api/auth/register` and `/api/auth/login` endpoints instead of `setLoggedIn(true)`. JWT token stored in SecureStore (native) / AsyncStorage (web fallback). Auth state hydrated on app launch.

## Acceptance Criteria
- [ ] New `app/src/services/authService.ts` with `register(name, email, password)` and `login(email, password)` functions that call backend
- [ ] `register()` on success: stores JWT in storage, sets `isLoggedIn: true`, stores user profile `{ id, name, email }` in `useAppStore`
- [ ] `login()` on success: same as register
- [ ] `register()` / `login()` on error: displays backend error message inline (not generic "Something went wrong")
- [ ] Loading state shown on submit button while API call in progress (spinner or opacity)
- [ ] `app/src/store/useAppStore.ts` extended with `user: { id, name, email } | null` and `setUser()` action
- [ ] `app/src/config/api.ts` exports `API_BASE_URL` (configurable via env, defaults to `http://localhost:3001`)
- [ ] On app launch, if JWT exists and is not expired, skip AuthScreen → navigate to Home
- [ ] Sign Out in SettingsScreen clears JWT and navigates to AuthScreen
- [ ] All above verified against running backend (STORY-00118 must be done first)

## Notes
Use `expo-secure-store` for token on native. On web use `localStorage`. Abstract into `tokenStore.ts`.

**Spec Drift fix (logged for Arch)**: `initialRouteName` in RootNavigator is evaluated once at mount; async `hydrate()` arrived too late causing reload with valid JWT to show Auth screen. Fixed by adding `hydrated: boolean` flag to `useAppStore` and guarding RootNavigator render in `App.tsx` with `if (!hydrated) return <View style={{ flex: 1 }} />`. Both AC8 and AC9 live-verified.
