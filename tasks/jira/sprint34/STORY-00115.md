## Description
As a user reviewing my route history, I want the top stats bar and collapsed session cards to feel polished and visually consistent with the expanded card quality.

## Expected Result
Stats bar at top of MapHistoryScreen shows meaningful data with proper null states. Collapsed session cards have activity type badge clearly visible and better visual hierarchy.

## Acceptance Criteria
- [ ] Stats bar: distance shows "0 km" instead of "--" when no GPS data (matching STORY-00113 pattern)
- [ ] Stats bar: each stat cell has subtle left-border accent color (km=blue/running, time=primary, flags=flag color, elev=muted) — 2px left border for visual identity
- [ ] Collapsed session card: activity badge (Run/Hike) is a colored pill matching HomeScreen style (Colors.running bg for Run, Colors.primaryLight bg for Hike)
- [ ] Collapsed session card: "Today · No GPS" secondary line is muted (Colors.textMuted) — clear separation from primary stat
- [ ] Collapsed card tap area has spring press feedback (scale 0.98 → 1.0)
- [ ] Flags tab switcher: pill/tab styling consistent with Routes tab (currently both look the same — verify and tighten)
