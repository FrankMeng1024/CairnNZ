# STORY-00111: RoutesScreen — Premium Card Design

**Epic**: E-001/E-006 UI Quality Uplift
**Sprint**: Sprint 34
**Sprint Goal**: Premium screen polish
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user browsing my saved routes, I want the route list to feel premium and information-rich, matching the quality of HikingScreen and MapScreen.

## Expected Result
RoutesScreen cards have gradient icon badges, well-formatted stat chips without parenthesis-style borders, and a clear visual hierarchy matching AllTrails/Strava card quality.

## Acceptance Criteria
- [ ] Each route card has a gradient icon badge (Mountain icon, Colors.primary gradient) matching HikingScreen activity card style
- [ ] Stat chips (km, time, flags) use the capsule style from MapHistoryScreen (rounded pill, icon + value, no parenthesis characters)
- [ ] Route title is bold, date is muted secondary text — clear typographic hierarchy
- [ ] Download button is visually integrated into the card (bottom row, secondary style, not floating)
- [ ] Cards have subtle shadow (Shadow.card) and Radius.lg rounding
- [ ] Spring press animation on card tap (scale 0.97 on pressIn, back to 1.0 on pressOut)
- [ ] Empty state: if no routes, show designed empty state (not blank screen)
- [ ] All colors from design tokens (Colors.*), no hardcoded values

## Dependencies
- None

## Notes
Competitor reference: AllTrails route list — gradient icon, stats row, download CTA integrated into card.
