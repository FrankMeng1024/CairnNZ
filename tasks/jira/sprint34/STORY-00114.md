# STORY-00114: GPS Status Pill — Pre-Tracking State

**Epic**: E-002/E-006 UI Quality Uplift
**Sprint**: Sprint 34
**Sprint Goal**: Premium screen polish
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user opening HikingScreen or MapScreen before starting tracking, I want the GPS status pill to communicate something useful rather than showing "GPS Offline" in alarming red — which implies an error when really tracking just hasn't started yet.

## Expected Result
GPS status pill shows a calm, informative state before tracking starts. "GPS Offline" red pill only appears when GPS is genuinely unavailable (permission denied / hardware off).

## Acceptance Criteria
- [ ] HikingScreen: before tracking starts, GPS pill shows "GPS Ready" (green dot, neutral) if location permission granted, or "Enable GPS" (amber, not red) if permission not yet granted
- [ ] MapScreen: same pill logic — "GPS Connected ±5m" style when permission available but not tracking
- [ ] "GPS Offline" red pill only appears when: expo-location returns an explicit error OR permission is denied
- [ ] Pill color system: green = connected/ready, amber = permission needed, red = error/offline
- [ ] No change to pill behavior during active tracking (existing "GPS Connected ±5m" state preserved)
- [ ] Pill uses existing pill component/style — only the label text and color logic changes

## Dependencies
- None

## Notes
Visual audit observation: "GPS Offline" red pill on Hiking pre-start screen reads as error state, not as "haven't started yet".
On web simulator, GPS permission is not granted, so we need "Enable GPS" amber state for web.
