# STORY-00113: HomeScreen — Activity Card Subtitle + Stats Bar Null State

**Epic**: E-006 UI Quality Uplift
**Sprint**: Sprint 34
**Sprint Goal**: Premium screen polish
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a first-time user on the HomeScreen, I want the activity card descriptions to be readable and the stats bar to clearly communicate what "--" means.

## Expected Result
Activity card subtitles fit on one line (or two clean lines without awkward wrapping). Stats bar shows "0 km" instead of "-- km" when no GPS data, eliminating UX ambiguity for first-time users.

## Acceptance Criteria
- [ ] Hiking card subtitle: "Navigate trails · Plant flags · Explore" displays without wrapping mid-phrase — either single line or max 2 lines with natural break point
- [ ] Running card subtitle: "Route planning · Voice guidance · Lock mode" same treatment
- [ ] Stats bar distance: shows "0 km" when totalDistM < 10 (replacing "--") — eliminates ambiguity for first-time users
- [ ] "0 km" uses same muted styling as current "--" (not a red error state)
- [ ] Stats bar distance: shows formatted value (e.g. "14.2 km") when totalDistM >= 10 — existing behavior preserved
- [ ] No layout changes to card structure — only subtitle text and stats bar value

## Dependencies
- None

## Notes
UX friction item from Sprint 33 review: "-- km" is ambiguous — could mean zero, untracked, or error. "0 km" is clearer.
Activity card subtitle wrapping noticed in Sprint 34 visual audit.
