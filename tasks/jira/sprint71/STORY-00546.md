**Epic**: E-Friend (Friend System v1) · **Sprint**: 71 · **Points**: 5 · **Owner**: Frontend + Arch · **Status**: Todo (iPhone-gated)

## Description
Activate the SPIKE-67-1 conditional gate: measure live FPS of 5-friend fog UNION render on user's iPhone. If pass, implement Story-00541 (FogLayer extension); if fail, activate SPIKE-67-1 Fallback A (per-friend translucent overlay).

## Steps

### Pre-flight on Mac (user)
1. `cd app && npx expo run:ios --device` (real iPhone, not simulator — sim doesn't reproduce Mapbox iOS perf)
2. Sign in as 9163. Subscribe to 5 mock friends (use Sprint 67 seed user_id 19/20/21/22/23: Alice/Bob/Carol/Dave/LDY).
3. Backend ensures these friends have memory_points (Sprint 67 seed for Bob = 3 points; rest = 0). For a real perf test, seed each friend with ~50 points spread across a 5km bbox — script below.

### Seed extra memory_points for perf test (run on aliyun)
```sql
-- run on aliyun MySQL via ssh root@122.51.174.118 docker exec
INSERT INTO memory_points (user_id, lat, lng, ts, client_id)
SELECT u.id, 31.232 + (RAND()*0.04 - 0.02), 121.434 + (RAND()*0.04 - 0.02),
       UNIX_TIMESTAMP(NOW()) * 1000 + n.n,
       CONCAT('perf-seed-', u.id, '-', n.n)
FROM users u CROSS JOIN
  (SELECT 0 AS n UNION SELECT 1 UNION SELECT 2 UNION ... [50 rows]) n
WHERE u.email IN ('1@cairn.demo','2@cairn.demo','3@cairn.demo','4@cairn.demo','5@cairn.demo');
```

### Live FPS measurement
1. Open Memory tab → Friends scope on iPhone connected to Mac
2. Open Safari Web Inspector → Memory + CPU + Network tabs
3. Pan + zoom at z=12, z=14, z=16, z=18 — record FPS each
4. Record memory delta during pan
5. Stop at any zoom that drops below 50fps

### Decision
- **PASS (FPS ≥ 50 at all 4 zoom levels, mem < 200MB)**: implement Story-00541:
  - `useMemoryStore.loadCircleFog()` consuming `GET /api/circle/fog`
  - `FogLayer.tsx` extension: when `useMemoryScopeStore.scope === 'friends'`, include subscribed-friend points in the corridor union
  - Visual: friends' fog cleared regions in lighter sepia tint
  - Land in F5 Sprint after FPS confirmed
- **FAIL**: activate SPIKE-67-1 Fallback A:
  - Each subscribed friend gets a separate ShapeSource + FillLayer with fillOpacity 0.4
  - 5 translucent shapes stacked; visual sum reads as social-overlay
  - Trade-off documented in `_research/friend-system/fallback-A-implementation.md`
