# STORY-00072: SettingsScreen — premium redesign to Sprint-25 quality

**Epic**: E-006 UI/UX
**Sprint**: Sprint 26
**Sprint Goal**: Flag planting excellence + SettingsScreen premium uplift
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a Cairn user, I want the Settings screen to feel as premium as the rest of the app, so that the experience is consistent from end to end.

## Expected Result
SettingsScreen matches Sprint 23-25 design language: h3 title, gradient mode cards, styled section headers, toggle rows with consistent typography, and a Save button that matches the shimmer/green pattern from Sprint 22.

## Acceptance Criteria
- [ ] Screen title: "Settings" as h3/700 (matching RunningScreen, FriendsScreen, MapHistoryScreen pattern)
- [ ] Mode selector cards: Explorer and Navigator each have gradient icon badge (40×40, LinearGradient), card title at h3/600, description at caption/400, selected state = 2px Colors.primary border + Colors.primaryLight tint + CircleCheck badge top-right
- [ ] Section headers (e.g. "Tracking", "Experience"): FontSize.tiny, Colors.textMuted, uppercase, Spacing.md top margin — matches Sprint 23 QuickStats section style
- [ ] Toggle rows: label at body/500 + icon badge (16×16, tinted) left, Switch right — all switches use consistent green/grey track + white thumb
- [ ] Save button: hidden when no changes pending; visible + Colors.primary solid + "Saved" shimmer animation when dirty state — matches Sprint 22 established pattern
- [ ] LogOut row: Colors.danger text + Trash2/LogOut icon, visually separated at bottom
- [ ] No regressions on mode-switch functionality or switch persistence at 390px
- [ ] Zero console errors after screen navigation

## Dependencies
- None

## Notes
SettingsScreen was last touched Sprint 12 (SVG icon pass). It has not received the Sprint 22+ design token uplift. Mode cards, section headers, and toggle rows all need to be brought to current standard.
