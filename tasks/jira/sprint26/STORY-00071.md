# STORY-00071: Flag plant modal — premium bottom sheet UX

**Epic**: E-003 Marker System
**Sprint**: Sprint 26
**Sprint Goal**: Flag planting excellence + SettingsScreen premium uplift
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a hiker, I want the flag planting flow to feel intentional and premium — not like a debug overlay — so that planting a flag feels like leaving something meaningful.

## Expected Result
Tapping the Flag FAB opens a bottom sheet (not a dark AR camera overlay) that lets the user pick a flag type and optionally add a note, then confirms with a checkmark animation. The flow matches the Sprint 23+ design language.

## Acceptance Criteria
- [ ] Flag FAB tap opens a bottom sheet (white surface, Radius.card top corners, Shadow.overlay) — NOT the dark AR camera overlay
- [ ] Bottom sheet header: "Plant a Flag" h3 title (Colors.textPrimary, FontSize.h3) + X close button (top-right)
- [ ] Flag type row: 4 horizontal cards (Danger/Scenic/Water/Junction), each with gradient icon badge + label, selected state = 2px Colors.primary border + primaryLight tint
- [ ] Note input: TextInput with placeholder "Describe this spot… (optional)", 30-char counter, Colors.border outline
- [ ] "Save Flag" primary button (Colors.primary bg, white text, Flag icon left) — enabled when a type is selected
- [ ] On save: bottom sheet closes, a CircleCheck toast appears bottom-center for 1.5s ("Flag saved")
- [ ] Marker pins on map show after save (existing behavior retained)
- [ ] Tapping a marker pin opens the MarkerDetailSheet (existing sheet retained, no changes needed)
- [ ] No regressions at 390px viewport; zero console errors

## Dependencies
- None (ARFlagPicker + PlantNoteSheet replaced/upgraded)

## Notes
The existing ARFlagPicker uses a dark "camera BG" aesthetic from Sprint 18 pre-dating the design system. This Story replaces it with a bottom-sheet approach consistent with the Sprint 23+ language. The MarkerDetailSheet is already premium — retain as-is. Draggable AR mechanics removed (browser/web incompatible) in favour of bottom sheet selection which works cleanly on all platforms.
