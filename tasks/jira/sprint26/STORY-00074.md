# STORY-00074: AuthScreen Create Account + HowItWorks onboarding polish

**Epic**: E-001 Account & Friends
**Sprint**: Sprint 26
**Sprint Goal**: Flag planting excellence + SettingsScreen premium uplift
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new Cairn user, I want the Create Account flow and first-run onboarding to feel as premium as Sign In, so that I'm excited to start from the very first screen.

## Expected Result
Create Account form matches Sign In quality (same field styling, same validation UX, privacy checkbox). HomeScreen HowItWorks 3-step row uses gradient icon badges matching Sprint 23 QuickStats style.

## Acceptance Criteria
- [ ] Create Account form: Name + Email + Password fields all use the same input style as Sign In (white surface card, Colors.border outline, body/400 text, Colors.textMuted placeholder)
- [ ] Create Account validation: email regex + password min-6 + name required — red error text below each field on blur, same as Sign In
- [ ] Create Account privacy checkbox: identical layout to Sign In (22×22 checkbox + "I agree to the" label + underlined "Privacy Policy" link)
- [ ] Create Account submit button: same pill style as Sign In "Sign In" button (Colors.primary solid, white text)
- [ ] HomeScreen HowItWorks (empty state): 3-step icons upgraded from flat muted icons to gradient icon badges (LinearGradient, 40×40, same spec as QuickStats capsule icons). Step labels remain unchanged.
- [ ] No regressions on Sign In flow, Auth navigation, or HomeScreen data state
- [ ] Zero console errors after Create Account → Home navigation

## Dependencies
- None

## Notes
Create Account form was last touched Sprint 9 and has not received the Sprint 21 AuthScreen premium treatment. HowItWorks icons are currently flat/muted from Sprint 21 — upgrading to gradient badges makes the empty state feel more alive and consistent with the app's visual language.
