# STORY-00045: FriendsScreen — add-friend flow + empty state

**Epic**: E-001 Account & Friends
**Sprint**: Sprint 19
**Sprint Goal**: UI quality round 2: Session track visualization, SettingsScreen expert mode, FriendsScreen polish, MapHistoryScreen visual uplift
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new user with no friends yet, I want a welcoming empty state on the Friends screen, and when I tap "Add a friend" I want a polished invite form with validation and a clear success state.

## Expected Result
Empty state: a friendly illustration + "No friends yet" message with a CTA. Add friend modal: email input with format validation, Send Invite button with loading → success/error states.

## Acceptance Criteria
- [ ] Empty state (0 friends): shows an illustration (Users icon large, muted), "No friends yet" heading, "Add friends to share flags and stay connected" body, "Add a Friend" CTA button
- [ ] Add-friend form accessible via CTA or top-right Add button
- [ ] Email field: shows validation error "Enter a valid email" for malformed input on submit attempt
- [ ] Email field: shows error "Can't invite yourself" if own email entered
- [ ] On valid email submit: shows success state "Invite sent to name@email.com" with checkmark, form resets after 2s
- [ ] Cancel/dismiss closes the form
- [ ] With friends present: existing list unchanged, Add button still works
- [ ] No console errors
- [ ] Verified at 390px viewport

## Dependencies
None — purely frontend state, no backend required

## Notes
"Own email" check: compare against a hardcoded test email or use a simple string mismatch.
Success state can be local (no real API call needed).
Keep mock MOCK_FRIENDS list as fallback when friends exist.
