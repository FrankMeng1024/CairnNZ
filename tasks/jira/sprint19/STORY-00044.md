# STORY-00044: SettingsScreen — Expert mode UI implementation

**Epic**: E-006 UI/UX
**Sprint**: Sprint 19
**Sprint Goal**: UI quality round 2: Session track visualization, SettingsScreen expert mode, FriendsScreen polish, MapHistoryScreen visual uplift
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As an experienced hiker, I want the "Expert" UI mode in Settings to visibly change the app's information density — showing more stats, smaller text, and less hand-holding — so the mode toggle has real product value.

## Expected Result
When UIMode = 'expert', the HikingScreen stats bar shows additional metrics (elevation, bearing), flag labels are hidden (icons only), and the map topo art shows a grid overlay. When UIMode = 'beginner' (default), the current clean layout is shown.

## Acceptance Criteria
- [ ] SettingsScreen mode cards: "Explorer" (beginner) and "Navigator" (expert) — both visually distinct with icon + description
- [ ] "Explorer" card: Mountain icon, "Simplified view · Guided prompts" description
- [ ] "Navigator" card: Compass icon, "Full data · Dense interface · Expert controls" description
- [ ] Selected mode has a prominent accent border and filled background badge
- [ ] uiMode persisted to AsyncStorage (already implemented) — verify it reads on mount
- [ ] In Expert mode: HikingScreen stats bar adds elevation row (shows '--' when no GPS)
- [ ] In Expert mode: AR flag picker corner buttons show icon only (no label text)
- [ ] Switching mode in Settings immediately reflects on next HikingScreen visit (no restart needed)
- [ ] No console errors
- [ ] Verified at 390px viewport

## Dependencies
None — uiMode already in useAppStore
