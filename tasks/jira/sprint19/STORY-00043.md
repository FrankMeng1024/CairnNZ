# STORY-00043: MapHistoryScreen — session track polyline visualization

**Epic**: E-002 Map & Navigation
**Sprint**: Sprint 19
**Sprint Goal**: UI quality round 2: Session track visualization, SettingsScreen expert mode, FriendsScreen polish, MapHistoryScreen visual uplift
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a hiker who just completed a session, I want to tap a session card and see a simple track line drawn on the topo map placeholder, so I can review my route visually.

## Expected Result
When a session card is selected in MapHistoryScreen Routes tab, the topo map area shows a polyline path derived from the session's trackPoints (or a representative mock path for sessions with no GPS points). The line is styled in the activity colour (green for hike, blue for run).

## Acceptance Criteria
- [ ] Tapping a session card selects it (already works) AND shows a polyline on the map
- [ ] Track line drawn using connected View segments or SVG path approximation for trackPoints with ≥2 points
- [ ] For sessions with 0 trackPoints (GPS offline), show a dashed "No GPS data" placeholder line
- [ ] Line colour: hiking = Colors.primary (#5d7c46), running = #3d7ab5
- [ ] Session stats (distance, duration, elevation) displayed below the map in a stat bar
- [ ] Stat bar shows: distance km, duration, markers planted (count)
- [ ] Marker pins from the session still render on top of the track
- [ ] No console errors
- [ ] Verified at 390px viewport

## Dependencies
None

## Notes
TrackingSession has `trackPoints: TrackPoint[]` where TrackPoint = `{ lat, lng, alt?, timestamp }`.
For web preview, trackPoints will be empty (no GPS). Implement both states.
Use Dimensions.get('window') to map lat/lng to pixel coordinates within the map bounds.
