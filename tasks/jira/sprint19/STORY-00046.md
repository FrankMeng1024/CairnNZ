# STORY-00046: MapHistoryScreen — visual quality uplift + flag detail sheet

**Epic**: E-006 UI/UX
**Sprint**: Sprint 19
**Sprint Goal**: UI quality round 2: Session track visualization, SettingsScreen expert mode, FriendsScreen polish, MapHistoryScreen visual uplift
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user reviewing my history, I want the MapHistoryScreen Flags tab to show a richer flag detail when I tap a marker — including the flag type, note, and planted date — and I want the overall layout to feel more polished.

## Expected Result
Tapping a flag marker in the Flags tab opens a bottom sheet with: flag type badge, note text (or "No note"), date planted, and a Delete button. The flag list items show richer metadata. The tab header shows counts as badges.

## Acceptance Criteria
- [ ] Flag list items show: type icon + type label badge, note preview (truncated at 40 chars), time-ago string
- [ ] Tap a flag list item → bottom sheet slides up (Animated translateY)
- [ ] Bottom sheet shows: type badge (icon + label + colour), full note text, "Planted: [date]", Delete button
- [ ] Delete button: shows "Delete Flag" in red, confirms via Alert, removes from store on confirm
- [ ] Bottom sheet has a drag handle at top, tapping outside dismisses it
- [ ] Tab header: "Routes (N)" and "Flags (N)" show count badges when N > 0
- [ ] Empty states: Routes tab "No sessions yet · Start hiking or running", Flags tab "No flags planted · Open the map to place your first flag"
- [ ] No console errors
- [ ] Verified at 390px viewport

## Dependencies
None

## Notes
Bottom sheet: use Animated.Value for translateY, start at screen height, animate to 0 on open.
The existing marker detail sheet in HikingScreen can serve as a reference for the pattern.
Deletion already works via useMarkerStore.deleteMarker.
