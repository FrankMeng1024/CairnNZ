# STORY-00099: MapScreen top bar + activity mode chip consistency

**Epic**: E-006 UI/UX
**Sprint**: Sprint 31
**Sprint Goal**: Bring MapScreen to premium quality
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user on the Map screen, I want the top bar elements (GPS chip, activity mode chip) to use the semi-transparent overlay standard (0.95 opacity) consistent with other floating UI elements in the app.

## Expected Result
GPS status chip and activity mode chip use rgba(255,255,255,0.95) background (semi-transparent, matching Sprint 28 overlay standard). Activity mode modal upgraded to use shadow card + LinearGradient icon badges for each mode option.

## Acceptance Criteria
- [ ] GPS chip background is rgba(255,255,255,0.95) (not opaque Colors.surface)
- [ ] Activity mode chip background is rgba(255,255,255,0.95)
- [ ] Both chips have Shadow.card elevation (same as other floating elements)
- [ ] Activity mode modal rows have LinearGradient icon badge (Mountain=primaryLight gradient, PersonStanding=runningLight gradient)
- [ ] Activity mode modal has h3/700 title, proper card radius (Radius.cardLg)

## Dependencies
- STORY-00095

## Notes
Top bar chips at line 260-280 of MapScreen.tsx. Currently use Colors.surface (opaque). Sprint 28 established the 0.95 opacity standard for floating overlays.
