# STORY-00097: MapScreen MarkerDetailSheet premium redesign

**Epic**: E-006 UI/UX
**Sprint**: Sprint 31
**Sprint Goal**: Bring MapScreen to premium quality
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user tapping a flag on the map, I want the detail sheet to have premium visual quality — gradient type badge, author attribution, "Helpful" interaction with proper visual feedback — matching the design language of other sheets in the app.

## Expected Result
MarkerDetailSheet: LinearGradient type badge (matching flag color), bold marker title + note text, clear author + time-ago attribution, "Helpful" button as a proper outlined pill with ThumbsUp icon (not just a flat row), close handle at top.

## Acceptance Criteria
- [ ] Type badge uses LinearGradient (matching flag's color system — Danger=red, Scenic=blue, Supply=green, Junction=orange)
- [ ] Marker title displayed in h3/600 weight
- [ ] Author + time-ago in caption/muted style (e.g. "Sam · 12m ago")
- [ ] Note text body-size with proper line height
- [ ] "Helpful" button is an outlined pill (border Colors.border, rounded Radius.pill) with ThumbsUp icon + "Helpful" label
- [ ] Sheet handle (drag indicator) visible at top of sheet
- [ ] Sheet has Shadow.overlay elevation
