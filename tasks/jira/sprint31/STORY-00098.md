# STORY-00098: MapScreen tracking bar + FAB consistency upgrade

**Epic**: E-006 UI/UX
**Sprint**: Sprint 31
**Sprint Goal**: Bring MapScreen to premium quality
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user actively tracking from the Map screen, I want the tracking bar to match HikingScreen's premium tracking bar (Sprint 25) — white elevated card with green left-border accent, clear stat hierarchy — rather than the current basic positioned bar.

## Expected Result
Tracking bar: white surface card (Colors.surface), Shadow.elevated, 3px Colors.primary left-border, stats in bold (h2/700 value + small muted unit). FAB updated to match HikingScreen style (red badge count). GPS status pill at top-left.

## Acceptance Criteria
- [ ] Tracking bar has white background (Colors.surface) + Shadow.elevated
- [ ] 3px left-border accent in Colors.primary (green)
- [ ] Stat values in FontSize.h2/700, unit labels in FontSize.small/muted
- [ ] GPS status pill visible top-left (matching HikingScreen "GPS Offline/Active" pattern)
- [ ] FAB has red badge showing flag count (hidden at 0, visible when > 0)
- [ ] Stop button style matches HikingScreen (red background, white text)
- [ ] Tracking bar does not overlap FAB (proper z-ordering)
