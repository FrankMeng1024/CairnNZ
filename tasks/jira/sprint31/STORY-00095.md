## Description

- [ ] S-curve trail path rendered on placeholder
- [ ] "Trail Map" title and "Download Map" outlined pill CTA visible
- [ ] "GPS Offline" red pill indicator present (matches HikingScreen)
- [ ] No visible raw grid lines (current grid pattern replaced)
- [ ] Marker dots still tappable on placeholder (functional regression: no break)
