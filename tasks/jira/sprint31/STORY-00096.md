# STORY-00096: MapScreen CreateMarkerSheet premium redesign

**Epic**: E-006 UI/UX
**Sprint**: Sprint 31
**Sprint Goal**: Bring MapScreen to premium quality
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user planting a flag from the Map screen, I want the flag creation sheet to match the HikingScreen FlagPlantSheet quality (Sprint 26) so that both entry points feel cohesive and premium.

## Expected Result
CreateMarkerSheet uses the same 4-card grid layout, LinearGradient icon badges per flag type, green border + CircleCheck selection indicator, char counter with three-tier color system (grey/amber/red), progressive disclosure Save button (disabled → active green), and permission selector with outlined pill style.

## Acceptance Criteria
- [ ] Flag type cards use 4-card grid layout (matching HikingScreen FlagPlantSheet Sprint 26 pattern)
- [ ] Each card has LinearGradient icon badge (40×40, type-appropriate color)
- [ ] Selected card shows 2px green border + Colors.primaryBg tint + CircleCheck badge
- [ ] Unselected cards have grey 1px border, white background
- [ ] Note input shows char counter — grey below 25, amber at 25-29, red at 30
- [ ] "Plant Flag" button is grey/disabled when no type selected; green when type selected
- [ ] Sheet has sheetHandle drag indicator at top
- [ ] Permission selector present (Personal/Friends/Public) with icon+label pills
