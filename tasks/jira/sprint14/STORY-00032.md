# STORY-00032: TrackingSession Store — real GPS tracking with expo-location

**Epic**: E-002 地图与导航
**Sprint**: Sprint 14
**Sprint Goal**: HikingScreen 真实 GPS + 本地标记持久化
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a hiker, I want to see my real GPS distance, duration, and elevation gain while tracking so I know how far I've gone.

## Expected Result
- `useTrackingStore` Zustand slice managing live tracking session
- expo-location watches position at high accuracy; distance calculated from coordinate deltas
- Duration counted by real elapsed time (setInterval seconds counter)
- Elevation from location.coords.altitude (with fallback to 0 on web)
- Tracking stats bar in HikingScreen shows real values
- On stop: session saved to `useSessionStore` for MapHistory to read

## Acceptance Criteria
- [ ] `src/store/useTrackingStore.ts` exists with `startTracking`, `stopTracking`, `addLocation` actions
- [ ] `startTracking` calls `Location.watchPositionAsync` with `accuracy: Location.Accuracy.BestForNavigation`
- [ ] Distance accumulates correctly using Haversine formula (unit-agnostic, meters internally)
- [ ] Duration is real elapsed seconds (not mock increment)
- [ ] Elevation gain = sum of positive altitude deltas (0 on web where altitude = null)
- [ ] HikingScreen tracking bar shows real distance (km, 2 decimal places), real duration (mm:ss), real elevation gain (m)
- [ ] On web: expo-location not available → graceful fallback shows "--" for GPS values, tracking timer still works
- [ ] `stopTracking` saves completed session to `useSessionStore`
- [ ] Session schema is geo-extensible: `{ id, regionCode, startedAt, endedAt, distanceM, durationS, elevationGainM, trackPoints: [{lat,lng,alt,t}], markerIds }`
- [ ] UX: GPS chip turns green with accuracy indicator when location active; grey/dashed when unavailable

## Dependencies
- Depends on: STORY-00031 (needs session to reference markerIds)

## Notes
Web preview limitation: browser Geolocation API less accurate than native expo-location.
On web, mock a position near `nz:auckland` default region center for visual testing.
Haversine formula must be in `src/utils/geo.ts` (not inline in store) — reusable across RunningScreen.
