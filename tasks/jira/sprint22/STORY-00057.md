# STORY-00057: Icon System Consistency

**Epic**: E-006 UI/UX
**Sprint**: Sprint 22
**Sprint Goal**: Design token hygiene, stat display polish, and icon system consistency
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want all icons to look consistent and high-quality across the app, with proper thumb color on toggles and no emoji-based checkmarks.

## Expected Result
All Switch components have white (`#FFF`) thumb color regardless of state. The checkmark in RunningScreen route selection uses a lucide `Check` icon instead of the "✓" text character. FriendsScreen Switch thumbColor updated to always white.

## Acceptance Criteria
- [ ] RunningScreen `checkBadge`: replace `<Text style={preStyles.checkText}>✓</Text>` with `<Icon name="Check" size={14} color="#fff" strokeWidth={3} />` — no emoji/unicode characters as icons
- [ ] `checkText` style removed from `preStyles` (no longer needed)
- [ ] SettingsScreen switches: `thumbColor` set to `{ false: '#fff', true: '#fff' }` (white always) — verify this was done in Sprint 21 (STORY-00054)
- [ ] FriendsScreen `FriendCard` Switch: `thumbColor` changed from `{ false: Colors.textMuted, true: Colors.primary }` to `{ false: '#fff', true: '#fff' }` — white thumb always per STORY-00054 AC
- [ ] All Switch components across the app verified: `thumbColor` always `'#fff'` (both states)
- [ ] No console errors at 390px viewport
