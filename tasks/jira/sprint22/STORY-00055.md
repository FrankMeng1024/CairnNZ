# STORY-00055: Design Token Consolidation

**Epic**: E-006 UI/UX
**Sprint**: Sprint 22
**Sprint Goal**: Design token hygiene, stat display polish, and icon system consistency
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a developer maintaining the app, I want all color and spacing values to use design tokens from `tokens.ts` instead of hardcoded hex values, so that the design system is consistent and future theme changes only require updating one file.

## Expected Result
Zero hardcoded hex color values (`#3d7ab5`, `#c87941`, `'rgba(93,124,70,*)'`) in screen files — all replaced with named tokens or constants. Running blue and flag orange added to `tokens.ts` as `Colors.running` and `Colors.flag`.

## Acceptance Criteria
- [ ] `Colors.running` token added to `tokens.ts` for the blue running accent (`#3d7ab5`) — replaces all inline `#3d7ab5` usages
- [ ] `Colors.runningLight` token added (`rgba(61,122,181,0.12)`) — replaces all inline running-tinted backgrounds
- [ ] `Colors.flag` token added (`#c87941`) — replaces all inline flag/orange accent usages
- [ ] `Colors.flagLight` token added (`rgba(200,121,65,0.12)`) — replaces all inline flag-tinted backgrounds
- [ ] `Colors.primaryBg` token added (`rgba(93,124,70,0.08)`) — replaces share banner background and other 8% opacity primary usages
- [ ] HomeScreen: all inline color values replaced with tokens
- [ ] RunningScreen: `#3d7ab5` checkBadge background and startBtn background replaced with `Colors.running`
- [ ] FriendsScreen: share banner background replaced with `Colors.primaryBg`
- [ ] No console errors at 390px viewport after changes
