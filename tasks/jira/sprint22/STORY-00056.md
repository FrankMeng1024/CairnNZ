# STORY-00056: Stat Display Quality

**Epic**: E-006 UI/UX
**Sprint**: Sprint 22
**Sprint Goal**: Design token hygiene, stat display polish, and icon system consistency
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user viewing my activity history, I want distance stats and dates to be presented in a human-readable format, and zero-value secondary stats to be hidden, so that the information looks polished rather than raw/technical.

## Expected Result
Session cards show human-readable dates ("Today", "Yesterday", "May 14" format), distance shows "--" or is hidden when 0.0 km, and the secondary stats row (elevation + flags) is hidden when both values are zero.

## Acceptance Criteria
- [ ] `formatDistance` helper: when distance is 0 (exactly 0 or < 10m), return `'--'` instead of `'0.0'`
- [ ] HomeScreen RecentActivityStrip: secondary stats line (`+0m elev · 0 flags`) hidden entirely when both elevation AND flag count are zero
- [ ] HomeScreen QuickStats: km capsule shows `'--'` instead of `'0.0'` when total distance is 0
- [ ] MapHistoryScreen session cards: date display uses human-readable format — "Today", "Yesterday", or "May 14" (not ISO `2026-05-16`)
- [ ] `formatDate` utility function added to `utils/geo.ts` — accepts timestamp, returns human-readable string
- [ ] RecentActivityStrip label: uses `formatDate(last.startedAt)` in the label instead of ISO date string
- [ ] MapHistoryScreen cards: same `formatDate` applied to session date display
- [ ] No regression: sessions with real data (non-zero distance, elevation, flags) display unchanged
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none
