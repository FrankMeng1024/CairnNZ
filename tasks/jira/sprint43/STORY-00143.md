# STORY-00143: Map User Location + GPS Status Indicator

**Epic**: E-002 GPS
**Sprint**: Sprint 43
**Sprint Goal**: Offline tiles + GPS tracking integration
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want to see my current position on the map with a clear indicator, and know when GPS signal is weak.

## Expected Result
Blue pulsing dot on map at user position. Amber "GPS weak" inline bar when accuracy degrades. Status persists across screens.

## Acceptance Criteria
- [ ] UserLocation component shows pulsing blue dot on MapScreen and HikingScreen
- [ ] GPS accuracy monitored: accuracy > 20m triggers "GPS signal weak" amber bar
- [ ] Amber bar appears inline at top (not popup), dismisses when accuracy improves
- [ ] "GPS signal weak" bar uses GlassPanel with amber tint
- [ ] Last known position continues showing when GPS temporarily lost
- [ ] GPS status stored in useTrackingStore (accessible across screens)

## Dependencies
- Depends on: STORY-00137 (MapScreen Mapbox)

## Notes
- expo-location coords.accuracy provides the accuracy reading
- Threshold: < 10m = good, 10-20m = okay, > 20m = weak signal
