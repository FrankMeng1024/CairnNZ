# STORY-00141: Offline Tile Download Manager

**Epic**: E-001 Map
**Sprint**: Sprint 43
**Sprint Goal**: Offline tiles + GPS tracking integration
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want to download map regions for offline use so that I can navigate trails without cellular coverage.

## Expected Result
User can select a region (e.g. "Tongariro"), see estimated size, download tiles, and use the map offline.

## Acceptance Criteria
- [ ] Offline download screen/modal accessible from MapScreen
- [ ] NZ region packs defined in config (at minimum: "Tongariro", "Abel Tasman", "Routeburn")
- [ ] Each pack shows: name, estimated size (MB), zoom levels covered
- [ ] Download progress bar with percentage + bytes completed
- [ ] Download can be paused/resumed/cancelled
- [ ] Downloaded packs listed with status (complete/partial/outdated)
- [ ] Delete pack option with confirmation
- [ ] Map renders from local tiles when offline (verified by airplane mode test)
- [ ] Mapbox offlineManager.createPack used with bounds from regions.ts

## Dependencies
- Depends on: STORY-00136 (Mapbox SDK installed)

## Notes
- Use Mapbox offlineManager API (documented in context7 results)
- Tile count limit: 6000 per pack (Mapbox ToS)
- NZ Tongariro region estimate: ~50-100MB at zoom 10-15
- Store download metadata in AsyncStorage for persistence
