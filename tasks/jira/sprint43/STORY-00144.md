# STORY-00144: Bottom Panel (Peek/Half/Full) for MapScreen

**Epic**: E-001 Map (UX)
**Sprint**: Sprint 43
**Sprint Goal**: Offline tiles + GPS tracking integration
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want a bottom panel that shows nearby markers and route info, pullable to different heights, with glass blur effect.

## Expected Result
Bottom panel with three heights: peek (one line), half (marker list), full (details). Smooth gesture-driven with spring physics.

## Acceptance Criteria
- [ ] Bottom panel component with three snap points: peek(80px), half(H*0.45), full(H*0.85)
- [ ] Gesture-driven (react-native-gesture-handler or PanResponder) with velocity-aware spring
- [ ] GlassPanel styling: blur(16px) + semi-transparent background + inner glow top edge
- [ ] Peek state: shows "X markers nearby" + drag handle
- [ ] Half state: scrollable list of nearby markers (type icon + name + distance)
- [ ] Full state: marker detail or route info (reuses existing MarkerDetailSheet content)
- [ ] Panel does NOT block map interaction when in peek state
- [ ] Drag handle visible and accessible (44pt touch target)
- [ ] Dark mode compatible (dark glass tint)
- [ ] Spring animation on snap (damping: 20, stiffness: 200)

## Dependencies
- Depends on: STORY-00137 (MapScreen), STORY-00140 (GlassPanel)

- Replace current Modal-based MarkerDetailSheet with inline panel for better UX
- Panel content changes with context (per UI_SPEC)
