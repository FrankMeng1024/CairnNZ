## Description
As a user, I want the hiking screen to show a real map with my live GPS position smoothed by the Kalman filter, drawing my track in real time.

HikingScreen displays real Mapbox map, user's smoothed GPS position updates in real time, track polyline draws as user moves.

- [ ] Console: zero errors during tracking start/stop/navigate-away cycle
