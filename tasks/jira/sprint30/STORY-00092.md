# STORY-00092: Create Account — name field auto-focus

**Epic**: E-001 Auth
**Sprint**: Sprint 30
**Sprint Goal**: Elevate date formatting, micro-interaction feedback, and remaining form polish
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new user creating an account, I want the Name field to auto-focus when the Create Account form appears, so I can start typing immediately — consistent with Sign In's email auto-focus.

## Expected Result
Name field has green focus border and keyboard open immediately on Create Account mount.

## Acceptance Criteria
- [ ] Name field on Create Account form has autoFocus=true — green focus border visible on mount without user tap
- [ ] Only Name field auto-focuses (Email, Password, Confirm Password do NOT)
- [ ] Sign In email auto-focus still works correctly (no regression from STORY-00087)
- [ ] Zero console errors

## Dependencies
None.

## Notes
STORY-00087 added autoFocus to FieldInput component. This Story uses the same mechanism — autoFocus={isRegister} on the Name field.
