# STORY-00094: HomeScreen — contextual subtitle variation

**Epic**: E-006 UI/UX
**Sprint**: Sprint 30
**Sprint Goal**: Elevate date formatting, micro-interaction feedback, and remaining form polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a returning user, I want the HomeScreen subtitle to vary contextually by time of day, so the app feels alive and aware rather than always showing the same static question.

## Expected Result
Subtitle cycles through time-of-day-aware variations: morning/afternoon/evening each have different texts. Stable within a session (not random per render).

## Acceptance Criteria
- [ ] At least 5 subtitle variants covering morning (5-11), afternoon (12-17), evening (18-23), and night/late (0-4) periods
- [ ] Selection is deterministic per hour — no render-to-render flicker (use current hour as seed)
- [ ] All subtitle variants fit within 2 lines at 390px viewport width
- [ ] Subtitle uses existing styles.subtitle (no new style definitions)
- [ ] Greeting ("Good morning/afternoon/evening") updates correctly with the subtitle
- [ ] Zero console errors

## Dependencies
None.

## Notes
"Good morning, Explorer" greeting already works. This Story adds contextual subtitle variety to complement it. subtitle pool should be NZ/Global outdoor-themed.
