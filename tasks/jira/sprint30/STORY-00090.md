# STORY-00090: Cross-screen date formatting — human-readable dates

**Epic**: E-006 UI/UX
**Sprint**: Sprint 30
**Sprint Goal**: Elevate date formatting, micro-interaction feedback, and remaining form polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want all dates displayed in a friendly, locale-appropriate format (e.g. "12 May" or "May 12, 2026" for older dates), so the app never shows raw ISO strings.

## Expected Result
RoutesScreen dates show as "12 May" or "Today/Yesterday" — never "2026-05-12".

## Acceptance Criteria
- [ ] RoutesScreen route cards show dates as "D MMM" for current year (e.g. "12 May") and "D MMM YYYY" for previous years — never raw ISO format
- [ ] "Today" and "Yesterday" labels for recent dates — consistent with HomeScreen activity strip behavior
- [ ] A shared `formatDate(dateStr)` utility (or extend existing) handles all cases
- [ ] Zero console errors after navigation to/from RoutesScreen

## Dependencies
None.

## Notes
HomeScreen already uses human-readable dates. RoutesScreen still shows raw ISO (2026-05-12).
