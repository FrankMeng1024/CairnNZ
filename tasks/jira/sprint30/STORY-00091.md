## Description
As a user planting a flag, I want the character counter to warn me at 25 characters so I can self-edit before hitting the 30-char hard cutoff.

## Expected Result
Counter shows: grey (0-24) → amber/orange at 25-29 → red at 30. Focus border stays green until hard limit.

## Acceptance Criteria
- [ ] Char counter uses Colors.warning (amber) when charCount >= 25 AND < 30
- [ ] Char counter uses Colors.danger (red) when charCount >= 30 (existing behavior preserved)
- [ ] Counter color remains grey (Colors.textSecondary) for 0-24 chars
- [ ] Focus border stays green (Colors.primary) during warning state (25-29) — only red at 30/30
- [ ] Counter format remains "N/30" throughout — no layout shift

## Dependencies
None.

Sprint 29 UX review flagged this as Low friction. The transition green→amber→red matches standard form validation patterns.
