# STORY-00093: SettingsScreen — conditional "Tap Save" hint visibility

**Epic**: E-006 UI/UX
**Sprint**: Sprint 30
**Sprint Goal**: Elevate date formatting, micro-interaction feedback, and remaining form polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user browsing Settings, I want the "Tap Save to apply" hint to only appear when I have unsaved changes, so the screen is clean when browsing and informative when I've made changes.

## Expected Result
Hint pill hidden on load. Fades in (200ms) when user changes any setting. Hides again after save.

## Acceptance Criteria
- [ ] "Tap Save to apply" hint pill hidden (opacity 0 / not rendered) when isDirty === false
- [ ] Hint appears (opacity 1, 200ms Animated fade) when user makes any change (mode switch or toggle flip)
- [ ] Hint disappears after successful save (matches Save button inactive state)
- [ ] No layout shift when hint appears/disappears (use Animated.View opacity or absolute positioning)
- [ ] Zero console errors

## Dependencies
None.

## Notes
Currently the hint ArrowUp pill is always visible. isDirty state already exists in SettingsScreen to control the Save button active state — re-use same state for hint visibility.
