# STORY-00122: Google OAuth — Continue with Google

**Epic**: E-001 账号与好友
**Sprint**: Sprint 38
**Sprint Goal**: Complete session sync pipeline + Google OAuth
**Points**: 5
**Owner**: Backend Dev + Frontend Dev
**Status**: In Progress

## Description
As a user, I want to sign in with my Google account so I can access Cairn without creating a separate password.

## Expected Result
"Continue with Google" button on both Sign In and Create Account screens opens Google consent flow. On success, user is logged in and redirected to HomeScreen. If Google email already registered, existing account is returned. New Google users get account created automatically.

## Acceptance Criteria
- [ ] `POST /api/auth/google` accepts `{id_token}`, verifies with Google, returns `{token, user}`
- [ ] Backend creates user if new Google email, or returns existing user if email matches
- [ ] Frontend: "Continue with Google" button triggers Google OAuth via expo-auth-session
- [ ] On success: JWT stored, store updated (isLoggedIn=true, user set), navigate to Home
- [ ] On failure: error shown inline (same pattern as email auth)
- [ ] Works in web preview (localhost:8082)
- [ ] Google Client ID stored in env var, not hardcoded

## Dependencies
- Google OAuth 2.0 Web Client ID stored in `backend/.env` as `GOOGLE_CLIENT_ID` and `app/.env` as `EXPO_PUBLIC_GOOGLE_CLIENT_ID`

## Notes
Client secret stored in `backend/.env` as `GOOGLE_CLIENT_SECRET` (backend only, never sent to frontend).
Token verification: use google-auth-library on backend to verify id_token.
