# STORY-00065: FriendsScreen Visual Depth — Avatar Badges + Row Cards

**Epic**: E-006 UI/UX
**Sprint**: Sprint 24
**Sprint Goal**: RunningScreen route card polish, MapHistoryScreen session card upgrade, FriendsScreen visual depth
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the Friends screen to feel warm and personal — with richer avatar initials, online status indicators, and card-level visual depth rather than a plain list.

## Expected Result
Friend rows have gradient avatar badges, visible online status dots, and the overall list feels like a premium social list (similar to Strava's friend activity feed).

## Acceptance Criteria
- [ ] Friend avatar badge: 44×44 circle with a LinearGradient background (Colors.primaryLight to Colors.primary at 30% opacity) — replaces flat grey circle. Initial letter in Colors.primary, fontWeight 700, FontSize.body
- [ ] Online status dot: 10×10 circle, positioned at bottom-right of avatar. Online = Colors.success (green), Recent (< 1h ago) = Colors.warning (yellow/amber), Inactive = Colors.border (grey) — derived from the existing status text logic
- [ ] Friend row: wrapped in a card-style container with Shadow.card — same card pattern as SettingsScreen toggle rows
- [ ] Shared flags count: "12 shared flags" text gets a small Flag icon (Colors.flag, size 12) to the left — visual context for the number
- [ ] "Add a friend" row: dashed border card uses Colors.primaryLight as background tint (currently pure white) — makes the CTA feel more inviting
- [ ] Header summary pill: "Sharing flags with 3/3 friends" — wrap in a small capsule with Colors.primaryBg background and Colors.primary text — elevates the sharing status to a visible metric
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 23 established gradient icon badges and tinted card backgrounds as the standard visual language. FriendsScreen uses flat grey avatars and plain white rows — inconsistent. The online/offline status indicator is particularly important for the social features of the app.
