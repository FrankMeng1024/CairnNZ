# STORY-00063: RunningScreen Route Cards Visual Polish

**Epic**: E-006 UI/UX
**Sprint**: Sprint 24
**Sprint Goal**: RunningScreen route card polish, MapHistoryScreen session card upgrade, FriendsScreen visual depth
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the RunningScreen route selection cards to feel visually rich and consistent with the rest of the app — with gradient icon badges, clear selection state, and brand-consistent Start button.

## Expected Result
Route cards have gradient icon badges matching the running color palette. The selected card has a clear visual lift (left-border accent or filled bg). The "Start Running" CTA uses brand green (Colors.primary) not blue.

## Acceptance Criteria
- [ ] "Start Running" bottom button: backgroundColor = Colors.primary (green) — currently uses blue (Colors.running), inconsistent with app CTA pattern
- [ ] Route card icon badge: uses a LinearGradient from Colors.runningLight to slightly deeper blue tone — matching the gradient pattern established in HomeScreen activity cards
- [ ] Selected route card: shows a left-border accent (3px, Colors.running) + Colors.runningLight background tint — clear visual selection state
- [ ] Unselected route cards: white/surface background, grey left-border — clear contrast with selected
- [ ] Route card row: route name in FontSize.body/700, distance in FontSize.small/400 Colors.textSecondary — clear hierarchy
- [ ] "Free Run" card icon: uses the target/crosshair icon (already correct) with gradient badge instead of flat color
- [ ] Named route cards: use the route icon (already present) with gradient badge
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 23 established: gradient icon badges are the standard for activity cards. RunningScreen predates this — needs to be brought in line. The blue Start Running button is particularly jarring against the green CTA pattern used on HomeScreen and HikingScreen.
