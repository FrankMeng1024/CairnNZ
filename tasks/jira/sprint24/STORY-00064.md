# STORY-00064: MapHistoryScreen Session Cards — Activity Badge + Visual Hierarchy

**Epic**: E-006 UI/UX
**Sprint**: Sprint 24
**Sprint Goal**: RunningScreen route card polish, MapHistoryScreen session card upgrade, FriendsScreen visual depth
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the route history session cards to feel like polished session summaries — with activity type badges matching the HomeScreen RecentActivityStrip pattern, not plain "Run · Today" text rows.

## Expected Result
Session cards in the bottom panel have the same visual quality as the RecentActivityStrip: activity type pill badge, bold primary stat, muted secondary line. The map placeholder also gets a premium look consistent with HikingScreen.

## Acceptance Criteria
- [ ] Session card header: activity type pill badge ("Run"/"Hike", same style as RecentActivityStrip — Colors.running bg at 15% opacity + Colors.running text for Run; Colors.primary at 15% for Hike) replacing the plain "Run · Today" text
- [ ] Session card primary stat: show duration in FontSize.body/700 as the primary info line (e.g. "00:32") — currently shows "Run · Today" which is not a stat
- [ ] Session card secondary line: "Today · -- km" in FontSize.small/400 Colors.textSecondary — date and distance
- [ ] Session card left icon: 40×40 rounded badge with gradient (runningLight→deeper for Run, primaryLight→deeper for Hike) — matches HomeScreen activity card icon style
- [ ] Session card expanded state (tapped): stat grid (km, time, elev, flags) retains current layout but stat values use FontSize.h3/700 for numbers and FontSize.tiny/600 for labels
- [ ] Map placeholder area (the sage-green zone above the bottom panel): show "Route Map" label and "Select a route below to view" subtitle — currently has a warning triangle icon which looks like an error
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: none
- Blocks: none

## Notes
The warning triangle (⚠️) in the map placeholder area is jarring — looks like an error state. Should be replaced with the same topo-style illustration pattern from HikingScreen or a simpler route-line illustration. The session cards lack the visual language established by RecentActivityStrip in Sprint 23.
