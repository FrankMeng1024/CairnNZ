# STORY-00066: Cross-Screen Typography & Spacing Consistency Pass

**Epic**: E-006 UI/UX
**Sprint**: Sprint 24
**Sprint Goal**: RunningScreen route card polish, MapHistoryScreen session card upgrade, FriendsScreen visual depth
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want every screen to feel like it belongs to the same premium app — with consistent heading sizes, spacing rhythm, and back-button treatment.

## Expected Result
All screens use the same top-bar pattern, heading hierarchy, and spacing as established by HomeScreen and SettingsScreen. No screen feels like a different generation.

## Acceptance Criteria
- [ ] RunningScreen top bar: "Running Mode" title uses FontSize.h3/700 (same as SettingsScreen "Settings" title) — currently uses a larger custom size that feels oversized relative to the top bar
- [ ] RunningScreen subtitle "Select a route (optional)": uses FontSize.small/400 Colors.textSecondary — currently appears as body-size text
- [ ] MapHistoryScreen tabs (Routes/Flags): selected tab uses Colors.primary text + Colors.primaryBg background pill — creates a clear selected state (currently selected is just bold/white)
- [ ] MapHistoryScreen top bar: "Route Map" title aligns with other screen title sizes (FontSize.h3/700)
- [ ] FriendsScreen "Add" button in top bar: uses same pill style as SettingsScreen "Save" button (bg=Colors.primary, white text, borderRadius=Radius.pill)
- [ ] All screen top bars: consistent padding (paddingHorizontal=Spacing.base, paddingVertical=Spacing.sm) — verify RunningScreen and MapHistoryScreen match HomeScreen/SettingsScreen
- [ ] No console errors at 390px viewport

## Dependencies
- Depends on: STORY-00063 (RunningScreen changes may touch same file)
- Blocks: none

## Notes
Systematic typography audit across all screens. These are micro-corrections that compound into a sense of polish. The RunningScreen "Running Mode" h1-sized title vs the more restrained h3 approach on all other screens is the most visible inconsistency.
