# STORY-00202: GPS pipeline correctness

**Epic**: Sprint 55 Hotfix
**Sprint**: Sprint 55
**Points**: 5
**Owner**: Frontend Dev
**Status**: In Progress

## Description
Real-device telemetry log (mpdk44cd) shows 94 `gps_fix` events for only 54 unique timestamps — every fix logged ~1.7×. Foreground watcher and background drain loop both fire on the same GPS sample. Coord-based dedupe (1e-6) too loose. Result: hike distance counted ~1.7×, GPS appears to "drift forward and back" on the map. Plus: running timer "double jumps", running screen shows "Real Map (EAS Build)" placeholder instead of Mapbox tiles, and double-tap-pause does not drop a flag pin.

## Acceptance Criteria
- [ ] AC1: 200m closed-loop hike yields distance within ±10% of ground truth (was ~3×)
- [ ] AC2: Running timer matches wall clock to within 1s over a 60s observation
- [ ] AC3: Backgrounding for 30s mid-hike → foreground → no duplicate timestamps in track, continuous polyline
- [ ] AC4: Running double-tap pause drops a flag pin at current location, persists in saved session
- [ ] AC5: Pre-run screen shows real Mapbox tiles (not the "Real Map (EAS Build)" placeholder)
- [ ] AC6 (test): Jest unit test for `addTrackPoint` timestamp-based dedupe (pure function)
- [ ] AC7 (test): Jest unit test for AppState-based source switching (single-source guarantee)

## Notes
**Root causes**:
1. `useTrackingStore.ts` runs both foreground `watchPositionAsync` AND background drain loop simultaneously. Same GPS sample logged 3× (foreground + background path × 2 source labels)
2. Coord-based dedupe `Math.abs(diff) < 1e-6` is ~10cm tolerance — GPS noise easily exceeds this
3. RunningScreen `try { require('@rnmapbox/maps') }` happens at module top-level → Hermes lazy mode returns undefined → fallback placeholder always renders
4. No `pausePins` state — pause action just sets status='paused' with no spatial marker

**Files**:
- `app/src/store/useTrackingStore.ts`
- `app/src/screens/RunningScreen.tsx`
- `app/src/screens/HikingScreen.tsx`

**Strategy**:
- Add `lastFixTimestamp` field; dedupe on `position.timestamp` (with fallback: same timestamp BUT > 5m apart still kept)
- Subscribe to AppState; while `active` use foreground watcher, while `background/inactive` use background updates — never both
- Add `pausePins: Coordinate[]` to store; render on map
- Move `require('@rnmapbox/maps')` into component-mount `useState` initializer
