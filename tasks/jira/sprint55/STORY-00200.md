# STORY-00200: Restore real-user auth + persist data on native

**Epic**: Sprint 55 Hotfix
**Sprint**: Sprint 55
**Sprint Goal**: Ship one EAS build that fixes 23 real-device bugs
**Points**: 3
**Owner**: Frontend Dev
**Status**: In Progress

## Description
As a real user, I want to actually have to sign in (instead of being auto-logged-in as `pw@cairn.nz`), and I want my activities/sessions to persist across app restarts so my data isn't lost every time I close the app.

## Expected Result
- Fresh install → AuthScreen, NOT HomeScreen
- After signing in with real account → kill app → reopen → still signed in
- Sessions saved during a hike persist after app restart
- Dev workflow (`expo start`) still has Playwright bypass available via `.env.development`

## Acceptance Criteria
- [ ] AC1: Fresh install lands on Sign In screen (not HomeScreen) when no auth token exists
- [ ] AC2: After real signin, force-killing the app and relaunching lands on HomeScreen with the previous user
- [ ] AC3: Sessions saved on Run #1 are visible after relaunch
- [ ] AC4: With `.env.development` containing `EXPO_PUBLIC_PLAYWRIGHT_BYPASS=true`, running `expo start` still bypasses auth (dev parity preserved)
- [ ] AC5 (test): Jest unit test for `storage.ts` round-trip on both web (localStorage) and native (AsyncStorage mock)
- [ ] AC6 (test): Playwright test that fresh load goes to AuthScreen, login → reload → still on HomeScreen

## Dependencies
- Blocks: STORY-00201 (Crash fixes — Sign Out lives in Settings, depends on auth flow being real)

## Notes
**Root cause analysis**:
- `.env` line 4: `EXPO_PUBLIC_PLAYWRIGHT_BYPASS=true` was committed and gets baked into every production build
- `useAppStore.ts:97-102`: bypass branch returns `isLoggedIn: true` with fake user `{ id: '0', name: 'Playwright', email: 'pw@cairn.nz' }`
- `storage.ts:7-20`: `isWeb` check → native paths are no-ops, so AsyncStorage was never used despite being installed in package.json (`@react-native-async-storage/async-storage@^3.0.2`)

**Files to modify**:
- `app/.env` — remove EXPO_PUBLIC_PLAYWRIGHT_BYPASS=true line
- `app/.env.development` — new file with bypass for dev only
- `app/src/store/useAppStore.ts` — guard bypass with `__DEV__ &&`
- `app/src/store/storage.ts` — implement native branch with AsyncStorage

**Risk**: AsyncStorage is async-only on native; storage.ts API is already async (returns Promise) so call sites compile unchanged.
