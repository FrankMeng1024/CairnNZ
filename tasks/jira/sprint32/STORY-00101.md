# STORY-00101: RoutesScreen download — premium overlay sheet

**Epic**: E-006 UI/UX
**Sprint**: Sprint 32
**Sprint Goal**: UI polish — pending items from Sprint 28-31 retros
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user tapping the Download button on a route card, I want a premium bottom sheet overlay (not a system Alert) that explains the download option and invites me to upgrade, matching the premium locked-state UI of other screens.

## Expected Result
Tapping Download on a route card dismisses the system Alert and instead shows a premium Modal bottom sheet: blurred/semi-transparent background, app icon or Lock illustration, "Download for Offline Use" title, short description, "Upgrade to Premium" CTA button (Colors.primary), and a close handle. Sheet uses Shadow.overlay, Radius.cardLg on top corners.

## Acceptance Criteria
- [ ] Tapping Download no longer triggers a system Alert.alert()
- [ ] A Modal bottom sheet appears with: drag handle, title "Download for Offline Use", one-line description, "Upgrade to Premium" button (Colors.primary, Radius.pill)
- [ ] "Upgrade to Premium" button is pressable and dismisses the sheet (no navigation required — just dismiss for now)
- [ ] Sheet has close button (X icon) in top-right OR close on backdrop tap
- [ ] Sheet uses Shadow.overlay elevation style
- [ ] Sheet background is Colors.surface (white), top corners rounded (Radius.cardLg)

## Dependencies
- None

## Notes
Currently RoutesScreen shows Alert.alert('Coming Soon', ...) for Download. This is a system modal with no premium feel.
