# STORY-00103: MapHistoryScreen route visualization premium uplift

**Epic**: E-006 UI/UX
**Sprint**: Sprint 32
**Sprint Goal**: UI polish — pending items from Sprint 28-31 retros
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user reviewing a past session in MapHistoryScreen, I want the "View on Map" section to show a premium map preview card (with stat overlays) rather than just a button, so I can preview my route before tapping.

## Expected Result
The expanded session card's map area shows a stylized route preview card: topo/terrain background placeholder (Colors.primaryBg tint with subtle grid), route path drawn as an SVG polyline (or simplified path from waypoints), stat overlays in rgba chip style (distance, duration, elevation), "View on Map" as a full-width CTA below the preview area. Shadow.card elevation on the preview card.

## Acceptance Criteria
- [ ] Expanded session card shows a route preview area (min height 120px) above the "View on Map" button
- [ ] Preview area has topo/terrain background style (Colors.primaryBg, subtle opacity grid lines or contour hint — same pattern as MapScreen Sprint 31 placeholder)
- [ ] At least 2 stat chips overlaid on the preview (distance + duration) in rgba(255,255,255,0.9) pill style
- [ ] "View on Map" is a full-width green CTA button (Colors.primary) below the preview, not just a text link
- [ ] Preview card has Shadow.card elevation
- [ ] Layout does not overflow or clip on 375px viewport

## Dependencies
- None

## Notes
MapHistoryScreen currently has `viewOnMapBtn` / `viewOnMapText` styles at line ~224. The route preview placeholder pattern is established in MapScreen Sprint 31 (topoPlaceholder style).
