# STORY-00104: AuthScreen Create Account form parity with Sign In

**Epic**: E-006 UI/UX
**Sprint**: Sprint 32
**Sprint Goal**: UI polish — pending items from Sprint 28-31 retros
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new user creating an account, I want the Create Account form to feel as polished as the Sign In form — consistent input focus states, proper error messaging timing, and the Name field onBlur validation to feel welcoming rather than punitive.

## Expected Result
Create Account form: Name field validation fires only on form submit (not on blur-without-input), password confirmation field has same focus ring as Sign In password field, all inputs share identical border/focus/error token usage, form has smooth entrance animation matching Sign In.

## Acceptance Criteria
- [ ] Name field does NOT show error state when user tabs through without typing (onBlur validation removed for Name field; validation only on submit attempt)
- [ ] Password confirmation input has identical focus ring to Sign In password input (Colors.primary border on focus)
- [ ] All Create Account inputs use same focus/error token pattern as Sign In inputs (verified visually — matching border radius, padding, font size)
- [ ] Create Account form has same card entrance animation as Sign In (fadeIn/slideUp, matching Sprint 21 pattern)

## Dependencies
- None
