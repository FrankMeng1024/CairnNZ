# STORY-00127: User Profile — GET /api/users/me + Profile in Settings

**Epic**: E-001 账号与好友
**Sprint**: Sprint 37
**Sprint Goal**: User data ownership — sessions stored per user account
**Points**: 2
**Owner**: Backend Dev + Frontend Dev
**Status**: Done

## Description
As a logged-in user, I want to see my profile (name, email) in the Settings screen.

## Expected Result
Settings screen shows the user's name and email when logged in. A "Not logged in" state is shown when no session exists.

## Acceptance Criteria
- [ ] `GET /api/users/me` (alias of `/api/auth/me`) returns `{user: {id, name, email}}` — already exists; ensure it is documented in API_SPEC.md
- [ ] Settings screen: Profile section shows `{name}` and `{email}` when `isLoggedIn` is true
- [ ] Profile section shows "Sign in to save your data" CTA when not logged in
- [ ] Profile section is the first section in Settings (above existing items)
- [ ] Logout button in Settings clears JWT and returns to AuthScreen (existing STORY-00095 logout — verify still functional)
- [ ] All states verified at 390px

## Dependencies
- None (auth/me endpoint already exists)

## Notes
Profile data available from Zustand `useAppStore.user` set during login/register/getMe.
No additional backend endpoint needed — use existing state.
