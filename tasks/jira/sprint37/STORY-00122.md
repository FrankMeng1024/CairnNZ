# STORY-00122: Google OAuth via expo-auth-session (moved from Sprint 35)

**Epic**: E-001 账号与好友
**Sprint**: Sprint 37 (moved from Sprint 36 — requires Google Cloud Console Client ID from user)
**Sprint Goal**: Live auth — MySQL running, real register/login E2E working, Google OAuth wired
**Points**: 5
**Owner**: Frontend Dev + Backend Dev
**Status**: Todo

## Description
As a user, I want to sign in with my Google account so that I don't need to create and remember a new password.

## Expected Result
"Continue with Google" button initiates real Google OAuth flow. On success, backend creates/finds user and returns Cairn JWT. User is logged in and navigated to Home.

## Acceptance Criteria
- [ ] `expo-auth-session` and `expo-web-browser` installed
- [ ] Google Cloud Console project created with OAuth 2.0 Web Client ID configured
- [ ] Google Client ID stored in env var `EXPO_PUBLIC_GOOGLE_CLIENT_ID` (not hardcoded)
- [ ] Backend `POST /api/auth/google` endpoint: accepts Google `id_token`, verifies with Google API, creates/finds user in DB, returns `{token, user:{id,name,email}}`
- [ ] Frontend `authService.ts` has `loginWithGoogle()` function calling `/api/auth/google`
- [ ] "Continue with Google" button on Sign In screen initiates real OAuth flow
- [ ] "Continue with Google" button on Create Account screen uses same flow
- [ ] On success: JWT stored, user profile set, navigate to Home
- [ ] On cancel/error: user stays on auth screen, no crash, no error banner unless actual error
- [ ] Verified in web preview (localhost:8082) with real Google account

## Dependencies
- Blocked by STORY-00121 (needs running backend + DB)
- Requires Google Cloud Console setup (user must provide Client ID)

## Notes
Google Cloud Console: https://console.cloud.google.com/
Create project → Credentials → OAuth 2.0 Client IDs → Web application
Authorized JavaScript origins: http://localhost:8082
Authorized redirect URIs: http://localhost:8082 + Expo proxy if testing in Expo Go
