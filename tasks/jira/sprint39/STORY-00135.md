## Description
As a first-time user, I want the app's opening animation to feel like reaching a mountain summit and planting a flag — conveying the adventure and achievement spirit of Cairn.

## Expected Result
The splash screen animates in sequence:
1. A curved trail path draws itself from bottom to top (SVG stroke-dashoffset animation)
2. The cairn stones stack from bottom to top with spring physics (existing)
3. A small flag/pennant plants at the top of the cairn with a bounce + subtle particle dust
4. The "Cairn" wordmark fades in with slight upward slide
5. The tagline lines appear with stagger
Total animation: ~1.8s, feels premium and purposeful

## Acceptance Criteria
- [ ] Trail path SVG draws from bottom to top over ~500ms (stroke animation)
- [ ] Cairn stones stack with existing spring animation (unchanged timing)
- [ ] Flag element appears at top of cairn after stones complete — bounces once with spring (toValue=1, overshoot ~15%)
- [ ] Flag is a simple pennant shape (triangle, 16×12px, primary green) rendered as SVG/View
- [ ] Subtle particle: 4–6 small dots (3px circles, opacity fade from 0.8→0) scatter outward from flag plant point over 400ms
- [ ] "Cairn" wordmark: fade + translateY(-8→0) over 300ms, starts 200ms after stones complete
- [ ] Tagline lines stagger 80ms apart, same fade+slide pattern
- [ ] Total animation completes ≤ 2000ms from mount
- [ ] Animation runs only once on mount (no loop)
- [ ] Performance: all animations use `useNativeDriver: true` where possible (transform/opacity only)
- [ ] No external animation library added (pure Animated API + SVG)
