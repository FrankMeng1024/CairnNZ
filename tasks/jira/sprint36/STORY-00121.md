# STORY-00121: MySQL Setup + Backend Live Auth E2E

**Epic**: E-001 账号与好友
**Sprint**: Sprint 36
**Sprint Goal**: Live auth — MySQL running, real register/login E2E working, Google OAuth wired
**Points**: 5
**Owner**: Backend Dev
**Status**: Done

## Description
As a developer, I need MySQL installed and the backend running against a real database, so that register/login/JWT-skip-auth can be verified end-to-end.

## Expected Result
MySQL server running locally. Backend starts cleanly (`/health` returns `{status:"ok",db:"ok"}`). Register creates a user in the DB. Login returns a real JWT. App launch with stored JWT skips AuthScreen.

## Acceptance Criteria
- [ ] MySQL 8 installed and running on localhost:3306
- [ ] `backend/src/migrations/001_init.sql` executed — `cairn` database and `users` table created
- [ ] `backend/.env` configured with correct DB credentials
- [ ] `GET /health` returns `{status:"ok", db:"ok"}` (not "degraded")
- [ ] `POST /api/auth/register` with `{name, email, password}` returns `{token, user:{id,name,email}}` (201)
- [ ] `POST /api/auth/login` with correct credentials returns `{token, user}` (200)
- [ ] `POST /api/auth/login` with wrong password returns 401
- [ ] `POST /api/auth/register` with duplicate email returns 409
- [ ] `GET /api/auth/me` with valid Bearer token returns current user
- [ ] Frontend: register via Create Account form → JWT stored → navigates to Home (real session)
- [ ] Frontend: app re-launch with stored JWT → skips AuthScreen, goes directly to Home
- [ ] Frontend: Sign Out → JWT cleared → returns to AuthScreen, next launch shows AuthScreen

## Dependencies
- Requires MySQL installation on dev machine

## Notes
MySQL installer: https://dev.mysql.com/downloads/mysql/ or via winget `winget install Oracle.MySQL`.
Run migration: `mysql -u root -p < backend/src/migrations/001_init.sql`
Start backend: `cd backend && node src/index.js`
