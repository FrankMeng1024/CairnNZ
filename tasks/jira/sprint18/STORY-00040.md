# STORY-00040: HomeScreen — Recent activity strip

**Epic**: E-006 UI/UX
**Sprint**: Sprint 18
**Sprint Goal**: Flag drag UX + Home activity strip + UI polish
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a returning user, I want to see my most recent activity (last hike/run) on the Home screen, so that the app greets me with context about my last session.

## Expected Result
If the user has completed at least one tracking session, a compact "Last activity" strip appears below the greeting header and above the activity cards. Shows: activity type icon, name/date, distance, duration. Tapping navigates to MapHistory. If no sessions, strip is hidden (no empty state shown here).

## Acceptance Criteria
- [ ] Strip is hidden when no sessions in useSessionStore
- [ ] Strip shows when ≥1 session exists: activity type icon (Mountain or PersonStanding), session name or "Hike · YYYY-MM-DD", distance in km (1 decimal), duration formatted
- [ ] Strip background uses Colors.surface with 1px Colors.border and Shadow.card
- [ ] Tapping the strip navigates to MapHistory screen
- [ ] Strip appears between the header and the cards section with correct spacing
- [ ] No console errors
- [ ] Verified at 390px viewport

## Dependencies
None (reads from useSessionStore which is already wired)

## Notes
Read sessions via `useSessionStore(s => s.sessions)` — stable selector, no function calls inside.
Sort by startedAt descending, take sessions[0].
