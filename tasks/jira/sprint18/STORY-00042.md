# STORY-00042: RunningScreen — lock screen polish + live stats improvement

**Epic**: E-005 Running Mode
**Sprint**: Sprint 18
**Sprint Goal**: Flag drag UX + Home activity strip + UI polish
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a runner with the screen locked, I want the lock state to feel purposeful and premium — showing clear stats and a confident visual that I'm being tracked — so the app rivals Strava's lock screen quality.

## Expected Result
When running state = 'running' and locked, the lock screen shows: large primary metric (distance or elapsed time), secondary metrics row (pace, elapsed), a pulsing GPS indicator dot, and "Double-tap to unlock" hint. The overall feel is dark-overlay with large text — confident and legible at a glance.

## Acceptance Criteria
- [ ] Lock state background is a dark semi-transparent overlay (rgba(0,0,0,0.88)) covering the full screen
- [ ] Primary stat: elapsed time in H:MM:SS format, font size ≥ 56px, white, centred
- [ ] Secondary row: distance (km, 2 decimal), pace (min/km) — both below primary, white, fontSize 20px
- [ ] GPS pulsing indicator: green dot with repeating scale animation (0.8→1.2→0.8, 2s loop)
- [ ] "Double-tap to unlock" hint text at bottom, muted white
- [ ] Existing double-tap unlock gesture still works
- [ ] Stats update live every second while locked
- [ ] No console errors
- [ ] Verified at 390px viewport
