# STORY-00039: AR Flag Picker — Drag-from-corners interaction

**Epic**: E-003 Marker System
**Sprint**: Sprint 18
**Sprint Goal**: Flag drag UX + Home activity strip + UI polish
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a hiker in AR flag mode, I want to drag a flag type from a corner to the centre drop zone to plant it, so that the interaction matches the design spec and feels more intentional than a tap.

## Expected Result
In the AR flag picker (HikingScreen state 3), each corner flag type can be dragged to the centre drop zone. On successful drop, the plant flow triggers (note sheet). Tapping the corner still works as fallback. Dragging back to corner = cancel.

## Acceptance Criteria
- [ ] Each corner flag type responds to PanResponder drag gesture
- [ ] A visible drop zone is shown in the centre of the AR view with a dashed border and "Drag flag here" label
- [ ] When dragged into the drop zone bounds, the drop zone highlights (border becomes solid primary colour)
- [ ] Releasing inside the drop zone triggers onPlant() — proceeds to note sheet
- [ ] Releasing outside the drop zone returns the flag tile to its corner (spring animation)
- [ ] Tapping a corner flag still triggers plant (touch fallback preserved for accessibility)
- [ ] Cancel button still visible and functional
- [ ] No console errors during drag/drop interaction
- [ ] Verified at 390px viewport

## Dependencies
None
