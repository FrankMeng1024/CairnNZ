# STORY-00041: HikingScreen map — topo art placeholder

**Epic**: E-006 UI/UX
**Sprint**: Sprint 18
**Sprint Goal**: Flag drag UX + Home activity strip + UI polish
**Points**: 3
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user on the HikingScreen before tracking starts, I want to see a visually rich map-style placeholder that makes the app feel professional and trail-focused, instead of the current plain grid.

## Expected Result
The map area background is replaced with a topo-style SVG art pattern — concentric elevation rings, trail dotted lines, NZ mountain silhouette — rendered via React Native SVG or pure View/StyleSheet geometry. Quality comparable to AllTrails offline map placeholder.

## Acceptance Criteria
- [ ] Map area shows topo-style visual: at minimum 3 concentric elevation ring arcs, 1 dotted trail line, muted green palette (#d4e8c2, #bfda9f, #e8f0e0)
- [ ] "Trail Map" label and "Real map loads with offline pack" sub-label still visible, centred
- [ ] GPS chip, Back chip, Start Hiking button all remain functional and correctly positioned
- [ ] Marker pins still render correctly on top of the new background
- [ ] Visual is purely decorative — no interaction needed
- [ ] No console errors
- [ ] Verified at 390px viewport

## Dependencies
None

## Notes
Implement with React Native View + BorderRadius + absolute positioning for rings. No external SVG library needed if using View geometry.
Keep file self-contained — no new files required.
