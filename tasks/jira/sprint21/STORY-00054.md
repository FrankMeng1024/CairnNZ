# STORY-00054: Cross-Screen Micro-Interactions

**Epic**: E-006 UI/UX
**Sprint**: Sprint 21
**Sprint Goal**: AuthScreen premium redesign + cross-app micro-interaction polish
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user navigating across all screens, I want consistent micro-interactions — gradient icon badges, uniform toggle styling, expandable session cards, and a shimmer on the save button — so the app feels cohesive and responsive to my actions.

## Expected Result
Activity icon badges use subtle gradients, all Switch toggles share consistent colors, MapHistoryScreen cards expand inline before navigation, and the Settings save button shimmers when it becomes active.

## Acceptance Criteria
- [ ] HomeScreen activity cards (Hiking/Running): icon badge area uses a subtle linear gradient background (top-to-bottom, primary color at 20% opacity to transparent) instead of flat solid color
- [ ] Gradient is implemented via LinearGradient (expo-linear-gradient) or equivalent — not an image asset
- [ ] All Switch/toggle components across the app (SettingsScreen, FriendsScreen sharing toggles, any others) use identical track colors: active track = theme accent color, inactive track = #E0E0E0 (light) / #555 (dark)
- [ ] All Switch thumb colors are consistent: white (#FFF) regardless of state
- [ ] MapHistoryScreen: tapping a session card first expands it inline (animated height expansion, ~200ms) to reveal full stats (duration, distance, elevation, flags) — a second tap or "View on Map" button navigates to detail
- [ ] Expanded card shows a "View on Map" pill button at the bottom of the expanded area
- [ ] Only one card can be expanded at a time — tapping another card collapses the first
- [ ] Settings: "Save" button has a subtle shimmer animation (moving highlight gradient left-to-right, loop, duration ~2s) that activates ONLY when unsaved changes exist
- [ ] When no changes exist, Save button is static (no shimmer) and visually muted (opacity 0.5 or grey text)
- [ ] Shimmer stops immediately when changes are saved (onPress saves and clears dirty state)
- [ ] No console errors across all affected screens at 390px viewport
- [ ] FAB badge on HikingScreen: if marker count is 0, badge is hidden entirely (fixes Sprint 20 gap — "1" badge was confusing)

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 20 retro gaps addressed: (1) FAB badge "1" showing when unclear — now hidden at 0; (2) cross-screen toggle inconsistency. The expandable card on MapHistoryScreen reduces jarring full-screen transitions for quick stats review.
