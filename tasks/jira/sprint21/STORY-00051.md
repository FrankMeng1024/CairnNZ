# STORY-00051: AuthScreen Premium Redesign

**Epic**: E-006 UI/UX
**Sprint**: Sprint 21
**Sprint Goal**: AuthScreen premium redesign + cross-app micro-interaction polish
**Points**: 6
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new user opening the app for the first time, I want the authentication screen to feel premium and trustworthy — a polished cairn animation, clear form fields with inline validation, and an unambiguous privacy consent row — so that I feel confident creating an account.

## Expected Result
AuthScreen has an animated cairn logo with subtle glow pulse on first load, larger premium pill-shaped entry buttons with icons, a visible Name field in registration, clearly separated privacy checkbox from policy link, inline field validation errors, and properly branded social login buttons.

## Acceptance Criteria
- [ ] Cairn logo renders a soft glow/pulse animation on first load (opacity oscillation 0.6-1.0, duration ~2s, runs once then holds at full opacity)
- [ ] "Create Account" and "Sign In" entry buttons are pill-shaped (borderRadius >= 24), minimum height 52px, include leading icon (UserPlus for Create, LogIn for Sign In)
- [ ] Registration form includes a visible "Name" text input field above the Email field
- [ ] Privacy policy row layout: checkbox square (left) + "I agree to the" text + tappable "Privacy Policy" underlined link (distinct tap target from checkbox)
- [ ] Tapping the "Privacy Policy" link text opens the policy modal/sheet; tapping the checkbox toggles consent state — these are independent actions
- [ ] Form validation: submitting with empty required fields shows red inline error text directly below each invalid field (not a toast, not an alert)
- [ ] Email field validates format on blur — invalid shows "Please enter a valid email" below the field
- [ ] Password field shows "Minimum 6 characters" hint when focused, shows error on blur if < 6 chars
- [ ] Social login buttons (Apple/Google) use brand-appropriate styling: Apple = black background + white Apple icon, Google = white background + Google "G" multicolor icon + border
- [ ] No console errors on AuthScreen at 390px viewport
- [ ] All animations use Animated API (no Reanimated dependency unless already present)

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 20 retro flagged the privacy checkbox confusion — users could not distinguish checkbox toggle from policy link tap. This story addresses that directly. The Name field was removed in an earlier sprint to simplify but users expect it for personalization.
