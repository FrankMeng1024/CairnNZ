# STORY-00052: HomeScreen Empty State + Onboarding Touch

**Epic**: E-006 UI/UX
**Sprint**: Sprint 21
**Sprint Goal**: AuthScreen premium redesign + cross-app micro-interaction polish
**Points**: 4
**Owner**: Frontend Dev
**Status**: Done

## Description
As a brand new user with no hiking data, I want the home screen empty state to feel alive and guide me on what to do next — with a subtle animated mountain icon and a clear "how it works" section — so I understand the app's value immediately without feeling lost.

## Expected Result
Empty state card has a pulsing mountain icon animation, a 3-step "how it works" onboarding row, and the greeting says "Welcome to Cairn" instead of the mode-based greeting when there is no data.

## Acceptance Criteria
- [ ] When hasData=false: mountain icon in empty state card plays a subtle pulse animation (scale 1.0 to 1.05, loop, duration ~3s, easing: ease-in-out)
- [ ] Below the empty state card: a "How it works" row with 3 mini-step items displayed horizontally
- [ ] Step 1: Flag icon + "Plant flags" label; Step 2: Users icon + "Share with friends" label; Step 3: Compass icon + "Guide others" label
- [ ] Each step item has a small circular icon container (size ~40px) with the app's accent color background at 15% opacity
- [ ] When hasData=false: greeting text reads "Welcome to Cairn" regardless of time of day or uiMode setting
- [ ] When hasData=true: greeting continues to show time-based + mode-based greeting as before (no regression)
- [ ] "How it works" row is only visible when hasData=false — hidden once user has session or marker data
- [ ] No console errors; 390px viewport verified
- [ ] Pulse animation does not cause layout shift (uses transform only, not width/height)

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 20 retro noted the greeting showing "Good evening, Explorer" to a brand new user feels odd — they have no identity yet. "Welcome to Cairn" is warmer for first-time empty state.
