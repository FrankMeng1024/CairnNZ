# STORY-00053: Running Screen Pre-Start UX

**Epic**: E-006 UI/UX
**Sprint**: Sprint 21
**Sprint Goal**: AuthScreen premium redesign + cross-app micro-interaction polish
**Points**: 5
**Owner**: Frontend Dev
**Status**: Done

## Description
As a runner selecting a route before starting, I want clear visual feedback on which card is selected, a centered lock hint, and a share/save option after completing a run — so the selection state is unambiguous and I can capture my achievement.

## Expected Result
Selected route/free-run card shows a green left border accent, lock hint text is center-aligned with a lock icon, and the post-run summary screen includes a share/save button.

## Acceptance Criteria
- [ ] Selected card (Free Run or any route card) displays a 3px solid green (#4CAF50 or theme accent-green) left border — unselected cards have no left border or a transparent one
- [ ] The check badge (existing) remains as secondary indicator; left border is the primary visual selection cue
- [ ] Lock hint text ("Double-tap to unlock") is center-aligned horizontally within the lock overlay
- [ ] Lock hint text is preceded by a Lock icon (inline, same color as text, size ~16px)
- [ ] After run completes (stopped state / summary view): a "Share" button is visible (Share icon + "Share" label)
- [ ] Share button is a pill-shaped outlined button (borderRadius >= 20, border 1px theme color)
- [ ] Tapping Share button triggers the platform share sheet (Expo Sharing API or equivalent) with run summary text: "I completed a [distance] run on Cairn!"
- [ ] If sharing is unavailable on platform, Share button is hidden (not disabled/greyed)
- [ ] No console errors on RunningScreen at 390px viewport
- [ ] Green left border uses borderLeftWidth + borderLeftColor (not a separate View element for performance)

## Dependencies
- Depends on: none
- Blocks: none

## Notes
Sprint 20 identified that Free Run and route cards look identical when selected except for the small check badge — users scan cards quickly and need a stronger affordance. The share feature addresses post-run delight.
