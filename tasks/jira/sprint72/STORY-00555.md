# STORY-00555: Hiking 中主动续 token

**Epic**: E-Auth · **Sprint**: 72 · **Points**: 2 · **Owner**: Frontend · **Status**: Done

## Description
When the user is actively hiking, silently refresh the token every 30 minutes so an 8-hour hike never crosses a token boundary and gets kicked to login mid-trail.

## 依赖
- STORY-00550（refresh endpoint 存在 + 铁律：refresh 失败绝不清 token）

## 改动
1. `useTrackingStore.startTracking()` 成功后 start `tokenRefreshInterval`（30 分钟）
2. Interval callback:
   - `useAppStore.getState().isLoggedIn === true`
   - 调用 `refreshToken()` (from authService)
   - 结果只 breadcrumb，绝不 clearToken 或 logout（走 STORY-00550 铁律）
3. `stopTracking()` clear interval
4. AppState=background 时 interval 保留（tracking 中）

## Breadcrumbs
- `hiking_refresh:start`
- `hiking_refresh:success`
- `hiking_refresh:fail reason=<>`
