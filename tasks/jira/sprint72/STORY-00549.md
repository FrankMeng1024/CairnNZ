# STORY-00549: 冷启动 auto-login + 注销硬清

**Epic**: E-Auth · **Sprint**: 72 · **Points**: 3 · **Owner**: Frontend · **Status**: Done

## Description
As a returning user, I want to open the app and immediately see my map without re-entering my password, so that the app feels like it "remembers me" the way Strava/AllTrails do.

## 现状根因
`app/src/store/useAppStore.ts:117-186` 的 hydrate 显式注释："The user must always go through the Sign In screen on a cold start, even if a JWT is still valid in storage." 即使 `getMe()` 返回有效 user，也只 `set({ user })` 不 `setLoggedIn(true)`。这是设计，不是 bug。改设计。

## 改动
1. `useAppStore.ts` hydrate 分支重写:
   - `getMe()` returns valid user + 无"注销标记" → `set({ isLoggedIn: true, user, hydrated: true })`
   - `getMe()` returns null (token invalid/expired) → `set({ user: null, hydrated: true })` → AuthScreen
   - `getMe()` throws (network timeout) → **保留 token**，`set({ user: null, hydrated: true })` → AuthScreen（此时用户可选择"离线继续"或重登）
   - 有"注销标记" `cairn_logout_marker=1` → 强制 AuthScreen（不 auto-login）
2. `authService.logout()` 修改:
   - 先 `clearToken()` (SecureStore)
   - 再 `storage.setItem('cairn_logout_marker', '1')` (AsyncStorage)
   - 然后 fire-and-forget POST /api/auth/logout（可选服务端 revoke）
3. AuthScreen 登录成功时 `storage.removeItem('cairn_logout_marker')`
4. Playwright bypass 分支保留

## Breadcrumbs（P0-log 强制）
- `hydrate:start`
- `hydrate:auto_login_success user_id=<id>`
