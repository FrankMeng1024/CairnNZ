# STORY-00550: JWT 30 天 + refresh endpoint + 铁律

**Epic**: E-Auth · **Sprint**: 72 · **Points**: 5 · **Owner**: Backend + Frontend · **Status**: Done

## Description
Users should not be signed out because of transient network errors, backend blips, or normal 30-day inactivity. Only a real server-side "your token is invalid" should sign them out.

## 现状根因
- `backend/.env` JWT_EXPIRES_IN=7d — hiking app 用户一周不打开 = 被踢
- 无 refresh endpoint — 到期后只能重登
- `apiService.ts:41-49` — 任何 401 无脑 clearToken + logout，不区分"服务器说 invalid" vs "路由错误" vs "网络抖动"
- `getMe():111-112` 已经只在 401/403 才 clearToken，网络错误保留 token — **铁律已部分存在但未推广**

## 改动

### Backend
1. `backend/.env` 阿里云 docker：`JWT_EXPIRES_IN=30d`
2. `backend/src/routes/auth.js` 新增 POST /api/auth/refresh（authenticated）：
   ```js
   router.post('/refresh', authenticate, async (req, res) => {
     const newToken = signToken({ userId: req.user.userId, email: req.user.email });
     return res.json({ token: newToken });
   });
   ```
3. `authService.ts` 新增 `refreshToken()`:
   ```ts
   export async function refreshToken(): Promise<{ token?: string; error?: string }> {
     const token = await getToken();
     if (!token) return { error: 'no_token' };
     try {
       const res = await fetch(`${API_BASE_URL}/api/auth/refresh`, {
         method: 'POST',
         headers: { Authorization: `Bearer ${token}` },
       });
       if (!res.ok) return { error: `http_${res.status}` };
       const data = await res.json();
       if (data.token) await saveToken(data.token);
       return { token: data.token };
     } catch { return { error: 'network' }; }
   }
   ```

### Frontend — 铁律
`apiService.ts` authenticatedFetch 改：
- **网络错误** (fetch throw) → 不动 token，Response 由 caller 处理
- **401 with `X-Cairn-Auth-Invalid: true` header** OR body `{ code: 'TOKEN_INVALID' }` → clearToken + logout（真过期）
- **单纯 401 without invalid marker** → 只 breadcrumb，不 clearToken（保守）
- 如果 hiking active (`useTrackingStore.status === 'tracking'`) → **绝不 logout**，只 breadcrumb "revoke:401_during_tracking_marked"，标记 `pendingReauth=true` 让 AppState=active 时再处理

Backend `authenticate.js` 已经在 TokenExpiredError 时返回 message "Session expired"，加上 header：
```js
if (err.name === 'TokenExpiredError') {
  res.set('X-Cairn-Auth-Invalid', 'true');
  return res.status(401).json({ message: 'Session expired.', code: 'TOKEN_INVALID' });
}
res.set('X-Cairn-Auth-Invalid', 'true');
return res.status(401).json({ message: 'Invalid token.', code: 'TOKEN_INVALID' });
```
