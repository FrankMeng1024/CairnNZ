# STORY-00551: 未结束 session 恢复

**Epic**: E-Tracking · **Sprint**: 72 · **Points**: 3 · **Owner**: Frontend · **Status**: Done

## Description
As a hiker whose phone died mid-tramp (or iOS killed the app), I want to open the app after charging and be asked "Continue your hike?" so I don't lose half the route.

## 现状根因
`backgroundLocationTask.ts:117-172` 已有 session_id AsyncStorage 恢复路径，但**UI 层没接**——冷启动看不到"你有未结束的徒步"。

## 改动
1. `useAppStore.hydrate()` 完成后（`hydrated=true` 前）检查:
   - AsyncStorage 里有 `cairn_active_session_id` 且 `useSessionStore` 中该 session `endedAt=null`
   - → set `pendingSessionResume: { sessionId, startedAt, activityMode, lastPointTs }`
2. RootNavigator / HomeScreen 检测到 `pendingSessionResume` → 顶部黄色 banner "继续 X 分钟前的徒步？[继续] [结束并保存]"
3. **继续**: `useTrackingStore.resumeSession(sessionId)` — 恢复 status=tracking，重启 GPS 源，AppState listener
4. **结束**: mark session ended，distance/duration 用 last point 计算，AsyncStorage 清 active_session_id
5. 用户不响应超过 24 小时的 session → 静默视为"结束"
