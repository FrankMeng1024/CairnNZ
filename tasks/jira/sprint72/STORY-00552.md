# STORY-00552: Auto-pause / 静止提醒

**Epic**: E-Tracking · **Sprint**: 72 · **Points**: 3 · **Owner**: Frontend · **Status**: Done

## Description
As a hiker who forgot to hit "Stop" after reaching home, I want the app to detect I've stopped moving and either auto-end my session or at least ask me — so my battery doesn't drain to 0 recording my couch.

## 现状根因
方案完全缺失。竞品（Strava/AllTrails/Komoot）全有。

## 改动
1. `useTrackingStore` 新增 idleness detector（tracking active 时启用）:
   - 每 60 秒计算：过去 15 分钟内所有 GPS 点是否满足：
     - 平均速度 < 0.5 m/s AND
     - 位置最大漂移 < 50 米
   - 满足 → 判定 "idle"
2. Idle 达到 15 分钟且未曾提醒 → 触发 iOS 本地通知 (`expo-notifications.scheduleNotificationAsync`) "你还在徒步吗？"
   - 用户点通知打开 app → 弹 Alert "继续 [继续记录] [结束并保存]"
3. Idle 后 30 分钟仍未响应且仍无移动 → 静默 `stopTracking()`，session mark ended，用最后一个非 idle 点作为终点
4. 用户任何 GPS 移动（>50m 或 >0.5m/s 持续 60s）→ 重置 idle 计时

阈值全部走 constant，方便真机调:
```ts
export const AUTO_PAUSE = {
  IDLE_SPEED_THRESHOLD_MS: 0.5,
  IDLE_RADIUS_M: 50,
  IDLE_WINDOW_MS: 15 * 60_000,       // 15 分钟窗口
  PROMPT_AFTER_MS: 15 * 60_000,      // 15 分钟提示
  AUTO_END_AFTER_MS: 30 * 60_000,    // 提示后 30 分钟自动结束
};
```

## Breadcrumbs
- `auto_pause:idle_detected duration_ms=<ms>`
- `auto_pause:prompt_sent`
- `auto_pause:user_continued`
- `auto_pause:user_ended`
- `auto_pause:silent_end`
- `auto_pause:movement_resumed reset_idle=true`

## AC
- [ ] 15 分钟静止 → breadcrumb `idle_detected` + `prompt_sent`
- [ ] 30 分钟静止 → session 自动 ended + breadcrumb `silent_end`
- [ ] 用户移动 → idle 计时重置 breadcrumb 有 `movement_resumed`
- [ ] Playwright: mock 位置停在同一点 → 快进时间验证 breadcrumb 序列
- [ ] 阈值全走 constant，可 config 调整

## Non-goals
- 通知点击后深链到某个页面（用普通 launch app 即可）
- Auto-pause 期间 GPS 是否降到 static-sampling — 现有 `classifyMovement:static` 已经会给 10s 采样
