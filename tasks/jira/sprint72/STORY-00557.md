## 基础设施
1. `app/tests/sprint72/setup.ts` — 通用 helpers:
   - `mockToken(page, token)` — 预置 localStorage
   - `mockLogoutMarker(page, on)` 
   - `mockNavigator(page, position)` — GPS mock（复用 GpsLockStep 现有 web mock）
   - `mockFetch(page, path, response)` — API mock
   - `readBreadcrumbs(page)` — 从 `window.__crashLoggerBreadcrumbs` 读（新增 dev hook）
   - `fastForward(page, ms)` — jest fake timers via evaluated JS
2. `crashLogger.ts` 增加 dev hook：`if (__DEV__ && Platform.OS === 'web') window.__crashLoggerBreadcrumbs = recentEvents;`
3. `app/tests/sprint72/*.spec.ts` — 按 Story 分文件
