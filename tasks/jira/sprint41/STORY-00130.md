# STORY-00130: HomeScreen全屏布局重构

**Epic**: UI Quality
**Sprint**: Sprint 41
**Sprint Goal**: HomeScreen全屏重构
**Points**: 3
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user, I want the HomeScreen to fill the entire phone screen with Hiking and Running as the dominant visual elements, so that the app feels purposeful and immediately actionable.

## Expected Result
- 屏幕无多余留白，内容铺满iPhone 14 (390×844)
- Hiking / Running 两张Card视觉上是页面主角，占据大部分屏幕高度
- 最近记录缩为一行compact条，点击可跳转MapHistory
- Header精简（保留logo+问候，去掉副标题）
- Tools区（Map/Routes/Friends/Settings）保留但视觉权重降低

## Acceptance Criteria
- [ ] 固定布局（非ScrollView），内容铺满SafeAreaView
- [ ] 两张Activity Card高度合计占屏幕可用高度的50%以上
- [ ] Recent Activity缩为单行（icon + 主要数据 + chevron），高度≤52px
- [ ] 屏幕底部无空白gap（Tools行贴近底部或合理分布）
- [ ] iPhone 14 (393×852) 截图无溢出、无空白底部
- [ ] 空状态（无数据）时布局同样铺满，不出现大片空白

## UX AC
- [ ] 第一眼看到页面，Hiking/Running Card是最显眼的元素
- [ ] 最近记录一眼能读懂（类型+距离/时长），不需要展开
