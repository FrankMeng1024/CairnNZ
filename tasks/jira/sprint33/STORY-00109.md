# STORY-00109: FriendsScreen staggered entrance animation

**Epic**: E-006 UI/UX
**Sprint**: Sprint 33
**Sprint Goal**: Premium micro-interactions and UI polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a user checking on my hiking partners, I want FriendsScreen to animate into view with the same polished entrance as HomeScreen, so it feels cohesive with the rest of the app.

## Expected Result
FriendsScreen renders with: (1) screen fade-in on mount, (2) sharing banner pill slides + fades in, (3) each friend card stagger-slides up with 60ms inter-card delay.

## Acceptance Criteria
- [ ] Screen fades in (opacity 0→1, 280ms, ease-out) on mount — matching HomeScreen screenOpacity pattern
- [ ] Sharing banner row fades + slides up (translateY 12→0, opacity 0→1, 250ms, delay 80ms)
- [ ] Friend cards stagger entrance: each card fades + slides up (translateY 16→0, opacity 0→1, 220ms) with 60ms stagger between cards
- [ ] "Add a friend" dashed card follows after last friend card (60ms additional delay)
- [ ] All animations use useNativeDriver: true
- [ ] Navigation away and back: animation re-runs on re-mount
- [ ] Zero console errors during animation

## Notes
Pattern matches HomeScreen card1Anim/card2Anim (Animated.spring or Animated.timing with useNativeDriver:true). FriendsScreen currently renders 4 MOCK_FRIENDS + addFriend card. Use Animated.stagger(60, [banner, card0, card1, card2, card3, addCard]) on useEffect mount. Cleanup on unmount.
