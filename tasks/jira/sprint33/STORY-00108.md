# STORY-00108: MapHistoryScreen — "Route Preview" label fix + staggered card expand animation

**Epic**: E-006 UI/UX
**Sprint**: Sprint 33
**Sprint Goal**: Premium micro-interactions and UI polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a hiker reviewing past sessions, I want the expanded session card to reveal its content with a staggered animation (not a flat pop-in), and the preview label to accurately describe what I see, so the interaction feels premium and the content is clearly labelled.

## Expected Result
The "Route Preview" label is renamed to "Preview". When a session card expands, the three content rows (stats capsules, preview card, View on Map CTA) stagger-animate into view with opacity + translateY.

## Acceptance Criteria
- [ ] The previewLabel text reads "Preview" (not "Route Preview")
- [ ] When a session card expands, stats capsule row fades + slides up (opacity 0→1, translateY 10→0, delay 0ms)
- [ ] Preview card fades + slides up (opacity 0→1, translateY 10→0, delay 40ms)
- [ ] View on Map CTA fades + slides up (opacity 0→1, translateY 10→0, delay 80ms)
- [ ] All three animations use duration 200ms, ease-out
- [ ] useNativeDriver: true for opacity and transform (NOT height — height stays on JS thread)
- [ ] Collapse hides content immediately (no reverse animation needed)

## Notes
The expandedArea uses Animated.timing for height (JS thread, cannot use useNativeDriver:true for height). The stagger animations are separate Animated.Values for opacity+translateY (can use useNativeDriver:true). Use Animated.stagger(40, [...]) triggered when card expands. Reset animations to 0 when card collapses.
