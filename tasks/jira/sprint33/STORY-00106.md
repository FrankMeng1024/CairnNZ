# STORY-00106: Haptic feedback on key interactions

**Epic**: E-006 UI/UX
**Sprint**: Sprint 33
**Sprint Goal**: Premium micro-interactions and UI polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As an outdoor user tracking with Cairn, I want haptic feedback at key interaction moments (flag type selection, tracking start/stop, lock screen unlock), so I get physical confirmation even with gloves on or eyes on the trail.

## Expected Result
Haptic feedback fires at: (1) flag type card selection in FlagPlantSheet and CreateMarkerSheet, (2) Start Hiking / Start Running / Stop button press, (3) RunningScreen double-tap unlock success.

## Acceptance Criteria
- [ ] Selecting a flag type card in HikingScreen FlagPlantSheet fires Haptics.impactAsync(ImpactFeedbackStyle.Light)
- [ ] Selecting a flag type card in MapScreen CreateMarkerSheet fires Haptics.impactAsync(ImpactFeedbackStyle.Light)
- [ ] Tapping "Start Hiking" (HikingScreen) fires Haptics.impactAsync(ImpactFeedbackStyle.Medium)
- [ ] Tapping "Start Running" (RunningScreen) fires Haptics.impactAsync(ImpactFeedbackStyle.Medium)
- [ ] Tapping "Stop" during tracking (HikingScreen/RunningScreen) fires Haptics.impactAsync(ImpactFeedbackStyle.Medium)
- [ ] RunningScreen double-tap unlock success fires Haptics.notificationAsync(NotificationFeedbackType.Success)
- [ ] No haptic fires if haptics not supported (expo-haptics graceful no-op on web)

## Notes
expo-haptics is already in expo SDK. Import: import * as Haptics from 'expo-haptics'. On web preview, Haptics methods are no-ops — no error. All calls alongside existing onPress handlers, zero layout change.
