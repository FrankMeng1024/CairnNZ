# STORY-00110: HomeScreen contextual nudge when user has markers but no sessions

**Epic**: E-006 UI/UX
**Sprint**: Sprint 33
**Sprint Goal**: Premium micro-interactions and UI polish
**Points**: 1
**Owner**: Frontend Dev
**Status**: Done

## Description
As a new user who has planted flags on a casual walk but hasn't done a tracked session yet, I want to see a contextual prompt between QuickStats and the activity cards, so I understand how to complete my first tracked hike.

## Expected Result
When hasData=true but sessions.length === 0, a small inline nudge card appears between QuickStats and Activity Cards: PlayCircle icon, "Complete your first hike to see activity here" text, tappable to navigate to Hiking.

## Acceptance Criteria
- [ ] Nudge card renders only when sessions.length === 0 AND (markers.length > 0 OR sessions.length > 0) — i.e., when hasData is true but no sessions exist
- [ ] Nudge card shows: PlayCircle icon (Colors.primary, 18px) + "Complete your first hike to see activity here" in caption/textSecondary
- [ ] Nudge card is tappable and navigates to Hiking screen (same as "Hiking" activity card)
- [ ] Nudge card has surface bg, Radius.card, 1px Colors.border, Spacing.md padding
- [ ] Nudge card does NOT appear when sessions.length > 0
- [ ] Full HomeEmptyState (HowItWorks) still renders when hasData === false

## Notes
This addresses the edge case where user has markerCount > 0 but sessions = []. In test data (mocked) sessions are seeded by default, so this state may need manual testing. The card sits between the QuickStats row and the Activity Cards section. Existing RecentActivityStrip null-return at sessions.length === 0 is complementary — the nudge fills the gap where the strip would be.
