# STORY-00105: GPS pulse animation on HikingScreen and MapScreen location dot

**Epic**: E-006 UI/UX
**Sprint**: Sprint 33
**Sprint Goal**: Premium micro-interactions and UI polish
**Points**: 2
**Owner**: Frontend Dev
**Status**: Done

## Description
As a hiker using Cairn on trail, I want the location dot on the map placeholder to pulse like a live GPS indicator (as seen in Apple Maps, AllTrails, Google Maps), so I can see at a glance that GPS tracking is active.

## Expected Result
The outer ring of the location dot on HikingScreen and MapScreen animates as a repeating fade-out pulse (opacity 0.3→0, 2s loop). The inner dot has a subtle scale pulse (1.0→1.05, matched loop). Animation uses useNativeDriver: true.

## Acceptance Criteria
- [ ] HikingScreen locationPulse (outer ring) has a looping opacity animation: 0.3 → 0, duration 2000ms, repeat (Animated.loop)
- [ ] MapScreen outer location ring has the same looping pulse animation
- [ ] Inner location dot has a subtle scale animation (1.0 → 1.05, 2000ms loop) on both screens
- [ ] Animation uses useNativeDriver: true
- [ ] No layout shift or flicker during animation loop
- [ ] Navigation away and back: animation restarts cleanly (no zombie Animated values)

## Notes
Pattern: Animated.loop(Animated.timing(pulseAnim, { toValue: 0, duration: 2000, useNativeDriver: true })). Start in useEffect on component mount, cleanup in return. Both HikingScreen and MapScreen have locationPulse style already — this adds animation to the existing element.
