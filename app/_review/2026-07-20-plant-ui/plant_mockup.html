A DOC Handbook Field Note Warm, serif-first, NZ cultural signals baked in — matches Product Soul
Feels like reading a page from a DOC (Department of Conservation) trail hut ledger. Serif type for headings, sepia eyebrows, sage green CTAs. Every screen carries a small piece of NZ context: an illustrated cairn on loading, a Māori bilingual greeting, a Leave-No-Trace ethic quote below the map. Fills empty space with meaning, not with widgets.
NZ culture elements used: Māori greeting "Kia ora" · "whenua" (land) inline reference · Leave No Trace ethic quote (NZ Environmental Care Code line 4) · DOC handbook visual language (cream + sage + sepia + serif) · Illustrated cairn against a Kepler-style ridgeline

B Trail Utility — AllTrails / Strava style Data-dense, precise, tool-first. Fills empty space with useful signal.
Optimised for hikers who want numbers first, feeling second. Loading screen shows live coordinates, altitude, satellite count, and accuracy meter as they lock in. Below the map, a live list of "recent nearby cairns" — social proof + wayfinding at once. Less NZ warmth, more competence.
NZ culture elements used: Palette only (cream / sage / sepia). No Māori copy. Would need to be layered in via nearby cairn titles ("Kepler Ridge Cache", "Tongariro Lookout"). Weakest cultural signal of the three — chosen if we position Cairn as a power-user tool rather than a cultural product.

C Handwritten Journal Personal diary — date, weather, handwritten note feel
Feels like opening a leather-bound journal on the trail. Ruled paper texture, dashed borders, a rubber-stamp badge, page numbers in the corner. Every screen frames the moment as a private memory being pinned to a place. Warmer than B, more personal than A — but less institutional / less "NZ official".
NZ culture elements used: Handbook aesthetic (dashed borders, ruled paper, rubber-stamp typography). No explicit Māori/DOC copy. Could be layered in via a hand-drawn cairn stamp. Best fit if we target NZ tourists / casual walkers rather than serious trampers.

Recommendation from Senior Product Designer: Direction A — DOC Handbook Field Note
It is the only direction that simultaneously (1) fills the empty space with intent, (2) delivers the "digital handbook + stranger kindness" Product Soul, and (3) carries real NZ / Māori / DOC cultural signal.
B is a fallback if Cairn shifts toward power-user positioning. C is a fallback for the casual-tourist segment.
