# STORY-00018: HomeScreen deep redesign

**Epic**: E-003 UI Quality
**Sprint**: Sprint 6
**Points**: 5
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a user, I want the HomeScreen to feel premium and alive — with personalized greeting, animated card interactions, and visual depth — so that the app makes a strong first impression on every session.

## Expected Result
HomeScreen has: time-of-day greeting, spring-physics card press animations, staggered entrance animation, SVG icons, visually distinct activity cards with depth, properly sized entry buttons.

## Acceptance Criteria
- [ ] Header shows time-of-day greeting: "早上好" (5-11h), "下午好" (12-17h), "晚上好" (18-4h)
- [ ] Activity cards animate with `Animated.spring` scale 0.97 on press-in, snap back on release
- [ ] Cards have staggered entrance: slide up (translateY 20→0) + fade in, 80ms stagger between cards
- [ ] Activity card icons use SVG (Mountain for hiking, PersonRunning/Footprints for running)
- [ ] Activity card chevron uses SVG ChevronRight inside a tinted circular pill
- [ ] Card visual depth: subtle gradient or layered background using `LinearGradient` from expo-linear-gradient OR a styled background shape
- [ ] Entry buttons (地图/好友/设置) minimum height 80px, SVG icon above label, icon size 26px
- [ ] Entry buttons have press scale animation (Animated.spring scale 0.94)
- [ ] Divider between activity cards and entry buttons is polished (text label centered, lines fade out)
- [ ] Screen entrance: entire screen fades in on mount (opacity 0→1, 300ms ease)
- [ ] All touch targets ≥ 44pt (WCAG AA)
- [ ] Zero emoji in any interactive element (non-interactive decorative text is ok)
- [ ] No console errors at any viewport

## Dependencies
- STORY-00017 (SVG icons must be installed first)

## Notes
Target quality bar: "this screen looks like it belongs in the App Store top 100". Reference: Strava home screen card layout, AllTrails activity picker.
expo-linear-gradient is already in package.json as a dependency.
