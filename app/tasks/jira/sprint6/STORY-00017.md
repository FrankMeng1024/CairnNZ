# STORY-00017: Install SVG icon system (lucide-react-native)

**Epic**: E-002 Design System
**Sprint**: Sprint 6
**Points**: 2
**Owner**: Frontend Dev
**Status**: Todo

## Description
As a developer, I want a unified SVG icon system so that all screens use consistent, production-quality icons instead of emoji.

## Expected Result
`lucide-react-native` + `react-native-svg` installed. A thin `<Icon>` wrapper component exists at `src/components/Icon.tsx`. HomeScreen uses SVG icons exclusively — no emoji in navigation or interactive UI.

## Acceptance Criteria
- [ ] `react-native-svg` installed (npx expo install)
- [ ] `lucide-react-native` installed (npm install)
- [ ] `src/components/Icon.tsx` wrapper created — accepts `name`, `size`, `color`, `strokeWidth` props
- [ ] `src/components/tokens.ts` updated with `IconSize` constants (sm=18, md=22, lg=28)
- [ ] HomeScreen: activity card icons use SVG (Mountain, Footprints or PersonStanding)
- [ ] HomeScreen: entry buttons use SVG (Map, Users, Settings2)
- [ ] HomeScreen: chevron arrows use SVG ChevronRight
- [ ] Zero emoji used in HomeScreen UI elements (decorative text emoji in greetings is acceptable)
- [ ] No console errors from SVG rendering

## Dependencies
- STORY-00016 (can run in parallel)

## Notes
Icon library choice: lucide-react-native. Reason: dedicated RN package, consistent 2px stroke weight, tree-shakeable. Document in UI_SPEC.md §icon-system after completion.
