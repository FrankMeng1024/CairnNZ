Variant C · 3D Demo (Three.js)

3D 真实空间感Three.js基于 C v2

这是 3D 版 — 用真实透视相机 + 地面 plane + 圆柱形光带几何 + AR-correct billboard 标签. 操作:

· 左拖 旋转视角 · 滚轮 缩放 · 右拖 平移 · 看 cairn 从不同角度的样子

对比 2D 版 (variant_C_v2): 这里你可以**绕到 cairn 后面**, 从**斜上方**看, 从**眼睛高度** 1.6m 看 — 体验真实 AR 中你会看到的角度. 光带的"飘上去断开"在 3D 里更明显.

注意: 这只是视觉感受版本. Unity 实现会用 ARFoundation + ParticleSystem (TrailModule) 直接达到同等效果, 性能更好.
