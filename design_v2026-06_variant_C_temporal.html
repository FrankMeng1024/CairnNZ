Variant C · 时间锚 (DS Strand)

DS 灵魂亲属细节层次异步社交温度

设计语言: 直接致敬 Death Stranding 的"陌生人在 5 天前留下的 sign"美学。Cairn 不只是位置标记，是**时间胶囊** — 显示"X 时间前由谁留下"。光带表达**时间的延续**而非装饰。

组成: 阵图 = 双层 (内圈静态 SDF + 外圈缓慢旋转刻度)；光带 = **垂直丝缕**像 DS 化学发光丝 (6条左右、笔直向上、轻微扰动 + 顶端 fade)；3D 文字 = 平视卡片 + 时间戳 + 留言者头像 (匿名马赛克)。

种植仪式 (1s): 阵图缓慢绘制描边 (clockwise stroke 0.5s) → 中心 SDF 浮现 (0.2s) → 丝缕从底部一根一根点亮 (0.3s, 串联式)。

哲学: "你不是看到一个 marker，你看到的是另一个人 5 天前来过这里、留下的话。" 时间的厚度 = Cairn 的护城河。
