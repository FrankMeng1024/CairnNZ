Cairn Memory — Hierarchy Icon & Panel (Design A v2)

Icon shape: a 3-stack Layers glyph — reads instantly as "zoom out one level / see the tier above". It shares no visual DNA with the Target crosshair on the right (dots + cross), so left/right controls stay one-glance distinct. Panel: single-level, 5 rows max, breadcrumb header carries the parent (Shanghai) so we never spend a row on "back". Current district gets a filled sage row so users always know where they stand. No-mark expression: filled sepia dot + "N marks" = explored & marked; dashed sepia ring + "explored" = passed through but never dropped a Cairn. Same hue, different fill weight — one visual family, two clear states.
