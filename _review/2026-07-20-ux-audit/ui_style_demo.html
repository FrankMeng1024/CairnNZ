Cairn UI Style — Now vs Recommended

Cairn is a New Zealand outdoor journal where hikers plant stones of kindness for strangers to find. The product soul is digital handbook + stranger kindness. Current UI reads as flat, cold, tool-like. This document proposes a lightweight shift toward handbook warmth + soft illustration, keeping information density intact.

User feedback (2026-07-20): "过于死板,UX 糟糕" — too rigid, no emotional temperature. The empty-Routes mountain illustration is the only element with warmth today; everything else feels like Notion.

What changed (and what didn't): Card layout, spacing, and info hierarchy are identical. What we added: watercolor edge on cards (bottom-right radial), paper-grain texture on background (very faint), a serif-italic voice for headings (handbook feel), a mini scene in each empty state, a soft glow on the CTA, and micro-animation on illustrations (sun pulse, cairn breathe, heartbeat). Silent submit

After — Stone Stacking Ritual

4 stones, 1.6s, 1 glow

On successful plant: 4 stones stack from top with 0.4s stagger. Each falls -20px with -15° rotation, settles with a bounce. On stone 4, a soft yellow glow appears (radial-gradient, 0.4s fade). Haptic medium fires with stone 1. Toast appears after glow.

@keyframes stone-stack { 0% { opacity: 0; transform: translateY(-20px) rotate(-15deg); } 30% { opacity: 1; transform: translateY(2px) rotate(2deg); } 40% { transform: translateY(0) rotate(0); } 100% { opacity: 1; } } // Stone 1 → 4: animation-delay 0s / 0.4s / 0.8s / 1.2s // On stone 1: Haptics.impactAsync(MEDIUM) // On stone 4 + 0.4s: glow-appear (radial yellow, 0.8s) // Toast after 1.8s total

Guardrails — what we are NOT doing

  • No mascot / no 旅行青蛙-style character. Cairn itself (the stone stack) is the icon-mascot. No frog, no fox, no illustrated hiker persona.
  • No story arc / no narrative overlay. This is a handbook, not a game. No progress rings dressed as adventure meters, no "Level 3 Explorer" titles.
  • No maximalist decoration. Outdoor users read this in bright sun, gloves on, one thumb. Every added element must survive a 1s glance at 400 nits sun.
  • No color-scheme overhaul. The Cairn palette is #f5efe4 / #7ea065 / #c88a2a. We layer gradients and textures on top; we do not replace.
  • No animation over 300ms on interactive elements. Only decorative/idle elements (sun pulse, cairn breathe, CTA glow) can run 2-4s loops. Never delay the user.
  • Yes: watercolor edges, paper grain, brushstroke underlines — these are handbook signals costing zero cognitive load.
  • Yes: serif italic for empty-state headings only — used sparingly as a voice signal.
  • Yes: full scenes in empty states with primary CTA — turn dead pages into invitations.
  • Yes: micro-animations tied to real user actions — stone stacking on plant, fog reveal on step, haptic on cairn found.
