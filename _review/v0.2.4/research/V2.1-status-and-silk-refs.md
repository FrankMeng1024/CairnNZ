## 一、当前实现概览

**文件**:
- `UnityARLib/Assets/Scripts/SilkRibbonV2.cs` (286 行,5-顶点 mesh ribbon,LateUpdate 重建)
- `UnityARLib/Assets/Shaders/RibbonSilkV2.shader` (182 行,URP transparent + additive)

**架构**:
- 每根 ribbon 一个 GameObject + MeshFilter + MeshRenderer
- mesh 每帧重建(C# 里 5 顶点 × N segs,世界空间 + billboard 宽度方向)
- shader Additive Blend One One,Tag Transparent+10
- Configure(ringRadius, angleRad, phaseOffset, baseTint, tipTint) 接口设丝带参数

**默认值**:
- `_ringRadius = 0.55f` 阵法半径
- 起源 X/Z = `Cos(angleRad) * ringRadius * 1.05f` ✅ **已经在外圈**(1.05 倍 = 圆环外侧 5cm)
- `_lifeHeight = 3.0f` 总上升高度 3m
- `_bodyLength = 1.0f` 可见段长度 1m(确实"有自己的长度")
- `_maxWidth = 0.10f` 最大宽度 10cm
- `_segs = 24` 段数
- `_swayAmp = 0.05f` 摆幅 5cm
- 5 顶点 spindle:halo-edge / core / center / core / halo-edge
- 颜色:base tint = 暖金 (1.0, 0.85, 0.55) → tip tint = 浅天蓝 (0.95, 0.97, 1.00)

## 三、业界丝绸感参考(从 V1.1 调研里挑相关的)

V1.1 调研报告(`research/V1.1-ribbon-research.md`)里挑出**对 Cairn 丝绸感最有用**的 3 个:

1. **Apex Legends 复活信标**
   - 单 cylinder mesh + 2 层 noise scroll + dissolve mask
   - 关键:**底端 fade-in + 顶端 dissolve 消散**(对应用户"脱离 + 淡出")
   - Cairn 可借鉴:加 dissolve mask 让顶端不是简单 alpha 衰减,而是有"溶解"的丝感

2. **Sky 光遇 信标**
   - soft particle depth fade + 低饱和梦幻调色
   - 关键:**与 fog/背景颜色融合**,不刺眼
   - Cairn 可借鉴:soft particle 在 AR 真实背景前不显得突兀

3. **Tilt Brush "Light" 笔刷**
   - **vertex shader noise displace** 让 mesh 本身扭动
   - 关键:**"不死板" = vertex 微位移**,不是只靠 alpha 闪烁
   - Cairn 可借鉴:在丝带 segments 上加微 vertex offset,让丝绸像真飘

**不采用的**:
- Pokémon GO raid 能量条纹(当前 RibbonSilkV2 已经抄了,但 step() 步进太硬,不柔)
- 原神元素配色双色 lerp(已经做了 BaseTint/TipTint,无需加)

## 七、当前丝带视觉问题快速诊断(从 SIDE-BY-SIDE-cairn.png 看)

之前侧边对比图里:
- HTML 丝带 5 根**贴地紧凑**升起,丝绸感强
- Unity 丝带 视觉看 4 根?(代码 RIBBON_COUNT=5,subagent 已确认)→ 需查为什么 1 根没显示
- Unity 丝带**很细很硬**,缺丝绸饱满感

诊断(修订):
- **数量差异**:代码 5 根,但视觉只看到 4 根 → 可能 1 根被 cluster 主体遮挡或 lifeT 同步导致 1 根在不可见相位 → V2.2 起步加 `phaseOffset = i / 5f` 错峰均匀分配
- **飘空中**:bottomY 已经离地(代码逻辑对应),但**没有"贴地阶段"** → V2.2/V2.4 加二阶段
- **太细**:`_maxWidth=10cm` + `_FlowTex=white` 让 flow=1.47 反而**亮但失质感**,加上 step bands 的硬边横条 → V2.3 删 bands + 加 fresnel rim + 给 _FlowTex 真 noise

V2.2 起步先改三个最显眼的:
1. phaseOffset 错峰精确分配(0/0.2/0.4/0.6/0.8)
2. 删 step bands 改柔正弦 / 或暂关
3. _FlowTex default 从 "white" 改 "gray" 或 "black",降 _FlowStrength 默认值
