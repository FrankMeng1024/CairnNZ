**调研时间**：2026-06-13
**调研者**：Cairn AR — V1.2 视觉强化研究阶段
**问题陈述**：用户反馈「Three.js 做的 type 各自对应的粒子效果 目前的太单调 不够凸显 type 本身。Unity 要再加强」。当前 5 type（cairn / danger / water / hut / junction）只在颜色/速率上有差异，形态语言基本同款。本调研给出每个 type 的视觉灵魂、业界对照、Unity 实现路径、5-type 同框区分策略、可 OTA 化参数清单。

## §0 总体观察:为什么"太单调"

读完源码 + 业界资料后，"单调"的根因是 **5 个 type 共用一套形态语法**：
1. 同样在 ringRadius 半径上 spawn
2. 同样的 additive blend + glow trail
3. 颜色是唯一可读差异，但在 NZ 晨曦 #E8DCC4 暖白底色下，加法混合的低饱和粒子被环境光"吃掉"，颜色读取变弱
4. cube / sphere / cone 三种 primitive，全部是凸壳实心，没有"拟物形态语言"
5. **缺的不是粒子数量，而是「形态原型」**：cairn 应该看起来像石头，不是发光的 cube；hut 应该有温度感，不是飘浮的 sphere

业界共识（原神/塞尔达视觉特效，多源印证）：**元素粒子的可识别度 = 颜色 (20%) × 形态原型 (40%) × 运动模式 (40%)**。Cairn 当前在颜色上做到 60%，形态/运动几乎为零。

### 1.3 Unity 实现路径

**形态升级**（脱离 cube/sphere）：
1. **真石头 mesh**：替换 GetCubeMesh() → 3-4 个 low-poly stone variant (~50 tris each)，Mesh 资源放在 `UnityARLib/Assets/Resources/Meshes/`，按 spawn index 取模轮换。Maori "ahu" 视觉 = 灰褐色岩，不是发光体。
2. **苔藓/地衣层**：石头表面 sub-mesh 或 vertex color，用绿苔色 (#5A7048) 在向上面分布，向下面（重力侧）保留岩本色。这是 Skyrim shrine 视觉的核心 — 「时间感」。
3. **悬浮"灵气"颗粒**（替代当前 stone particles）：极小（0.003 unit）、半透明、缓速上升（0.05 m/s），生命 3-4s，azimuthal 方向缓慢漂移。**这是"灵气"而不是"喷射"**。
4. **地面投影圈**：cairn ringRadius 处在地面绘一圈极淡的暖橙色 decal + outer 浅蓝灰 ring（"门槛"感），对应 design_v2026-06 已有的 ground anchor 概念。

**Shader 路径**：
- 石头本体用 URP Lit，启用 **fresnel rim** 在边缘加 0.3 强度的暖白光 → 在 NZ 晨曦底色下"凸出来"而非"飘起来"。
- 苔藓用 URP Lit + 一张 noise mask 控制覆盖率（OTA 可调）。
- 地面 decal 用 URP Decal Renderer Feature。

**呼吸节奏**：current breathFreq=0.5 偏快。改 **0.25-0.30 Hz**（每 3-4 秒一次），跟"敬意感"对齐。空洞骑士长椅是 0.3-0.4 Hz。

**关键参考资源**:

- URP Particle Lit 多光照模式: https://www.cnblogs.com/SmalBox/p/19300257

- **戒**（warning / threshold-crossing）

### 2.2 业界对应案例

| 案例 | 视觉做法 | URL |
|------|---------|-----|
| **原神 火元素（胡桃）** | 液态火焰 + 次表面散射 + 螺旋轨迹粒子，**关键不是"红色"而是"流体感"**。残留 spark 形成蝴蝶状轨迹。 | https://www.rongbaozhai.cn/index.php?id=ywmowj-174126 |
| **原神 火焰特效（视觉冲击）** | 火焰本身是 texture flipbook（8x8 格 atlas），sub-emitter 发出 ember + 烟雾。**double layer**：核心火舌 + 外围余烬。 | https://news.jinghua.cn/20240103/f85751.shtml |
| **塞尔达 爆炸效果** | 从核心点展开的星形 + 十字形粒子（Photoshop 自制 alpha texture），billboard 朝相机。形状只有圆/星/十字三种。 | https://www.cgjoy.com/thread-213721-1-1.html |
| **Diablo IV / 暗黑系** | 警示用 **黄黑相间脉冲条纹** + 粒子散逸，"边界"做强对比，远比"加大火焰"更醒目。 | (英文搜索命中差,但属业界共识) |
| **危险标志（视觉语言）** | 红黑配色 + 不等距脉冲（人眼对不规律节奏更敏感）+ 顶点收敛形（三角/菱形比圆形危险感强 3 倍）。 | (色彩学/UX 通识) |

### 2.3 Unity 实现路径

**形态升级**（脱离实心 sphere）：
1. **火舌核心**：用 **Flame Flipbook Texture**（8x8 格 atlas，64 帧循环，0.5s 一周期），billboard 朝相机。预算 4-6 个 quad。
   - Shader: ShaderGraph 实现，Time → TilingAndOffset → Flipbook UV，Gradient Noise 叠 distortion。
   - 关键参考: https://blog.csdn.net/Czhenya/article/details/119101204 (《Unity ShaderGraph 火焰教程》)
2. **余烬 ember 上升**：当前已有，但要"分两层"——
   - 内层 ember：明亮橙 (#FF6633)，快速上升 (0.4 m/s)，0.6s 寿命
   - 外层 dust：暗红 (#3A1505)，缓慢上升 (0.1 m/s)，2s 寿命，更多数量
3. **Heat haze（折射扰动）**：URP Render Feature 用 Grab Pass + noise scroll，在火焰上方 0.5m 范围扰动后方画面。**这是"热"的核心视觉信号**，移动端可用降级版（屏幕空间 noise distort）。
4. **不等距脉冲光环**：在 ringRadius 处地面 decal，alpha 按 `0.3 + 0.4*sin(t*1.4) + 0.3*noise(t)` 而非纯 sine — 不规律才"危险"。
5. **三角形发射形状**：danger 的 spawner shape 改用 Cone with negative angle（向上汇聚）而非圆周散射 — 形态收敛 = 警告。

**Shader 路径**：
- 火舌：ShaderGraph + Voronoi (cells: 8) + Gradient Noise 叠加 + Time UV scroll，最终输出到 Emission，颜色 lerp(#FF2A1A → #FFD040) by mask Y。
- Heat haze：单 Pass URP Renderer Feature, sample _CameraOpaqueTexture with offset = noise(uv + time * 0.3) * 0.02。

**关键参考资源**:

- 《Unity Shader 总结(十五)——噪声(火焰、水面、缥缈雾效)》: https://blog.csdn.net/memory_MM_forever/article/details/118520412

### 3.3 Unity 实现路径

**形态升级**（drop 不再是发光 sphere）：
1. **雨滴形 mesh**：drop 用 elongated teardrop（拉长椭球，y/x ≈ 1.7），底部尖头朝下落方向 → 视觉上立刻"是一滴水"而非"发光球"。生成 mesh 见 RingMeshBuilder.cs 同模式。
2. **触地涟漪 (ripple decal)**：每个 drop 落地时，在地面 spawn 一个 0.15s 寿命的圆环 decal，外径从 0.05 → 0.25 扩张，alpha 1 → 0。**这一个改动可能是 water 体感最强的提升**。
3. **细水流 ribbon**：从 ringRadius 内侧向中心，发 4-6 条 LineRenderer 带，UV 沿带方向 scroll（速度 0.6 m/s），透明度脉冲。这是「溪水流动」的核心 — 不是粒子，是「流向」。
4. **caustics 投影**：在地面投一个低对比度 caustics 贴图（Voronoi noise + scroll），半径 = ringRadius × 1.5，叠加 Multiply blend。
5. **环境湿润感**：water cairn 周围 1m 范围内，地面 decal alpha 提升 0.1（"打湿了"）+ 一点点冷蓝 tint。

**Shader 路径**：
- ribbon material: URP Unlit Transparent + scroll UV + fresnel intensity = 1.2（已有 preset 值）。
- ripple decal: 用上面 RippleTex 4-channel 法的简化版（只用 R + A）。
- caustics: URP Decal + Voronoi Time-based。

### 4.3 Unity 实现路径

**形态升级**（ember 不再是发光球）：
1. **烟柱 (smoke plume)**：在 cairn 顶部 0.3m 高度 spawn 大颗粒（0.04 unit），生命 3s，慢速上升（0.1 m/s），fade in fade out，受 wind perlin noise 横向漂移。**烟柱是 hut 的视觉签名**，没有它就不是 hut。
2. **核心 hearth 光斑**：在 cairn 中心放一个 0.06 unit 直径的 emissive sphere（hut 暖琥珀色 #E0BE8C），点光源 0.2m 半径，intensity flicker 0.5+0.3*noise(t*1.5)。
3. **ember 改造**：当前的 ember 拉长生命 → 4-5s，速度 → 0.05 m/s，但**spawn 范围收紧**到 ringRadius * 0.3（聚拢在中心）。"烟囱"是垂直窄柱，不是散射。
4. **silhouette 暖光环**：地面 decal，soft 暖色（#D4A06B → 透明），半径 1.0-1.5m，呼吸 0.4Hz。这是"召唤感"——远处看到了知道是 hut。
5. **避难感 audio cue**（不在视觉范围，但建议 Sprint 后期带入）：低频 60Hz 嗡声 +200Hz 木材噼啪。

**Shader 路径**：
- 烟柱用 URP Particle Unlit + soft particle (depth fade) + alpha texture（圆形云团）。
- 暖光环 decal: URP Decal + radial gradient + breath uniform。
- 蜡烛 flicker: 在 light 组件上加 LightFlicker.cs（已有的或新增）— Mathf.PerlinNoise(Time.time * 1.5, 0) 驱动 intensity multiplier。

### 5.3 Unity 实现路径

**形态升级**（arrows 不再是飘浮 cone）：
1. **箭头质感升级**：当前 6 个 cone 沿环旋转。改为：
   - 每个箭头是「箭头 + 短拖尾」组合（cone + tapered ribbon trail of 0.4m）
   - 箭头本体加 outline shader（URP 的 Stencil-based outline 或 Sobel post-process）→ 在暖白 AR 底色下"框出"箭头轮廓
   - 旋转方向：3 个顺时针 + 3 个逆时针（current 都是同向） → "分叉"语义
2. **中心垂直光柱**：cairn 中心向上发 0.8m 高、半径 0.04m 的 emissive cylinder，alpha 上下渐变（顶部透明），UV scroll 向上。这是死亡搁浅 chiral 路标的核心。
3. **Koru 螺旋曲线 (decoration)**：地面 decal，3 条从中心向外放射的 koru 曲线（1/3 圆 + 反向螺旋），半径 0.4-0.7m。**这是 NZ 文化锚点**。
4. **粒子从中心放射**：替代当前 orbit only。每 0.3s 从中心 spawn 一个 spark，沿 6 方向之一射出（与箭头同步），生命 0.6s。"路径"= 粒子轨迹，"选择"= 多个轨迹。
5. **远距离光柱 LOD**：远距离（>10m）时只渲染中心垂直光柱（1 draw call），近距离（<5m）时全功能。距离阈值可 OTA。

**Shader 路径**：
- 光柱：URP Unlit Transparent + radial alpha gradient + UV scroll。
- 箭头 outline：URP Renderer Feature with Stencil（成本低，移动端友好）或 简化 fresnel rim。
- Koru decal：手画 PNG（256x256 RGBA），URP Decal Renderer Feature。
- 中心放射 spark：复用现有 SpawnSpark 但改 velocity 为指向 6 个箭头位置。

## §6 5 type 同框时如何"互相区分但不打架"

### 6.1 三维区分矩阵

将 5 个 type 在 **(色彩空间, 运动模式, 形态原型)** 三维空间分开放置:

| Type | 色相 (HSV.H) | 饱和度 | 主运动模式 | 形态原型 | 节奏 (Hz) |
|------|------------|--------|----------|---------|----------|
| **cairn** | 0° (warm sepia #E8C896) | 中低 (40%) | 静止 + 极慢悬浮 | **块体 (mass)** stone mesh | 0.25-0.30 |
| **danger** | 5-15° (red-orange #FF2A1A) | 高 (90%) | **不规律脉冲** + 上升 | **火舌 (flame)** flipbook quad | 1.4 (irregular) |
| **water** | 190° (cyan #5AE6FF) | 中 (70%) | **持续流动** + 下落 | **滴/带 (drop+ribbon)** | 0.3 (smooth) |
| **hut** | 35° (warm amber #D4A06B) | 中 (60%) | **稳定上升** (smoke) | **柱 (plume)** | 0.4 (steady) |
| **junction** | 75° (green-gold #C4E847) | 中高 (80%) | **旋转 + 放射** | **箭+柱 (arrow+pillar)** | 0.6 (rotational) |

**关键洞察**：当前实现 5 type 的"色相"是分开的（已经做到），但"运动模式"和"形态原型"高度雷同（都是 spawn → ballistic → fade）。**最大改动应该是运动模式和形态原型，颜色已 OK**。

### 6.2 防止"打架"的设计原则

1. **色彩"温度对"**：cairn (sepia) 和 hut (amber) 都是暖色系，但 cairn 的饱和度故意压低 → 静；hut 的明度故意提高 → 召。两者不会混淆。
2. **运动方向正交**：water 向下/向内，hut 向上/向中，junction 旋转/放射，danger 不规律向上，cairn 几乎不动。从屏幕动量看不会重叠。
3. **形态语言专属**：5 个 type 各有独特 mesh / shader（stone / flame flipbook / drop+ribbon / smoke plume / arrow+pillar），不能互换。
4. **节奏频率分离**：0.25 / 0.4 / 0.6 / 1.4 (irregular) — 5 个频率覆盖低/中/高三个段，多 cairn 同框时 visual rhythm 不会同步成"心跳"。
5. **远距离降级到色彩**（>10m）：远处所有 type 退化到 1 个垂直光柱 + 主色，靠颜色辨认；近距离才显形态。这是死亡搁浅/塞尔达的 LOD 策略。

### 6.3 NZ 晨曦 #E8DCC4 暖白底色的应用约束

- **加法混合（additive）在暖白底色下饱和度损失大**。danger 的红光/water 的 cyan 需要 emissive intensity 拉到 2.5-3.5（已在 preset 中），但 hut 的 amber 反而要降到 1.6-2.0 — 否则与底色融合。
- **outline / fresnel rim 比 emission 更可靠**：在暖白底色下，黑色或深色的 0.5-1px outline 让 cairn / junction 的形态"切出来"。
- **shadow blob (cairn_shadow_blob.png 已存在)**：每个 cairn 在地面投一个 soft shadow decal，**这是把粒子从背景"分离"出来的最关键单步**。

## §7 OTA 化清单 — 不动 native 也能调

把以下参数**全部**暴露到 RN 端 (`unityCairnSpawn.ts` SpawnRequest payload)。这样真机调试时不必重 EAS build。

**已有 OTA 字段**（CairnTypePresets.cs 现状）:
- `color`, `scrollSpeed`, `bloomBoost`, `fresnelPow`, `fresnelIntensity`, `breathFreq`, `haloColor`, `haloIntensity`, `particleRate`, `particleStartColor`

**建议新增 OTA 字段**（按可调价值降序）：

| 字段 | 类型 | 范围 | 用途 |
|------|------|------|------|
| `particleSize` | float | 0.005-0.05 | 粒子尺寸总缩放，单点可调"显眼度" |
| `particleLifeSec` | float | 0.5-5.0 | 生命长短控制 trail 长度 + 视觉持续感 |
| `particleSpeedMul` | float | 0.3-2.5 | 速度乘数，调"急/缓"语气 |
| `outlineColor` + `outlineWidth` | Color + float | - / 0-2px | 形态切出来 |
| `groundDecalRadius` + `groundDecalAlpha` | float + float | 0.3-2.0 / 0-0.6 | shadow blob / 暖光环 / 涟漪 范围 |
| `flickerFreq` | float | 0.2-2.0 | 节奏频率，per-type override |
| `flickerIrregularity` | float | 0-1 | 0=纯正弦, 1=纯 noise，danger 设 0.7 |
| `pillarHeight` (junction/hut) | float | 0-1.5 | 中心光柱高度 |
| `pillarIntensity` (junction/hut) | float | 0-3 | 光柱亮度 |
| `embersDoubleLayer` (danger/hut) | bool | - | 双层 ember (核心+外圈) on/off |
| `windDirection` + `windStrength` | Vec3 + float | - | 烟/sparks 受全局风影响 (hut/danger 必备) |
| `lodFarDistance` | float | 5-20m | 远距离 simplify 阈值 |

**预估**：上述 12 个参数加上之前 10 个，22 个字段全 OTA 化后，**90% 的视觉调优不需要重 build**。这与项目 OTA 推送策略 (memory: feedback_ota_push_gate) 一致。

## §8 可执行总结 — 5 type Unity 端的具体改动清单

按"投入产出比"优先级排序。建议在后续 Sprint 用 Story 拆分。

### Tier 1（高优先级，单独都能让 type 立刻可识别）

1. **cairn**: 替换 cube → low-poly stone mesh + 苔藓 vertex color 层 + 地面 shadow blob decal（已有 cairn_shadow_blob.png 资源未充分利用）
2. **danger**: ShaderGraph 火焰 flipbook (Voronoi+GradientNoise) 替换 sphere spark + heat haze post-process（移动端友好版）
3. **water**: 雨滴 mesh (拉长 sphere) + **触地涟漪 ripple decal**（这一个改动可能是 water 体感最强的提升）+ inward ribbon 流向
4. **hut**: 烟柱 plume（垂直窄柱、wind perlin 横向漂移）+ 中心 hearth point light + 暖光环地面 decal
5. **junction**: 中心垂直光柱（死亡搁浅 chiral 风）+ 箭头 outline shader + Koru 螺旋地面 decal

### Tier 2（中优先级，加深视觉风格）

6. 5 type 节奏频率重新校准（0.25 / 0.4 / 0.6 / 1.4(irregular) / 0.3）— **per-type breathFreq override**
7. 5 type 都加 spawn shape 收敛/发散 区分（cairn=ground only, danger=cone-up, water=ring-inward, hut=narrow-up, junction=radial+spin）
8. URP Renderer Feature 实装 outline pass（cairn/junction 用）
9. URP Decal Renderer Feature 实装地面 decal 系统（5 type 都用）

### Tier 3（低优先级，OTA 调优 + LOD）

10. 上面 §7 表中 12 个新 OTA 字段加到 SpawnRequest payload + CairnTypePresets.cs preset 字段
11. 远距离 LOD：>10m 时所有 type 退化到中心光柱 + 主色 quad
12. EditorManualTick 同步 batch capture 验证（v0.2.4 已有的 V024CapturePlayground.cs 模式）

### 不该做的

- ❌ **不要再加更多粒子数量**。当前 80/cluster × 5 cluster = 400 已是 SE2 的合理上限。"单调"不是粒子少的问题。
- ❌ **不要追"逼真物理流体"**（Obi Fluid / Compute SPH）。AR 户外场景，性能预算容不下，且与"暖白晨曦"风格不符。
- ❌ **不要把所有 type 全切到 VFX Graph**。当前 TypeParticleController.cs 自管粒子已能 batch mode 渲染，且 Editor 自动化测试已稳定（v0.2.4-P2）。VFX Graph 只在 type 单独加强（如 danger 火焰）时局部引入。
- ❌ **不要破坏 RN OTA 通路**：所有强化必须通过 CairnTypePresets.cs 的 preset struct 暴露字段，不要 hardcode magic number 在 TypeParticleController.cs 里。
