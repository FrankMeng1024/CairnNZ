# V1.1 Ribbon 视觉调研报告

**目标**：用户对 Three.js demo 当前丝带效果不满意——"死板的纸带子往上"。需要在 Unity 端实现：

- 不是死板上升纸带 → **气流/能量感/灵气**
- **脱离感**（从地面分离上升）
- **渐入浅色**（底深 → 顶浅）
- **顶端淡出**（消散到背景）
- **昼夜不同**（白天 vs 夜晚）
- **远近 LOD**（近 hero / 中 mid / 远 fade）

**调研方法**：GLM `search-pro` 30 query × 多轮 + GLM chat-mode 技术原理 query × 15。WebFetch/WebSearch 在企业网络下不可用，已用 GLM `glm_websearch.py` 替代。

**仅调研，不写代码、不开 EAS、不推 OTA。**

## §1. 业界 5 个独立思想可借鉴案例

### Case 1 — 《原神》(Genshin Impact) 元素能量带 / 能量光柱

**做法关键点**（基于米哈游 NPR shader 解读社区资料）：
- **多层 UV 流动**：能量带通常由 2-3 层 UV scroll 叠加而成。底层是低频 noise（控制大形态），上层是高频 noise（控制闪烁/细节），各层 UV.y 用不同的 `_Time.y * speed` 偏移
- **顶点 height 渐变**：vertex.localY 进 fragment 后，用 `smoothstep(_FadeStart, _FadeEnd, height)` 控制底部"渐入浅色"和顶部"消散"
- **NPR 边缘光**：rim light 用 Fresnel `pow(1 - dot(N, V), _RimPower)`，让能量带边缘呈现高光感（这是"灵气"的关键，纸带子没有 rim 是死板的根源）
- **元素配色**：风元素青绿→白、雷元素紫→白、岩元素橙黄→白。每个元素都有 base color → tip color 双色 lerp
- **Bloom 必备**：HDR color 强度 > 1.0 的 emissive，配合 post-process bloom 才能产生"光"的感觉

**Unity 复刻可行性**：高。URP 自定义 ShaderGraph 即可，不需 HDRP。`_DayNightT` 单 uniform 控 base/tip color lerp。

**参考**：
- https://www.cnblogs.com/DenZi/articles/15484026.html (米哈游卡通渲染分析)
- 知乎NPR shader系列 https://zhuanlan.zhihu.com/p/569862136 (Unity Shader入门精要)

### Case 2 — 《塞尔达：旷野之息》神庙光柱（Shrine Beacon）

**做法关键点**（业界公认的"光柱"标杆）：
- **不是单一 ribbon，是 4-6 层叠加体**：
  - (a) 中心实心圆柱网格，溶解 shader（vertical noise dissolve）
  - (b) 外层透明圆柱，rim fade（Fresnel 边缘亮中间暗）
  - (c) 上升粒子（spark）从底部喷涌
  - (d) 底座地面装饰（rune ring 圆环投影）
  - (e) 顶端云雾（soft particle 散开）
- **昼夜行为**：
  - 白天：低饱和、亮度 0.6-0.8、bloom 弱、距离淡出快
  - 夜晚：饱和度高、亮度 1.5-2.0、bloom 强、距离淡出慢（夜里光柱要"刺破天空"）
- **远近 LOD**：
  - 近距离（< 5m）：全套 5 层 + 粒子全开
  - 中距离（5-30m）：保留中心圆柱 + rim fade + 顶端云雾，关粒子
  - 远距离（> 30m）：仅保留中心圆柱 + 简化 rim，关 dissolve noise，关粒子，alpha 衰减

**Unity 复刻可行性**：极高。这正是 Cairn cone 的目标范式。当前 cone (inner+outer 双圆台) 已经接近 (a)+(b) 两层，缺 (c) 上升粒子的脱离感、(d) 底座装饰、(e) 顶端云雾。

**参考**：
- https://github.com/topics/zelda-breath-of-the-wild
- 知乎《Unity Shader学习:体积光》 https://zhuanlan.zhihu.com/p/425495211

### Case 3 — 《Sky:光遇》(Sky: Children of the Light) 精神信标

**做法关键点**（thatgamecompany 的极简美学）：
- **核心思想：少即是多**。信标是单层柔和光柱 + 缓慢上升的粒子点 + 环境雾混合
- 用 **soft particle depth fade**：粒子接触几何体时 alpha 自动衰减，避免硬边
- **梦幻调色板**：低饱和、高明度，色相在「淡蓝-淡紫-淡粉」之间漂移（不像原神那样高饱和）
- **环境融合**：信标顶端 alpha fade 到 fog color，让信标"溶进"天空，没有突兀的截断
- **节奏感**：粒子上升不是匀速，是 ease-out（底部快、顶部慢），形成"灵气抽离"感

**Unity 复刻可行性**：高。URP soft particle 是内置 keyword (`SOFTPARTICLES_ON`)，`_CameraDepthTexture` 已在 URP renderer feature 默认开启。

**关键洞察**：用户说"渐入浅色"很可能就是这种 thatgamecompany 风格——比《原神》更含蓄。Cairn 是 AR app，环境是真实世界，过亮过饱和会"出戏"，光遇式克制配色更适合。

### Case 4 — 《死亡搁浅》(Death Stranding) 信标 / 路标视觉

**做法关键点**（小岛工作室 Decima 引擎）：
- 信标是「**反重力柔光柱 + 漂浮粒子 + 投影光环**」三件套
- 关键差异：粒子不是从底部"喷"出去，而是从空气中**凝结**出来（spawn 时 alpha=0，在生命周期前 30% lerp 到 1）
- **虚化层叠**：3 层圆柱内嵌，每层 alpha 0.3-0.5，叠加产生"体积感"
- **信号波纹**：底座有 expanding ring 周期扩散（波纹半径 = `(_Time.y * speed) % maxR`，alpha = `1 - radius / maxR`）

**Unity 复刻可行性**：中-高。波纹环很简单（一个 quad + ring shader），凝结粒子需用 ParticleSystem 的 lifetime alpha curve。

**关键洞察**：用户说的"脱离感"在死亡搁浅里实现得最强——粒子不"贴"在地上，是悬浮凝结。Cairn 当前 cone 是从地面"长"出来，加凝结粒子可立刻打破"纸带子"印象。

### Case 5 — 《Apex Legends》复活信标 / 重生信标 (Respawn Beacon)

**做法关键点**（Source 引擎的工程化范例）：
- **核心是一根半透明 cylinder mesh + 内部高速 UV scroll noise**：
  - mesh 是普通圆柱（low-poly，8 段）
  - shader 用两层 noise，垂直 UV scroll，速度差 3-5x
  - 用 `frac(uv.y - _Time.y * speed)` 制造无限循环
- **顶部消散用 dissolve mask**：vertex.localY 高于 0.85 时 alpha smoothstep 到 0
- **远距离自动收缩**：距离 > 50m 时 mesh 半径加宽（让远处也能看见），alpha 略降
- **死锁信号 vs 复活信号**：用 `_BeaconType` int 切换 base color（红 vs 蓝），不重新 spawn shader——单 shader 多 type 的工程范式

**Unity 复刻可行性**：极高。这是最朴素也最有效的"光柱"做法，约 80 行 shader 代码。`_BeaconType` 思想正好对应 Cairn 的 5 type（air/water/fire/earth/spirit），单 shader 用 enum 切色。

**参考**：
- 知乎《Unity Shader 实现 X光效果》 https://blog.csdn.net/u012871784/article/details/49475049 (溶解 shader 基础)
- 《Unity透明边缘发光Shader实现》 https://blog.csdn.net/batman1208/article/details/130507492

### Bonus Case — Tilt Brush "Light" / "Embers" 笔刷

**做法关键点**（Google 已开源 Tilt Brush，技术细节最透明）：
- Tilt Brush 的 `Light` 笔刷（开源后改名 Open Brush）核心是 **billboard ribbon + additive blend + UV.y noise scroll**
- 顶点流式生成（每帧根据 spline control points 生成 quad strip），没有预制 mesh
- shader 关键三件：
  1. `_FlowSpeed` UV scroll
  2. Fresnel rim light
  3. HDR emissive `_EmissionStrength`
- "Embers" 笔刷在 Light 基础上 + 噪声扰动顶点位置（vertex shader 里用 simplex noise 偏移 worldPos.xz）

**Unity 复刻可行性**：极高。Open Brush 整套 shader 在 GitHub 开源（Apache 2.0），可直接抄思路。

**关键洞察**：对 Cairn cone strand 的核心启示——**ribbon 不能是死板矩形 mesh**，需要 vertex shader 微扰（noise displace）让丝带"飘"起来。当前 Cairn ribbon 如果是规则 mesh，就是用户说的"死板纸带子"根源。

## §2. 关键问题清单 — 业界做法答复

### 2a. "脱离感"怎么实现？

业界 4 种方案：

| 方案 | 做法 | 优劣 |
|---|---|---|
| **A. 底部断开** | mesh 从地面上方 0.1-0.3m 开始，不接触地面 | 最便宜，最不真实 |
| **B. 底部 alpha fade-in** | 底部 0-15% 高度做 smoothstep 渐入；底部不可见，越上越实 | 简单，效果好。**Cairn 推荐起步** |
| **C. 凝结粒子伴随** | mesh 上升 + ParticleSystem 在 mesh 周围 spawn alpha=0 → 1 → 0 的小光点 | 死亡搁浅范式，效果最强 |
| **D. 整体上飘** | 顶点 vertex shader `worldPos.y += _Time * speed`，mesh 实际持续位移；底端用 alpha 遮 | 最贵但最有"灵气"。Tilt Brush Embers 路线 |

**推荐 Cairn 用 B + C 组合**：基础 alpha fade-in（B）已经能解决"脱离感"，叠 5-15 个 spawn 粒子（C）立刻有死亡搁浅级品质。

### 2b. "渐入浅色 + 顶端淡出" shader 实现

**标准 pattern**（业界通用）：

```hlsl
// vertex
float heightT = saturate((worldPos.y - _BaseY) / _Height);   // 0..1
o.heightT = heightT;

// fragment
float fadeIn  = smoothstep(0.00, 0.15, i.heightT);   // 底部 0~15% 渐入
float fadeOut = 1.0 - smoothstep(0.85, 1.00, i.heightT); // 顶部 85~100% 渐出
float alphaMask = fadeIn * fadeOut;

float3 baseColor = lerp(_BottomColor, _TopColor, i.heightT); // 底深→顶浅
col.rgb = baseColor;
col.a = baseColor.a * alphaMask;
```

来源：GLM chat 综合 Ronja shadertutorial、catlikecoding、URP shader graph 模式。两个 smoothstep 是业界默认手法。

### 2c. "昼夜变化" 业界参数化

**3 种主流方案**：

| 方案 | 复杂度 | 适配 Cairn |
|---|---|---|
| **单 uniform `_DayNightT` (0..1)** | 极简 | **推荐**。0=白天 / 1=黑夜，主代码 lerp `_DayColor → _NightColor`、`_DayBloom → _NightBloom` |
| **LUT 切换** | 中。预制 day.png / dusk.png / night.png 3 张色卡，按 sun height 选 | 适合多状态过渡（黄昏） |
| **多光源 blend** | 重。Directional sun + Point moon 各自照明，按时间衰减 | 太重，不适合 AR 移动端 |

**推荐 Cairn**：单 uniform，配 4 个 color 属性（_BaseColorDay/_BaseColorNight/_TipColorDay/_TipColorNight）+ 1 个 bloom 强度 lerp。**全局 manager 写 `_DayNightT`，所有 cone/ribbon/particle 共享**。

### 2d. "近远 LOD" 业界做法

**3 层做法**（Apex/Zelda/原神 都这么做）：

```
distance < 5m   (Hero):  full mesh + dissolve noise + 粒子全开 + bloom 强 + rim light
5 ≤ d < 30m    (Mid):    full mesh + dissolve noise + 粒子半数 + bloom 中
30 ≤ d < 80m   (Far):    简化 mesh (8段→4段) + 关 noise + 关粒子 + 加 alpha 距离衰减
d ≥ 80m        (Cull):   不渲染
```

**实现方式**：
- C# `Update()` 里算 distance to camera，写 MaterialPropertyBlock 的 `_LODLevel` (0/1/2)
- shader 里 `if (_LODLevel == 2) skip noise sample;` （或用 shader_feature multi_compile 出 3 个变体）
- 粒子开关：直接 `particleSystem.emission.enabled = lodLevel < 2;`

**性能要点**：mobile AR 60fps 严格预算，远距 cone 必须收敛到 8 indices 以内（一个简单圆柱 + 1 张 alpha 贴图），noise sample 要砍掉。

### 2e. "灵气感 / 能量感" 视觉关键词清单

业界共识的 7 个关键词（任意 cone shader 至少要有 4 个）：

1. **HDR Emissive (color > 1.0)** — 没有 HDR + bloom 就没有"光"的感觉
2. **Bloom Post-Process** — URP Volume 配，必备
3. **Fresnel Rim Light** — `pow(1 - dot(N, V), _RimPow)`，边缘亮，灵气感来源
4. **2-Layer Flow Noise UV Scroll** — 单层是水波，双层是能量流。不同 speed/scale 叠加产生"无规律生命感"
5. **Soft Particle Depth Fade** — 接触面无硬边，URP keyword `_SOFTPARTICLES_ON`
6. **Vertex Displacement Noise**（可选）— vertex shader 里 `worldPos.xz += sin(uv.y * 10 + _Time)*0.05`，让 ribbon 微微飘，破"纸带子"
7. **Additive Blend + ZWrite Off** — 多层叠加才有"光"的累积感（ZWrite Off 保证不互相遮挡）

## §3. Cairn Unity 端可执行总结

> 给 Frontend Dev / Arch 看的"我们改什么、改到什么程度"清单。

### 3.1 Shader 改造（CairnConeCore + CairnConeOutline）

**当前问题诊断**（基于 git status `Resources/Materials/CairnConeCore.mat` 已 modified，Cone 已存在）：
- 推测当前 cone 是双层 cylinder + 简单 unlit，缺少业界标配的 7 个关键词中至少 4 个

**必加 7 项**：

| # | 项目 | 实现复杂度 | 性能成本 |
|---|---|---|---|
| 1 | HDR emissive `_EmissionColor`，强度 0.5-3.0 可配 | 简单 | 0 |
| 2 | URP Volume Bloom（如未开） | 简单 | 中（移动端 ~0.8ms） |
| 3 | Fresnel Rim Light | 简单 | 极低 |
| 4 | 2-layer flow noise UV scroll（一张 noise tex 两次 sample） | 中 | 低 |
| 5 | Vertex height fade-in (0-15%) + fade-out (85-100%) | 简单 | 0 |
| 6 | `_DayNightT` uniform → `_BaseColor/_TipColor` 4 个 lerp | 简单 | 0 |
| 7 | `_LODLevel` int → 远距 skip noise 分支 | 中 | 节省 |

### 3.2 粒子改造（凝结上升）

新增 `CairnConeMotes.prefab`（小光点粒子）：
- ParticleSystem，emission rate ≈ 8/s（近 hero） / 4/s（mid） / 0（far）
- 形状：cylinder 半径略大于 cone outer
- 生命 1.5-2.5s，velocity.y = 0.3-0.6 m/s（缓慢上升，ease-out）
- color over lifetime: `(0,0)→(0.2,1)→(0.8,1)→(1,0)` (alpha 凝结-持续-消散)
- Renderer：billboard，soft particle ON，additive blend
- 与 `_DayNightT` 同步：白天 mote color `#FFE6B0` 暖白，夜晚 `#A8D8FF` 冷蓝

### 3.3 LOD Manager（C# 单例）

`CairnRibbonLOD.cs` 已存在（git status 显示 untracked .meta） — 应实现：

```csharp
// 伪代码
void Update() {
  float d = Vector3.Distance(Camera.main.transform.position, transform.position);
  int lod = d < 5f ? 0 : (d < 30f ? 1 : (d < 80f ? 2 : 3));
  if (lod != _lastLod) {
    _propBlock.SetFloat("_LODLevel", lod);
    _renderer.SetPropertyBlock(_propBlock);
    _moteSystem.gameObject.SetActive(lod < 2);
    _lastLod = lod;
  }
}
```

### 3.4 DayNight Adapter（C# 单例）

`CairnDayNightAdapter.cs` 已存在（git status untracked .meta） — 应实现：

```csharp
// 伪代码
[Range(0,1)] public float dayNightT;  // 外部时钟驱动
void Update() {
  Shader.SetGlobalFloat("_DayNightT", dayNightT);
  // bloom intensity 也跟着 lerp
}
```

`Shader.SetGlobalFloat` 让所有 cone/ribbon/particle 自动同步，不用每个 material 单独写。

### 3.5 不要改的事项

1. **不要换 mesh 拓扑**。当前 `cairn_cone_inner.asset` / `cairn_cone_outer.asset` 已经是双层 cone，是正确架构。改 shader 即可。
2. **不要堆 4+ 层 mesh**。Zelda 5 层叠加是 console 预算，AR 移动端 2 层 + 粒子 + bloom 已是上限。
3. **不要用 HDRP**。URP 14 + Bloom + Soft Particle 已够，HDRP 在 ARFoundation iOS 兼容性是历史坑。

## §5. 决策建议（Arch + Frontend Dev 阅读）

**最少改动达成"不死板"的 P0**（按 ROI 排序）：

1. **+ Fresnel rim light**（30 行 shader 改动） → 立即解决"纸带子"无质感
2. **+ 顶部 alpha smoothstep 淡出**（5 行）→ 立即解决"消散"问题
3. **+ 底部 alpha fade-in**（5 行）→ 立即解决"脱离感"
4. **+ HDR emissive + URP Bloom**（2 行 + 1 个 Volume 配置）→ 立即解决"无光感"
5. **+ 2-layer noise UV scroll**（30 行）→ 立即解决"死板不流动"

P0 总工时：约 1 个 Sprint（含 5 张验证截图）。**这 5 项即可让用户从"不满意"提升到"可接受"**。

**P1（次 Sprint）**：DayNight uniform、Mote particles、LOD Manager。

**P2（再下 Sprint）**：vertex displacement noise、底座 rune ring、上升爆点效果。
