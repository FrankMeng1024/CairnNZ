Design rationale

Lens: 45-year-old NZ tramping club member. Uses Strava, Gaia GPS, PocketEarth. Reads every setting. Trusts apps that are honest.

Density decisions

  • Every row carries a sub-caption. Power users don't want to tap in just to learn what a setting does. "Night mode" tells them Dims map + UI · saves ~18% battery so they can decide from the list view alone.
  • Current value shown inline. Units row shows Metric (km, m, °C) on the right — no need to enter the modal to check current state.
  • Memory row is expanded stat line. Instead of just "47 places · 3 cairns", we surface 47 places · 3 cairns · 12.4 km² revealed · 89h tracked. This is the summary this user actually wants to see when they open Settings.
  • Version row is fully specced. v0.2.5 (build 47) · OTA O11 · iOS 17.4. Power users file bugs; giving them the exact build info in Settings saves back-and-forth.
  • Top-right of nav bar carries "Last synced 2h ago" — passive but reassuring signal that sync is healthy.

Section header treatment

  • All-caps small labels with a right-aligned sub-hint (e.g. 3 items · applied instantly, External links open in Safari). This mimics Gaia GPS's info-first approach — the header carries meta so the rows can stay clean.
  • Section titles are precise/technical: Preferences, Memory, About & Legal, Danger zone, Debug & Diagnostics. No fluff, no marketing tone.

Danger zone visual wall

  • Thicker red border (2px solid #e8b8b8) + tinted background (#fdf6f6) so it cannot be scrolled past accidentally.
  • Section sub-hint Irreversible after 7-day window sets expectation before the user even reads the rows.
  • Sign out uses subdued text (grey label); Delete account uses bold red — visual priority matches destructiveness.

Debug section (5-tap unlocked)

  • Rendered in a dark terminal-inspired panel so it's visually distinct from user-facing settings. Signals "this is developer territory".
  • Includes rich diagnostics inline: FPS 58 · mem 142MB · GPS 3.2s · net 89ms. A power user filing a bug report can screenshot this instead of asking us "what version are you on".
  • Cache breakdown (tiles 84MB · tracks 12MB · db 2.1MB) with total on the right — matches how Gaia and PocketEarth expose storage.
  • DEV tag in the top-right corner reinforces this is not part of the normal product surface.

Restraint

  • No hero image, no marketing copy, no "welcome back" — this user opens Settings to do a task, not to be entertained.
  • All animations limited to toggle switches. Zero decorative motion.
  • Typography scale is tight: 15px row label / 12px sub / 11px section header. Fits more information per screen without feeling crowded.
  • Warm off-white background (#faf7f2) rather than pure grey — carries the outdoor brand without shouting.
