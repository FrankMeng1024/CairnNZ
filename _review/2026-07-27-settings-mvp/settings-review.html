⚠️ 3 处覆盖 (subagent 反对我的推荐):
  • #7 Night mode: subagent 建议实装而不是删 — "AllTrails/Gaia/Komoot 都有, 3-5 天工作量小, 承诺一年多不做比没做更伤 trust". 5am/8pm 高山起步用户需要.
  • #13 Route Deviation: subagent 建议删而不是隐藏 — "Dead UI 没 option value, git 里代码永远在, 未来 20 分钟就能恢复, 隐藏反而增加每次 UI 改动的维护税".
  • #20 Debug Mode toggle: subagent 建议隐藏(5-tap 手势恢复)而不是保留 — "App Store 2.2 会因'production 里有 debug/demo 内容'驳回. 恢复 5-tap version 手势".
🎯 我遗漏的 5 项 (subagent 建议加):
  • P0 Sign in with Apple 审计: 有 Google 登录 → Apple 强制 (App Store 4.8). 不是 Settings 行, 是 Auth 屏必查.
  • P0 Location 权限文案: NSLocationAlwaysAndWhenInUseUsageDescription — 户外 App 审核员会盯这个, 文案模糊会驳回.
  • P1 "Report safety issue": mailto NZ DOC. 免费的信任信号 + 卸责我们自己没做安全功能.
  • P1 MetService 天气链接: 外链 (不真接 API). NZ hiker 出发前必看 MetService. 一个按钮建立 credibility 而不做真实现.
  • P2 Onboarding replay: "再看一次介绍" — reduces churn.
Subagent 明确反对加的: 111 SOS integration / PLB — RCCNZ liaison + massive liability, AllTrails 都不做, MVP 别碰.
