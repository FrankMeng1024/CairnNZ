# 偏移量打分锚点(Phase 4 主 agent + 独立 subagent 复审用)

**用途**: 防止主 agent 拍脑袋 + self-serving bias(把 Cairn 打得偏移小让自己开心)。

## 打分规则

每个 Phase 3 浮现的主题 → 打 0-5 分:

| 分数 | 含义 | 判定标准 |
|---|---|---|
| **0** | 完全对齐 | Cairn 现有实现完全符合用户真需求,证据链清晰 |
| **1** | 轻偏 | 大方向对,细节需调 |
| **2** | 中偏 | 方向对,实现方式和用户预期有差距 |
| **3** | 重偏 | 方向对,实现严重脱离(需要重构) |
| **4** | 错位 | 方向本身错了(需要 pivot) |
| **5** | 空白 | Cairn 完全没做,而用户强烈需要(**注意:空白 ≠ 错,可能是正确的空白**) |

## Anti-Bias 机制(Review 1 要求)

### 独立 subagent 先打

**顺序反过来**(Review 1 的 v333 anchoring bias 教训):

1. **独立 subagent 先打**(不看主 agent 意见)
   - 输入: 主题清单 + Cairn 功能描述(不含主 agent 打分)
   - 输出: 每主题 0-5 打分 + 理由
2. **主 agent 后看** + 独立打分
3. **对比**: 冲突 > 20% 的主题 → 用户裁决(不再是主 agent)

### 复审强制

打完全部主题后:
- 全表 review 是否系统性偏低(全部 ≤ 2 就是 self-serving 信号)
- 如果 > 70% 主题打 0-1 → 让第 3 个独立 subagent 复审
- 冲突 > 20% → 用户最终裁决

## 6 条锚点示例(校准用)

### 锚点 A: "N 年后回看" 主题
- **用户真需求**: 装完 5 年后打开还能感动
- **Cairn 现状**: fog + marker + session 都能 N 年后看到,backend 有持久化
- **打分**: **0(完全对齐)**
- **理由**: 三层实现(fog 迷雾 / marker 短文 / session 轨迹),数据主权在 backend + 客户端

### 锚点 B: "私密分享给亲密好友" 主题
- **用户真需求**: 想给几个亲密人看,不想公开
- **Cairn 现状**: 好友订阅 max 5 个 fog + marker 3 级权限(personal/friend/public)
- **打分**: **1(轻偏)**
- **理由**: 大方向对,5 个 fog 订阅上限可能不够(家庭 + 徒步团 = 6-10 人)

### 锚点 C: "手账 + On This Day 提醒"
- **用户真需求**: 每年今天推送 5 年前的今天记录
- **Cairn 现状**: 有 memory 但无 push 通知,无"on this day"回顾
- **打分**: **3(重偏)**
- **理由**: 有基础数据但缺关键 utility(push + retrospection),Day One 靠这个粘住 8 年老用户

### 锚点 D: "多设备云同步"
- **用户真需求**: iPhone + iPad + Web 都能看
- **Cairn 现状**: 后端同步 OK,但 iOS 独占,无 Android/Web
- **打分**: **3(重偏)**
- **理由**: 严重限制用户扩展,尤其 NZ 徒步者混用设备

### 锚点 E: "商业化定价"
- **用户真需求**: 愿付 $3-8/月 for utility(高精度 GPS / 大离线区 / 多设备)
- **Cairn 现状**: 未定
- **打分**: **5(空白)**
- **理由**: 完全没做 → 是**待补的空白**,不是错

### 锚点 F: "AI 集成日记辅助"
- **用户真需求**: Day One 用户抱怨 AI 侵入(见 r/dayoneapp 5 帖 AI 焦虑)
- **Cairn 现状**: 无 AI
- **打分**: **5(空白)**
- **理由**: 完全没做,但**这是正确的空白**(Cairn "反 AI 侵入" 差异化定位),不需要补
- **特别注释**: 打 5 但不代表要补 —— 结合 Q3 竞品数据判断

## 打分完成后的 Sanity Check

1. **系统性偏低检查**: 平均分 < 1.5 = self-serving bias 信号
2. **系统性偏高检查**: 平均分 > 3.5 = 过度悲观(可能主 agent 也有反向 bias)
3. **合理分布**: 一般应该 0-2 占 40-60%,3-4 占 20-30%,5(空白)占 20-30%
4. **冲突主题清单**: 主 agent vs 独立 subagent 打分差 ≥ 2 的主题,写单独文件让**用户裁决**

## 最终决策权

**冲突主题的最终决策权在用户,不是主 agent。**

Review 1 说过:"主 agent 打分不就是它自己一个人的主观判断?" —— 这条锚点表就是防这个的护栏。
