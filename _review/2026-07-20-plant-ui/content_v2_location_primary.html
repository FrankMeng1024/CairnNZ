交互细节 (让 UI 更"炫酷")

保留 handbook 风格,加以下微交互质感 (纯 code 层可实现,不改设计):
🎬 Location chip → sheet 展开
- 点击时 chip 有 spring scale 0.97 弹跳 (haptic light)
- Sheet 从底部 360ms spring 弹入,background dim 淡入
- 候选 list staggered fade + slide-up (每个 40ms delay,像卡片轻轻落下)
- 选中候选后 chip pulse 光晕 + haptic success,sheet 关闭

🎬 Type 切换
- 选中 chip 有 underline 从中心展开 240ms
- 未选中的 chip 轻微 desaturate (opacity 0.7),视觉重心明确
- 切换时 haptic selection tick

🎬 Preview map
- Pin 上有 持续 breathing pulse (类似 v418 GPS PulseDot,更慢 3s 循环)
- 首次进入页面时 pin drop-in bounce (从上方 20px 落下,300ms spring)

🎬 Body 输入
- 键盘弹起时,页面 smooth scroll 到 body field 附近 (不遮挡)
- 字数接近 200 时 counter 从 muted 渐变到 amber (150+),超过变 red
- Confirm button 禁用时轻微 desaturate + 无阴影 (body 空时)

🎬 Confirm 按钮
- 内容有效时 button 有 subtle inner gradient shimmer (very slow,像微风吹过草地)
- 点击 → scale 0.96 spring + haptic success + 3 石头堆叠动画 (AuthScreen 已有的 AnimatedCairn 复用) → nav.replace to MarkerDetail

🎬 Sheet 内候选选择
- 候选点击时 整行 spring scale 0.98 + subtle sage tint
- 已选那行 border 用 sage gradient (不是纯色,更细腻)
推荐: 方向 A (preview map + location chip overlay)
理由:
• Location 是 marker 身份,应该在页面上部,视觉优先
• Preview map 提供**视觉锚**,让用户填 body 时"看着地方写"
• Chip overlay 在地图上比独立 row 更 elegant
• 现有 handbook 风格延续,不引入新 pattern

妥协: preview map 占 120h,body field 只有 100h。但 200 字 body 显示 5 行足够。
剩余讨论点:
1. Preview map 显示 satellite (卫星) vs outdoor (线条地图)? — Step 2 已经允许切换,Step 3 沿用用户选择就行
2. Location 输入框放顶部 chip vs 底部独立 row? Demo A vs Demo B 对比
3. 有网 vs 无网 chip 样式差异? 无网显示 GPS -40.877, 175.831 代替名字
