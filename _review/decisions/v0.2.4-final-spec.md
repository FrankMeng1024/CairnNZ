# v0.2.4 最终产品规格(用户拍板,2026-06-12)

## 核心产品语义

> **远箭头引导 + 近实化仪式**
> 跨年跨设备分档兑现 — 城区那棵树下,荒野那一带

## 行为剧本

### 1. 远场(>15m)
- 屏幕显示**箭头**指向 mark + 距离标签 "23m →"
- **不画 cairn 实体**(避免漂)
- 跨设备跨年:箭头方向靠 GPS+罗盘(误差 5-10m 用户不在意)

### 2. 接近场(5-15m)
- 箭头开始**距离脉动反馈**(逐级闪烁加重 + 触觉震动)
- 仍**不画 cairn 实体**

### 3. 触发实化(三条件全满足)
- 用户走到 ≤5m
- ARKit 扫到那一带地面
- 相机朝向 mark
- → cairn **从地面"长出来"**(仪式动画 = variant_C_3D.html 的 0→1s 序列)

### 4. 兜底机制(三层)
- **L1 距离脉动**:5/3/1/0.3m 各级反馈递增
- **L2 自动放宽**:≤3m 停留 >5s 还没出现 → 接受任何 plane(不挑 floor)
- **L3 引导提示**:≤3m 停留 >10s → 屏幕提示"慢慢转动手机扫描周围地面"

### 5. 严格无应急按钮
- 用户决定:**不加"就在这里"应急按钮**,保持严谨
- 找不到率预期 <1%(对标 Pokemon GO 实测)

## Cairn 已经实化后的行为(铁律)

- **本体永远不动**
- 任何 Y/位置调整必须**用户无感知**或**预期内潜规则**:
  - App 冷启动 / loading 时 ✅
  - Cairn 在屏外时 ✅
  - 用户主动"重新校准" ✅
  - **已 visible + 用户看着** ❌

# v0.2.4 Reviewer 修订后铁律(2026-06-12,Reviewer 1+2 报告后用户拍板)

## 三条铁律(产品必须遵守,绝不妥协)

### 铁律 #1: cairn 必须在地面,且不能飘
- **L2 兜底修正**:5s 后**仅放宽距离**(≤5m → ≤8m),plane 类型仍**严格 floor classification**
- **plane 验收硬条件**(LiDAR 设备):classification == floor && 法线偏差 ≤20° && 面积 ≥0.5m² && 高度低于相机 1m && extent 稳定 ≥1.5s
- 非 LiDAR 设备:用 raycast hit + classification + 高度判定
- **绝不接受**:车顶 / 桌面 / 雪堆 / 人头顶 / 墙面 / 积水反射

### 铁律 #2: 档位锁定 — cairn 一旦 anchored 本 session 不切
- 档位评估**只在 cairn 未 visible 时**做(屏外、loading、初次 spawn 前)
- 一个 cairn 一旦 anchored 到某档(ARWorldMap / Geospatial / GPS+IMU),**本 session 永不切**
- 下次冷启动重新评估档位
- 决策矩阵:
  - 1. 本机 ARWorldMap 重定位成功 + confidence >0.7 → 用此(0 偏移,but ≤24h 可信)
  - 2. ARCore Geospatial 可用 + horizontalAccuracy <3m → 用此(1-3m)
  - 3. GPS+IMU 兜底 → 用此(5-15m)

### 铁律 #3: 实化三条件锁存
- 首次三条件齐后,**本 session 这个 cairn 永久 visible**,不再回查条件
- 仪式动画启动后所有条件 freeze
- 用户头摆动/相机方向变化 → 不影响已实化的 cairn

## Reviewer 1+2 全部修订(15 条)

1. **L2 改为放宽距离不放宽 plane** ✅(铁律 #1)
