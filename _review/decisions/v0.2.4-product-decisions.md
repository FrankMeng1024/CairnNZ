# v0.2.4 产品决策(用户拍板,2026-06-12)

## Plant 落地的核心产品语义

**用户原话:**
> "我们之前讨论过 你说过大概率地面不会出问题 如果是扫大石头或者桌面也能扫
>  但是下次打开会因为GPS抖动 落地到地面 我只看最终能落地到地面"

**翻译:**
- Plant 时接受任何表面(地面/桌面/石头/草丛上),不强制 reject
- **下次打开 app(新 session)时,mark 必须落到当下扫到的真实地面 Y**
- 用户不在乎 plant 那一刻是否离地,在乎"重开时贴地"

**这跟 Branch B 报告里的"plant 时强制 reject 非地面"是不同设计 — 用户语义优先**

## 6 项决策

1. **ARMeshManager**:默认开;所有阈值/分支/hysteresis OTA-toggleable
2. **Plant 兜底**:保留 plane.center fallback **作为 plant 时的最后兜底**(允许桌面/石头);
   但 mark 持久化时同时记录 ARKit 世界 anchor(session 内不漂);
   重开 app 时,**新 session GPS 重定位 + 重扫地面 → 强制 snap 到当下真实地面 Y**
3. **PlaneEstimated**:删除(50cm+ 误差,违反"必须在地面"目标)
4. **验收**:不做 dev 屏幕显示;telemetry 上后端 + 用户真机 review
5. **OTA**:所有新阈值/分支都通过 CairnGlobals 暴露
6. **不 push github,不 EAS build,不 OTA(除非明确确认)**

## 三个核心问题的产品形态

### Branch A (anchor 不漂)
- 同 session 内:ARKit 世界坐标 anchor,绝不依赖 GPS
- 跨 session:GPS 找到 cluster 大概位置(<10m)→ ARKit 世界坐标 + 真实地面 Y 重锁

### Branch B (贴地)
- 同 session 内:plant 用 hit.pose(不用 plane.center),允许桌面/石头/草丛
- 跨 session:重开时,如果当前 session 扫到地面,**强制 snap mark 到当下地面 Y**(不论原 plant Y)
- LiDAR 用 mesh classification(1-3cm),无 LiDAR 用 plane polygon raycast

### Branch C (视觉)
- 1:1 移植 variant_C_3D.html(仪式 / 圆环 / SDF rune / 5 type 粒子)
- 丝带从死板纸带 → 脱离 + 渐入浅色 + 淡出 + 昼夜近远差异(业界调研驱动)
- 底座(青色 pebble + 圆环)保留
