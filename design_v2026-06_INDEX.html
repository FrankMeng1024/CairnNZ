Cairn AR v0.2.3 — 4 Design Variants 对比

每个变体都是 1 个完整的 2D 动态设想图：5 type 切换 + 1 秒种植仪式 + 阵图 + 光带 + 3D 文字标签。点击变体内的"Replay 仪式"按钮可重播。

这 4 个变体是按"产品哲学"差异化设计的，不是简单的色彩变化——它们代表 4 种**完全不同的视觉性格**。请挑一个 (或两个组合) 作为 Stage 8 的 3D 实施基线。

A · 静默路标 (Stoic Wayfinding)

朴素圆环 + 静态光带 + 平视卡片。Death Stranding 路标 + Apple Find My placemark。
✓ 户外日光下最可读 ✓ 视觉密度低不抢戏 ✓ 实施成本最低
✗ 缺少"魔法时刻"
独立打开 ↗

B · 生灵呼吸 (Bioluminescent Breath)

柔软发光圆盘 + 8 条生物丝缕 + 萤火虫粒子。Avatar 潘多拉 + 宫崎骏 kodama。
✓ 夜晚 / 林间最美 ✓ 神秘氛围浓 ✓ 视觉差异化最强
✗ 户外强光下可见度受影响 ✗ 实施成本最高 (8 条 ParticleSystem + shader)
独立打开 ↗

C · 时间锚 (Temporal Anchor / DS Strand)

双层旋转阵图 + 6 条 DS 化学发光丝 + 时间戳卡片 (X 天前由 Y 留下)。直接致敬 DS。
✓ 异步社交温度最强 ✓ 时间戳是 Cairn 真正的护城河 ✓ DS-meta 灵魂亲属
✗ 需要后端真实"留言者+时间戳" (PRD3 已有 marker.created_at, 可用) ✗ 标签信息密度高
独立打开 ↗

D · Topo50 圣物 (NZ Cartographic)

同心等高线 + sepia 印章 + 测绘虚线 + cream 底卡片 + 经纬度+海拔。LINZ Topo50 致敬。
✓ NZ 用户一眼识别本土 ✓ 与 PRD3 E-013 离线 Topo50 + E-016 DOC 橙完全协调 ✓ 竞品做不到的本土真实感
✗ 海外用户可能"看不懂"为何这种风格 ✗ sepia 在 AR 真实场景下与背景融合度需要测试
独立打开 ↗
