# Cairn 算法思想 v6.5 — Challenge 报告

**评分:88 / 100**(目标 90+,差 2 分,有 P0 1 个 / P1 3 个仍需思想层修补)

---

## 一、总体评价

v6.5 相比 v6.4 在三处做出了明确收敛:
1. SUSPICIOUS **唯一入口** = 向下急转
2. 严重度退出"是否进入"判定,只参与"处理力度"
3. 复活拆成"资格 + 初始寿命加成"两层

这三处都是好修补——把"什么时候进 ICU"和"进了 ICU 之后多狠"解耦,逻辑结构更干净。**但是这三处修补本身在边界场景上引入了新的逻辑空隙**,以下逐项 challenge。

---

## 二、P0 漏洞(必须思想层回答)

### P0-1:**慢性恶化 mark 永远进不了 SUSPICIOUS**

**场景**:Routeburn supply mark,远期 200 like 2 report。新季节资源真的消失了,但举报不是集中爆发——而是每周 2-3 条「资源已消失」report 缓慢累积。**6 个月内**累计 60 条 report,但任意时间窗口内"近期占比 vs 远期占比"的变化率都 **不构成"剧烈"**——因为信号是均匀分布的。

**思想推导**:
- 「急转」必须是占比剧烈变化 → 慢性恶化不剧烈 → 不进 SUSPICIOUS
- 「持续争议维持 HEALTHY」→ 这种 mark 整个生命周期都是 HEALTHY
- 寿命优先 → 等寿命走完才 DEAD,但 supply 类 base 寿命可能很长
- 续命系数 → 每周 2-3 条 like(假设来回打平)还在续命

**结果**:一个**真实变质的 mark 在 HEALTHY 状态下挂半年甚至更久**,误导无数陌生人,直到自然老死。

**核心矛盾**:v6.5 把 SUSPICIOUS 入口锁死成"急转",同时又说"持续争议维持 HEALTHY"——但忽略了**第三种状态:慢性单向恶化**。它既不是争议(50:50),也不是急转(剧烈变化),它是**温水煮青蛙**。

**修补方向(只说思想层)**:
SUSPICIOUS 入口除"急转"外,应补一个**累积单向偏离**判定:
- 不是看变化率,而是看"近期 N 个窗口的方向是否单调一致"
- 占比驱动 + 单调性识别,不引入数字
- 思想层只需回答:**急转(快)和单向漂移(慢)是 SUSPICIOUS 的两个并列入口**

如果产品哲学坚持"差 mark 让用户自己判 + UI 占比展示",那就要在 §九 明确列入"不防慢性恶化"——但这等于放弃了 supply / danger 类 mark 的价值担保。

## 三、P1 漏洞

### P1-1:**复活两层判断的"历史信誉"在反复死亡复活后的语义不清**

**场景 P 已经提到**:商业 mark 多次复活 → 历史资产稀释。但思想层没回答:

**复活后 mark 的"历史"指什么?**
- 选项 A:**新 mark 完全清零**——那"历史好评决定初始寿命加成"无源可查
- 选项 B:**继承上一世的 like/report**——那"复活 = 新 mark"不成立(死了又没死)
- 选项 C:**保留某种压缩信誉指纹**——那这个指纹的衰减规则没说

§六决策 1 写「复活 = 新 mark(寿命从 base 开始)」,又写「历史好评 → 初始寿命加成」——这两句**互相打架**。如果是新 mark,为什么有历史?如果继承历史,为什么是新 mark?

**修补方向**:思想层必须明确:复活后 mark 在"治疗时钟 / 急转识别"层面是新 mark(从零累积),但在"初始寿命基线 / 资格判断"层面引用前世。这两个层面的隔离规则要写清。

### P1-2:**"急转 + 强心剂回退"在向下急转刚发生瞬间的边界**

**场景**:mark 刚向下急转进 SUSPICIOUS,**同一小时内**作者朋友圈喊话,30 个真人到场刷 like —— 占比再次剧烈变化(向上)→ 强心剂 → 回 HEALTHY。

思想层说"门槛对称,简单设计,不防复杂攻击,允许来回切"——这没问题。但**新问题**:回 HEALTHY 后,刚才那波向下急转的 report 还**留在数据里**。下一个滑动窗口看,远期是大量 like、近期是 report+like 混合,**会不会立刻又触发一次向下急转**?

如果会,那就是震荡(SUSPICIOUS ↔ HEALTHY 高频抖动),用户体验极差(UI 警告标闪烁)。如果不会,**思想层没说清楚为什么不会**。

**修补方向**:思想层需要回答"状态切换后,触发上一次切换的信号是否在下一窗口被重新计入"——简单对称不等于震荡可接受。建议引入**滞回(hysteresis)**思想层概念:刚切过的状态有最短稳定期,期间相同方向的信号被吸收。

### P1-3:**SUSPICIOUS 中"寿命优先"和"续命系数"的优先级在边界 case 模糊**

§四写「续命系数在 SUSPICIOUS 中依然有效」+「寿命优先」。Case J 描述:寿命剩 1 天 → 50 like → 续命到 30 天 → 继续 SUSPICIOUS → 30 天内没强心剂 → DEAD。

**问题**:50 like 同时是**强心剂候选**(向上急转)。思想层没说清:
- 这 50 like 是 **先续命再判强心剂**?——续到 30 天,然后判强心剂回 HEALTHY → 进 HEALTHY 后又续一次?
- 还是 **同时判**?——续命 + 回 HEALTHY 一起发生?
- 还是 **互斥**?——只能续命 OR 只能强心剂?

每种解释推出的最终状态不同。Case J 的描述隐含了"续命但不算强心剂",但**为什么 50 like 不算向上急转**?这违反了"急转双向识别"原则。

**修补方向**:思想层明确续命与强心剂是**两个并行通道**,触发条件不互斥,同一波互动可同时计入两边。然后说清"既续命又强心剂"时状态切换的优先级。

### P1-4:**"治疗机会 = 新陌生人投票"在 mark 已被全村互动完后失效**

**场景**:小村 mark,200 个本地用户,180 个已经投过票(永久 1 票)。某天 mark 进 SUSPICIOUS。**剩下 20 个潜在投票者**,即使全部到场也只有 20 个治疗机会。如果 base 治疗机会比例需要更多,**这 mark 实际上失去了所有治疗可能**——不是因为变差,是因为人投完了。

时钟 B 由治疗机会驱动 + 没新投票时钟 B 暂停 → mark 卡死在 SUSPICIOUS,等时钟 A 走完 DEAD。

**问题**:思想层"占比驱动"在小池子里不成立——分母枯竭。

**修补方向**:思想层需要回答**潜在投票池**这个概念,或者明确接受"小村 mark 失去治疗机会 = 自然走完时钟 A 即可"。后者其实可接受(寿命优先兜底),但思想层没明说,应该补一句"治疗机会枯竭等价于无新投票,由时钟 A 兜底"。

## 八、结论

v6.5 是一次**结构性收敛**——从模糊的多入口 SUSPICIOUS 收紧成单入口、严重度解耦、复活两层化,这是真正的进步。但收紧本身让"慢性恶化"从原本的灰区跌出了算法视野,这是 P0 必修。其他 P1 都是边界对齐问题,工作量小。

**修补完 P0 + 至少一个 P1,可达 92+。**

**核心建议**:不要再加复杂规则,而是把"急转"这个支柱**升级为"占比方向变化"**——同时涵盖剧烈(快)和单调(慢)两种方向变化,保持思想的简洁对称。
