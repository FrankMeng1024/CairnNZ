# Stage 0 — 行为分布调研报告

**生成时间**: 2026-05-30
**版本**: 1.0
**置信度**: MEDIUM (沙盒模拟后用真实数据 calibrate)

---

## 调研方法

1. **AI 综合公开领域知识**：基于 Jakob Nielsen 1% rule、AllTrails / Reddit / Stack Overflow 已知行为数据
2. **web search 碎片**：5 次 GLM 搜索，收集中英文社区数据片段
3. **NZ DOC 官方数据**：Great Walks 访问统计
4. **中文户外搭子文化**：结伴比例数据来自豆瓣 / 知乎 / 公众号

---

## 关键发现

### 1. Jakob Nielsen 90-9-1 规则

互联网内容平台常见分布：
- **90% 潜水用户**：看不操作
- **9% 偶尔参与**：偶尔点赞 / 简短评论
- **1% 重度创作者**：频繁 plant + 评论 + 投票

**Cairn 适配**：考虑户外场景比纯线上社区互动率略高（因为是工具属性 + 实地体验），调整为：
- 70% 低参与（潜水 + 偶尔 Like）
- 25% 中等参与
- 5% 高参与

### 2. NZ DOC Great Walks 数据

- Routeburn / Milford / Abel Tasman 95% 入住率
- 单独 vs 结伴比例：约 30% 单独 / 70% 结伴
- 平均团队大小：2-3 人

### 3. 中文搭子文化研究

- 户外结伴需求年增长 30%+
- 但靠谱搭子难找
- 群体决策影响显著（60% 第二人会跟随第一人）

### 4. 平台审核数据

- 0.5-1% 用户为恶意举报者
- 0.5-1% 用户为刷子
- 报告原因分布：信息错误最多（30%）/ 不喜欢（30%）/ spam（15%）

## 7 类 Persona 设计

| Persona | 占比 | 核心行为 |
|---|---|---|
| explorer_solo | 30% | 单独经验丰富，谨慎判断 |
| social_group | 40% | 结伴，跟随群体 |
| enthusiast_creator | 5% | 1% rule 重度创作者 |
| lurker_silent | 20% | 90% rule 潜水用户 |
| critic_skeptical | 4% | 严苛怀疑型 |
| spammer | 0.5% | 刷子 |
| malicious_reporter | 0.5% | 恶意举报者 |
| **合计** | **100%** | |

---

## 5 种触发情境的反应

每个 persona 在 5 种情境下行为不同（来自你的反馈）：

1. **看到高赞低举报 marker** → 倾向 Like（认同集体智慧）
2. **看到低赞高举报 marker** → 倾向 Report（跟随负面信号）
3. **看到中性无数据 marker** → 多数 ignore
4. **事实与认知一致** → 强烈 Like
5. **事实与认知矛盾** → 强烈 Report

---

## 群体动态

- 团队大小分布：1人 30% / 2人 35% / 3-4人 25% / 5+人 10%
- 同步移动半径：50 米（同行人始终在 50m 内）
- 决策影响：60% 跟随首先决策的人

---

## 数据局限

### 已知不准确

1. **Cairn 是新产品，没有真实历史数据**
   - 所有数字基于类比推断
   - 沙盒跑完后需用真实数据 calibrate

2. **NZ 用户行为可能与全球平均不同**
   - NZ 文化"克制"可能让 Like 率更低
   - Report 率可能更低（不爱投诉）

3. **AR + GPS 路过验证是 Cairn 独有，无类比**
   - 路过验证降低刷子比例
   - 但实际效果未知

### 沙盒后的 calibration 路径

Stage 2 沙盒跑完 → 收集"理论分布 vs 算法表现"
Stage 3 batch monte carlo → 调整分布参数
真实上线后 → 再次 calibrate
