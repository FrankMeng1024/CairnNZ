## 一、修补点是否引入新逻辑漏洞?

### 修补 1:慢性恶化 → 转化率系数自动处理 ✅
合理。慢性恶化的本质是 like/view 转化率持续下行,续命系数自然衰减,寿命走完即死。无需 SUSPICIOUS 干预。无新漏洞。

### 修补 2:复活 = 带历史记录的 mark ✅(有一处需澄清,见 P1-A)
逻辑通顺。历史加成 → 起跑线长 → 实力续命。Tongariro 永生、商业 mark 自然消亡的对称性成立。

### 修补 3:信号消化(利空利好)⚠️(P1-B)
方向正确,但存在**边界模糊**——"旧 report 降权"具体到哪一刻终止?如果旧 report 永久降权,等同于"洗白";如果只在一段时间内降权,那段时间多长?**这是思想层必须回答的逻辑关系问题(不是数字)**。

### 修补 4:续命+强心剂同时生效 ✅
两个作用维度不同(续命=寿命延长,强心剂=状态回退),叠加生效逻辑清楚。无漏洞。

## 四、剩余漏洞(只列真逻辑漏洞)

### P1-A:复活 mark 的"近期窗口"基线未明示
**场景**:Tongariro mark 复活后,历史 4500 like 全部保留。第 1 天来 3 条 report —— 这 3 条相对"近期窗口"占比是 100%(近期只有 3 条),还是相对"全部历史"占比 ≈0.07%?

**风险**:若按全部历史算 → 复活 mark 永远不会进 SUSPICIOUS(历史太厚);若按近期窗口算 → 复活第 1 天 3 条 report 就触发向下急转,与"复活=继续故事"的精神矛盾。

**建议思想层澄清**:复活后近期窗口是从复活时刻**重新开始累积**,还是**沿用 DEAD 前的窗口**。这是逻辑关系,不是数字。

### P1-B:信号消化的"消化期"边界未明示
**场景**:case 12 — 强心剂触发后第 7 天来 5 条新 report。这 5 条算"新信号"(应正常触发新一轮急转),还是仍在"消化期"内被降权?

**风险**:若消化期无明确边界,攻击者可在消化期内继续刷,新负向信号无法触发新一轮 SUSPICIOUS。若消化期太短,容易立刻震荡回来(违背消化的初衷)。

**建议思想层澄清**:消化期的**逻辑边界**(例如"直到旧信号滚出滑动窗口"或"直到出现等量新信号"),而非具体天数。
