## 各页面详细描述

### 1. Login页

- 顶部：动态Cairn logo动画
- 中部：邮箱+密码输入框 + 登录按钮
- 或：Google / Apple 一键登录按钮
- 底部：隐私条款checkbox（必须勾选才能注册）
  - 点击可展开查看完整隐私条款

### 2. 功能选择页 (Home) — 登录后首页

**上方**：2个大Card
- 【🥾 徒步】→ 进入徒步模式（地图+AR插旗）
- 【🏃 跑步】→ 进入跑步模式（路线选择→Lock→播报）

**下方**：3个功能入口
- 【🗺️ 地图】→ 查看历史记录地图
- 【👥 好友】→ 好友管理
- 【⚙️ 设置】→ 偏好设置

### 3. 地图页（历史查看）

- 展示用户**曾经走过的路线、插过的旗帜**
- 可以点选旗帜查看详情
- 可以删除旗帜
- 可以设置"想走的路线"（规划未来路线）
- 规划好的路线可在跑步模式中选择用于导航播报
- 地图可缩放

### 4. 好友页

- 简易列表展示当前好友
- 邮件添加好友（输入邮箱 → 对方实时收到邀请 → 系统内同意）
- 删除好友
- 对单个好友选择"不分享"（关闭分享权限）
- 不做任何复杂社交功能

### 5. 设置页

- 简易/专业模式切换
- 添加好友后是否默认分享旗帜（开关）
- 夜间模式（开关）
- 其他偏好
- **需手动点"保存"** 才生效

### 6. 徒步模式页

**地图区域**：
- 当前用户位置（实时GPS）
- 附近的旗帜标记点
- 可放大/缩小
- 标记自己位置

**插旗操作**：
- 点击"添加旗帜"按钮 → 进入AR页面
- AR页面四角分别是4种旗帜类型（危险/风景/补给/路口）
- **拖拽交互**：用户从四角拖拽旗帜到AR画面中 = 插旗
- 拖拽回四角 = 取消
- 插旗成功后弹窗：输入文字 或 录语音（可跳过）

### 7. 跑步模式页

**启动前**：
- 选择预设路线（从地图页规划好的路线中选）
- 或不选路线直接开始

**启动后**：
- 界面Lock（防误触）
- 后台运行：GPS追踪 + 偏离检测 + 语音播报
- 用户停下时：右下角出现"插旗"按钮
- **双击屏幕** = 解除Lock

## 和当前方案的差异点（需更新）

| 差异点 | 原方案 | 用户设计 | 操作 |
|--------|--------|----------|------|
| 首页 | 直接全屏地图+底部tab | **功能选择页**（2大Card + 3入口） | 改为用户方案 |
| 地图角色 | 是主屏/首页 | 是**历史查看**入口，不是首页 | 改为用户方案 |
| AR插旗交互 | FAB按钮→选类型→AR | **四角拖拽**：4种类型在四角，拖到AR画面=插旗 | 改为用户方案（更直觉） |
| 跑步Lock | 提到"screen can be off" | **显式Lock状态 + 双击解锁** | 增加Lock UI |
| 跑步插旗 | 跑完后回顾标记 | **停下时右下角可插旗** | 改为用户方案（更灵活） |
| 设置保存 | 未明确 | **手动点保存**才生效 | 遵循用户方案 |
| 好友分享控制 | 三级权限（Personal/Group/Public） | **对单个好友可选"不分享"** | 补充到好友页（和三级权限互补） |
| 底部导航 | 4个tab固定 | **无固定底部tab**，从Home页选入口 | 改为用户方案 |

## 整合后的最终交互流程

```
Login → Home（2 Card + 3 Entry）
              │
    ┌─────────┼─────────────────────────┐
    │         │         │         │     │
  徒步      跑步      地图      好友   设置
    │         │         │         │     │
 地图+AR   选路线→    历史     列表   偏好
 四角拖拽   Lock模式   旗帜/    添加   保存
 插旗       播报纠偏   路线规划  删除
            双击解锁           分享控制
```
