# Grouped personal-journey device review

Use an isolated/disposable account after the required local backend patches are available. Do not use production destructive data.

1. Finish one disposable Activity, open its linked own Cairn, edit it, return through Memory -> All Cairns, then reopen the same Activity.
2. From that Activity choose Save as Route, cancel once, then save; confirm canonical Route Detail opens and Trails reopens the same Route/name/geometry.
3. Edit the Route, use one correction, confirm `Apply to draft` does not commit, then `Save Route`; test Back with an unsaved edit and confirm discard leaves the saved Route unchanged.
4. From Route Detail choose Hike and Run in turn; confirm each matching pre-start screen shows the selected Route/reference copy and recording does not begin until Start.
5. On the small iPhone, inspect Route Detail/editor in Day, Sunset, and Night, including keyboard, native Mapbox gestures/ornaments, failure copy, and safe-area/control collisions.

This card does not ask for friend-location access, production deletion, purchase, feedback/export, active-navigation, or full-app retesting.
