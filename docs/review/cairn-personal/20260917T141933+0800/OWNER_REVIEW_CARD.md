# CARD-CAIRN-01 owner device review

Use a disposable account and disposable Cairns. Do not use friend-location access or production data that must be retained.

1. Create one empty Quick Cairn and one named Plant, then open `Memory -> All Cairns`; confirm both rows open the same authoritative Own Cairn Detail and the empty Cairn uses a date-based fallback.
2. From a finished disposable Activity, open its explicitly linked own Cairn, edit the name/note, return to the same Activity, then retrieve the edited Cairn from `Memory -> All Cairns`.
3. Review All Cairns and Own Cairn Detail in Day, Sunset, and Night on a small iPhone; check Back/edit controls, long text, keyboard avoidance, map ornaments, and map-unavailable behavior.
4. While offline, edit a pending local Cairn, relaunch, and confirm the edit persists; after reconnecting, confirm one row/identity remains. After the owner-history backend is deployed, also verify an older off-map Cairn is found by search.
5. Delete a disposable Cairn through the confirmation, confirm the valid return destination and no resurrection after reconnect/relaunch, and confirm its source Activity and unrelated Memory/Routes remain.
