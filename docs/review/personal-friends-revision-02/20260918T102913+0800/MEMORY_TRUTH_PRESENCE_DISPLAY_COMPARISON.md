# Memory truth, presence, display, and projection comparison

| Domain | Durable authority | Can unlock personal coverage? | Can qualify Encounter? | Removal semantics |
|---|---|---:|---:|---|
| Personal exploration coverage | accepted personal `activity_real`/`passive_real` evidence | Yes | Legacy-compatible input only under server policy; new presence witnesses preferred | Ordinary Activity/Cairn/Route deletion does not erase accumulated Memory |
| Time-qualified presence witness | bounded accepted real-source first/latest observations with accuracy, continuity, and Activity identity | No additional area by itself | Only after server friendship/object/time/source/finalization checks | Bounded independently; never rewrites original event time |
| Display geometry | recomputable union/smoothing clipped to evidence | No; it visualizes existing support | Never | Cache clears on account/authority change; same-authority failure may retain prior valid shape |
| Friend projection | coarse, versioned, server-authorized cells by source friend | Never as personal truth | Never | Deselect hides; unsubscribe/revoke/block/account purge according to distinct product action |
| Planned/borrowed/Final/simulator/unknown | route or test/reference data | Never | Never | Governed by its own lifecycle, not Memory deletion |

One timestamp is one observation, not a verified whole visit. Repeated traversal does not add coverage area or opacity. New accepted evidence after a later day, Activity, or content boundary can update bounded presence without fabricating counts.
