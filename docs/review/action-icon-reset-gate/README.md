# CairnNZ action-icon reset gate

This is a from-zero, review-only exploration. None of these candidates is imported by application runtime code.

- Family A — Field Pictograms: human actions, rounded monoline, explicit outdoor/placement cues. Strongest overall balance and clearest semantics.
- Family B — Essential Objects: trail boot, running shoe, and hand-supported cairn. Very clear activity distinction; the hand/cairn relationship is slightly more interpretive.
- Family C — Trail Marks: route, terrain, track, and waypoint notation. Compact and outdoor-specific, but more dependent on labels than the figure families.
- Family D — Compact Action Marks: reduced solid action silhouettes for maximum small-size clarity. Strongest raw legibility, with a heavier and less quiet character.
- Family E — Quiet Gestures: fine open-line actions with the most restrained premium character. Most elegant, though slightly lighter at phone size.

The 15 SVG candidates are under `icons/`. The PNG and SVG review sheets are in this directory.
