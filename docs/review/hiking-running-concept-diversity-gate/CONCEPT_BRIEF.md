# CairnNZ Hiking + Running concept diversity brief

This review-only gate asks which semantic metaphor CairnNZ should use. It does not select or integrate a production icon.

## Five metaphors, locked before drawing

- **Family A — Field Signals:** Physical movement infrastructure distinguishes a rugged trail blaze from an athletics track marking.
- **Family B — Ground Rhythm:** Abstract contact marks record Hiking as weighted, irregular progress and Running as light, accelerating cadence.
- **Family C — Movement Profile:** A compact motion profile expresses Hiking through stepped elevation gain and Running through a continuous rebound rhythm.
- **Family D — Specialist Tools:** One defining tool stands for each mode: planted trekking poles for Hiking and a split timer for Running.
- **Family E — Worn Form:** Purpose-built footwear communicates a grounded lugged hiking boot versus a low, light running shoe.

Family E is the only footwear-led direction.

## Pairwise diversity audit before drawing

| Pair | Different semantic source? | Why they are not variants of one metaphor |
| --- | --- | --- |
| A / B | Yes | A depicts built field infrastructure; B depicts traces left by movement. |
| A / C | Yes | A uses recognizable outdoor/sport markings; C uses an abstract time/elevation profile. |
| A / D | Yes | A is environmental signage/surface language; D is activity-specific carried equipment. |
| A / E | Yes | A describes the place of movement; E describes the worn object doing the work. |
| B / C | Yes | B is a residual ground-contact trace; C is a diagram of movement behavior. |
| B / D | Yes | B has no object and shows only contact rhythm; D uses literal specialist tools. |
| B / E | Yes | B avoids anatomy and object depiction; E is a directly recognizable footwear silhouette. |
| C / D | Yes | C is symbolic motion notation; D is literal equipment pictography. |
| C / E | Yes | C communicates how motion changes over time/terrain; E communicates what is worn. |
| D / E | Yes | D uses carried/operated tools; E uses purpose-built footwear and is the sole shoe family. |

## Pre-drawing gate

- Five families: **YES**
- Five genuinely different semantic hypotheses: **YES**
- No more than one footwear-led family: **YES**
- No human figure or anatomy: **YES**
- Each pair has a shared internal grammar: **YES**
- Pairwise conceptual duplication found: **NO**
