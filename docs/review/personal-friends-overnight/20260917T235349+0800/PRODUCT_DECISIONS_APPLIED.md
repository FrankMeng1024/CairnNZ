# Product decisions applied

The frozen product contract superseded the older preflight stop/no-deployment language. No prior owner acceptance is inferred.

- Simple author controls: `Only me` / `Friends` for Cairns and Routes; an author toggle for future Memory sharing; internal per-friend authorization epochs.
- Memory sharing, Cairn discovery, and Route discovery are separate resource predicates.
- No permission request, approval inbox, public discovery, stranger exploration, payment, voice, or Cairn photo workflow was added.
- Cairn v1 is text-only. Empty Quick Cairns are valid.
- `A moment here` is a shared, nonpersisted display fallback. Authored nonblank names are shown verbatim.
- Shared Memory is prospective from completed accepted real Activities only, coarse, endpoint/private-place suppressed, and never raw.
- Friend Encounters are prospective and can include a stationary fresh accepted fix; passive discovery mechanisms cannot manufacture an Encounter.
- Viewer content is read-only. Borrowed Route geometry has only the active-outing/recovery safety exception.
- Technical offline, weak-network, poor-location, map-unavailable, Pacific/Auckland timezone and NZ text/spatial fixtures are in scope; none is represented as NZ field validation.
- O59 was the starting marker. After combined software/database gates passed, it was incremented exactly once to O60. App/runtime/build versions were not changed.
- Backend deployment was authorized under file 06 and performed through the canonical yiiling runbook. OTA publication was not authorized and did not occur.
