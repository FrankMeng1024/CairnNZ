A. 产品灵魂 — Cairn 到底是什么

A1Cairn 的核心不是安全工具、不是 AR,而是"数字手账 + 陌生人善意" 两个词概括。
数字手账 = 记录自己走过的路、想留的话,给未来的自己看
A2自己看:GPS 记录轨迹 + fog-of-war 迷雾地图 + marker 留短文本,N 年后自己回来还能看得到。
A3给别人看:好友订阅式互看 marker,陌生人也可看/被看到 marker,但不做社交、不做广场、不做算法推荐。
跟 AllTrails 那种公开路线库、社交推荐完全反着做
A4灵魂来源:Death Stranding 的异步社交哲学 — "独处时感受到人类温度"。
A5统计是"回忆录"不是"成绩单"。没排行榜、没勋章、没成就系统。

B2.2Running 模式:锁屏跑步 + 屏幕黑掉省电

B2.4Session 保存 + 后台增量同步(v412 atomic save 已上线)

B3. 地图

B3.1Mapbox 实时地图 + 卫星/地形样式切换
B3.2离线地图基础设施在(NZ 区域),但离线下载 UI 还没做(在 backlog)
B3.3回看历史轨迹(MapHistoryScreen):按 session 展示当时的路线 + 当时的 marker
B3.4路线编辑器:长按地图加中间点 + 拖动调整 + snap-to-road

B4. Marker(核心)

B4.1Marker 类型有 6 种:view / peak / rest / shelter / danger / summit
代码里读到的 enum,你可能想改类型分类
B4.23 级权限:Personal(只自己) / Group=friend(好友) / Public(陌生人)
B4.3PlantScreen 3 步:①5 秒 GPS 采样 → ②地图定位微调 → ③输入内容
B4.4owner 可编辑/删除自己的 marker
⚠️ B4.5 冲突点:代码 backend 里 marker text 是 250 字符上限,但 DISCOVERY.md 写的是 30 字。到底哪个是你想要的?
B4.5Marker 文字上限 = 250 字符(代码实际)/ 30 字(文档说)
B4.6Marker 可附照片 + 语音 memo
语音 memo 之前和 AR 一起放到 Phase 2,AR 舍弃后语音 memo 保留吗?
B4.7陌生人能看到 public marker,作者名字自动匿名(author_name = null)

B5. Memory / Fog-of-War 迷雾地图

B5.1MemoryScreen:H3 六边形迷雾地图,走过的区域被"点亮"

B5.3好友订阅:最多订阅 5 个好友的 fog UNION 合并显示
5 个上限是产品刻意设计还是可以放宽?

B6. 好友

B6.1邮箱添加 + 双向确认
B6.2好友能看到你的 group/public marker + 你的 route(如果 route 允许)
B6.3Hide-from-me:主动屏蔽好友/陌生人的某个 marker,以后再也看不到

B7. 陌生人互动(最重要,请仔细看)

⚠️ 关键冲突:代码里陌生人可以 50 米内点赞/举报 marker,已在生产。但 DISCOVERY.md Won't Build 明确写"点赞/评论/陌生人互动"。你到底要不要这个?
B7.1陌生人在地图上看得到 public marker,但按 bbox 限制,一次最多 50 条
B7.2陌生人在 50 米内能给 marker 点赞或举报(每人 1 票)
这就是 Death Stranding 的 "Like" 机制的现实版
B7.3反作弊限流:30 like/分钟、5 举报/分钟、20 举报/小时
B7.4反作弊 GPS 门槛:精度 <100m、距离 <50m、防瞬移(5km/60s)
B7.55 个举报后 marker 自动 hidden(auto-hide 已在生产)
5 这个阈值是不是刻意的?会不会被恶意刷下去?
B7.6没有关键词黑名单、没有 AI 审核、没有人工审核队列、没有封号系统
这是 URGENT 待补的合规底线
