## ① 部署后端（任选你已有的服务器，10分钟）

### 1.1 把代码push到server

```bash
# 在你的服务器
cd ~
git clone <你的仓库> Cairn
cd Cairn/docker
cp .env.example .env
nano .env
```

`.env` 必须改的字段：
- `DB_ROOT_PASSWORD` — 强随机
- `DB_PASSWORD` — 强随机
- `JWT_SECRET` — ≥32字符
- `CAIRN_TELEMETRY_API_KEY` — **记下来，等下要在app里填**

可选：`CORS_ORIGINS` 加你的iPhone IP（现在留空即可）

### 1.2 一键部署

```bash
cd ~/Cairn/docker
chmod +x deploy.sh
./deploy.sh
```

成功标志：

```
✓ Backend healthy.
✓ Cairn backend is running:
    Health: http://localhost:3001/health
```

### 1.3 验证telemetry endpoint

```bash
curl -X POST http://localhost:3001/api/telemetry/sessions \
  -H "X-API-Key: $(grep CAIRN_TELEMETRY_API_KEY .env | cut -d= -f2)" \
  -H "Content-Type: application/json" \
  -d '{"session_id":"smoke-test","events":[]}'
```

应返回 `{"ok":true,...}` 200。

### 1.4 把端口暴露到公网

如果你的server是阿里云/AWS/腾讯云，需要：
- 安全组放行 3001（或你映射的端口）
- 如果有反向代理（nginx/caddy），加一行 `proxy_pass http://localhost:3001;`
- 如果有HTTPS就更好，没有的话直接 `http://YOUR_IP:3001` 也行

**记下你的 backend URL**：明天app里要填这个。

## ③ EAS Build（30分钟，云端build等待）

### 3.1 装EAS CLI

```bash
npm install -g eas-cli
```

### 3.2 登录Apple账号

```bash
cd ~/path/to/Cairn/app
eas login                    # 用你的Expo账号（可以现注册一个）
eas device:create            # 注册iPhone — 跟提示走，扫QR码安装provisioning profile
```

### 3.3 启动云端build

```bash
# 如果你想测真实Mapbox（VPN下）：先填backend URL
nano eas.json
# 改 development -> env -> EXPO_PUBLIC_BACKEND_URL 为你的server

# 启动build
eas build --profile development --platform ios
```

云端会build 15-30分钟。会问几个问题：
- **Apple ID / password** — 你的开发者账号
- **bundle identifier**: `com.cairn.app`（已在app.json）
- **distribution certificate / provisioning profile**: 选 generate new
- **push notifications**: 选 No (我们没用)

build完成后，会给你一个URL，扫QR码或手动下载。

## ⑤ 配置Debug Mode

1. 打开app → Settings (右上角齿轮)
2. 滚到底部，看到 "Cairn v0.1.0" 文字
3. **连续点击5次** → 弹窗 "Debug Mode ON"
4. 现在Settings顶部会出现一个 "DEBUG" section
5. 点 "Open Debug screen"
6. 填两个字段：
   - **Backend URL**: `http://YOUR_SERVER_IP:3001` (或你的域名)
   - **API Key**: 你在server `.env` 里设的 `CAIRN_TELEMETRY_API_KEY`
7. 检查toggles：
   - ✓ Auto-upload sessions
   - ✓ WiFi only (推荐——回家连WiFi自动上传，省蜂窝流量)
   - ✓ Show annotation FAB

8. 返回Home

## ⑥ 户外测试 — 你只需要走

### 出门前

1. iPhone电量 ≥ 50%
2. **打开VPN**（如果你想看NZ Mapbox tile，否则地图会空白；GPS不影响）
3. 同步好emergency contact（Settings → Emergency → Contacts）
4. 选route（或Free mode）
5. 点 "Start Hiking"
6. **Always Allow Location** 弹窗如果还在 → 接受

### 徒步中

- **App可以放口袋锁屏**，会持续记录GPS
- 走过程中突然听到"Off route"播报但你心里清楚没偏 → **点右下紫色FAB → 选"False deviation"**
- 觉得GPS漂移很大 → 点FAB → "GPS off"
- 试试走超过50米的偏离路径 → 会收到偏离播报
- 试试waypoint到达 → 会播报waypoint label
- **不要测SOS！** 除非你真的在测试紧急联系人功能（朋友配合）

### 回家

1. 连上WiFi
2. App里：Settings → Debug → Open Debug screen
3. 看session列表，每个应该都标 "✓ Uploaded"
4. 如果没自动上传，点 "Upload now"
5. 通知Claude："看数据"

## ⚠️ 已知问题 / 限制

1. **Mapbox tile在中国大陆**：必须挂VPN才能加载NZ瓦片
   - 没VPN也能跑，但地图会显示空白；GPS定位仍正常工作
   - 离线包：没VPN没法下载（明天先在境外环境/VPN下载一次）
2. **iOS后台tracking**: 第一次会弹"始终允许"权限请求；选"Always"
3. **First launch GPS等很久**: 首次冷启动可能要15-30秒拿到fix；之后就快了

## 💡 任何卡点

- **EAS Build失败**: 多半是cert问题。`eas credentials` → 重新生成
- **Backend deploy失败**: `cd docker && docker compose logs backend` 看错误
- **iPhone装不上**: provisioning profile过期。`eas device:create` 重新注册
- **GPS永不定位**: 检查iOS 设置→隐私→定位服务→Cairn→Always
