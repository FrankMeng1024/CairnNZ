# CairnNZ Visual Roadmap

**Authority:** execution sequence derived from `CAIRNNZ_VISUAL_DNA.md`
**Rule:** a later Gate extends approved DNA; it does not reinterpret CairnNZ from zero.

## Gate rules

- Do not begin a Gate until the prior Gate has explicit human approval.
- Preserve behavior unless a Gate explicitly authorizes product change.
- Use the active production screen hierarchy and real product content for final proofs.
- Evaluate meaningful visual work at the complete 390×844 reference frame.
- Preserve masters and previous champions; the best-known visual state wins.
- Record only approved system-level decisions in `CAIRNNZ_VISUAL_DNA_CHANGELOG.md`.
- A screen or asset can be technically complete and still fail perceptually.

- Real Home at 390×844 preserves the approved static composition.

# Gate A2 — Home Day Weather Family

**Status:** not started
**Depends on:** approved Gate A1

Create and approve:

- Cloudy Day
- Rainy Day
- Snowy Day

Derivation source:

> Visual DNA + approved canonical Home geography.

Rules:

- Preserve camera, terrain, trail, water, major tree groups, world opening, environmental scale, crop, and UI quiet zones where practical.
- Transform light, sky, cloud, moisture, wetness, snow, foliage response, atmosphere, and surface behavior.
- Do not generate unrelated scenes or solve weather through global grading alone.
- Cloudy, Rainy, and Snowy must remain truthful and desirable.

Exit criteria:

- All four Day states clearly depict one physical world.
- Weather is immediately recognizable at phone scale.
- Biological life, depth, UI readability, and exploration desire survive every condition.
- Cloudy is not gray/dead, Rainy is not misery/storm imagery, and Snowy is not lifeless flat white.

# Gate A3 — Home Night Family

**Status:** not started
**Depends on:** approved Gate A2

Create and approve:

- Sunny Night
- Cloudy Night
- Rainy Night
- Snowy Night

Derivation source:

> Visual DNA + the same canonical geography + Night system rules.

Rules:

- Preserve world identity, route logic, terrain readability, water, tree silhouettes, atmospheric layers, and component geometry.
- Use natural illumination and condition-specific material response.
- Base UI materials on charcoal, slate, cool mineral neutral, and restrained blue-green; green remains an accent.
- Never use near-black disappearance, deep-green recoloring, fantasy night, neon, or black/gold luxury.

Exit criteria:

- Each Night state is recognizably the corresponding Day world after sunset.
- Weather remains legible without losing depth or navigation.
- Night surfaces integrate with scenery and do not become opaque slabs.
- Exact Night tokens are supported by rendered evidence across scenic and representative transient UI.

**Status:** not started

# Gate B1 — Memory

**Status:** not started
**Depends on:** approved Gate A4

Primary role:

> Home makes going outside desirable. Memory proves going outside mattered.

Scope:

- Derive Memory from the Visual DNA, not from Home’s literal scenery.
- Use real current Memory functionality and product data concepts.
- Express explored/unexplored terrain, accumulated routes, personal history, cairns, repeated journeys, and quieter other-person traces.
- Preserve geographic precision and map usability.

Reject:

- Generic Mapbox appearance
- Home background copied onto the map
- Fantasy fog-of-war
- Neon reveal
- Game HUD or quest language
- Vintage/sepia cartography

Exit criteria:

- Memory feels visually flagship-level and unmistakably CairnNZ.
- Exploration feels consequential without inventing functionality.
- Day/Night, map controls, sheets, loading, empty, and error states support the same meaning.

# Decision discipline

A Gate may refine derived rules and instance variables. It may not silently rewrite Locked Core DNA. If a genuinely system-level discovery requires a core change:

1. Stop the active Gate.
2. State the evidence and affected principles.
3. Obtain explicit human approval.
4. Update `CAIRNNZ_VISUAL_DNA.md` and `CAIRNNZ_VISUAL_DNA_CHANGELOG.md` together.
5. Reassess dependent Gates for drift.

Do not update the DNA merely because a generated candidate differs from it.
