## Vision

Cairn是一款面向新西兰和全球户外爱好者的安全工具App。用户在徒步/跑步时可以在地图上标记关键点位（危险、风景、补给、路口），与信任的好友协作共享路况，获得实时天气/路况播报，并在紧急情况下一键求助。

产品灵魂源自Death Stranding的异步社交哲学：不是社交app，而是"独处时感受到人类温度"的安全工具。统计是"回忆录"不是"成绩单"，没有排行榜，没有竞争。

## Epics

### E-001: 真实地图 + 离线地图 + 全球扩展
**Phase 1**

用户可以在精确到街道级别的真实地图上进行所有操作。新西兰地区支持离线地图下载，确保无网络环境下地图完全可用。架构支持全球扩展。

**关键需求**：
- Mapbox地图供应商，NZ精准到zoom 10-17
- 离线tile分区域下载（用户选择区域包，如"Tongariro包"、"南岛步道包"）
- NZ全境zoom 10-15约200-500MB，UI展示下载大小和进度
- 全球扩展通过`regions.ts`数据驱动（AU/US-PNW/JP已预留）
- 地图更新策略：Mapbox tile季度更新 + 社区旗帜补充滞后性
- 开发测试：Expo模拟定位注入NZ坐标（不做中国地图）

---

### E-002: GPS定位与精度优化
**Phase 1**

确保用户在各种户外场景下（步行、跑步、登山、山谷、树林）获得尽可能精准的GPS定位，误差控制在合理范围内，电池消耗最小化。

**关键需求**：
- expo-location实时追踪（优化现有基础版）
- Kalman Filter平滑轨迹（减少跳动和异常点）
- 速度+方向一致性检测（去掉GPS漂移产生的假运动）
- 动态采样频率：静止0.1Hz → 走路1Hz → 跑步2Hz
- GPS完全离线可用（不依赖网络，A-GPS仅加速cold start）
- 多卫星系统：GPS + GLONASS + Galileo
- AR旗帜存储：GPS坐标 + 海拔 + 方向，AR渲染时相对方位计算（±2-5米偏差可接受）
- 走近旗帜时运动轨迹"吸附修正"提高精度

### E-003: AR插旗
**Phase 3**

用户通过AR界面在真实世界中放置虚拟旗帜，下次经过同一位置时旗帜依然可见。AR是差异化核心功能，但依赖地图和GPS先行稳定。

**关键需求**：
- AR模式为独立视图（开启时地图渲染暂停，互斥省电）
- 拖拽精确放置旗帜 + 拖出取消
- 权限范围选择（个人/好友/社区）
- 旗帜间距控制（同一用户在X米内不能重复插旗）
- 光线不足/设备不支持时优雅降级到地图模式
- AR遮挡处理：地面平面检测
- 旗帜视觉外观：类型决定3D模型（danger=红色警告锥、scenic=蓝色水晶柱、supply=绿色补给箱、junction=黄色路标），权限用发光/透明度区分（个人实心、好友半透明、社区光圈）
- 首次使用闪烁教学（拖拽操作）
- 文字筛选：好友级别起用关键词黑名单（`bad-words`/`leo-profanity`），社区上线时升级AI审核

### E-004: 好友数据分享
**Phase 2.5**

好友系统完善，支持旗帜数据共享、权限管理、和好友旗帜的视觉区分。

**关键需求**：
- 双向确认添加好友
- 确认方式：in-app request + email backup
- 分享设置可配置（添加即分享 vs 添加默认不分享）
- 好友旗帜 vs 个人旗帜在AR/MAP中明显视觉区分
- 屏蔽他人旗帜 / 删除好友 / 分享旗帜给特定好友
- 旗帜时效性：不过期 + 显示"上次更新: X天前" + 设置里可配"只显示N天内更新的旗帜"
- 数据同步：有网时增量同步，session开始前拉取好友最新数据

### E-005: 社区插旗大数据整合
**Phase 3（用户量>1000后开放）**

社区级别的旗帜数据聚合、智能播报、和恶意内容防护。Phase 2开始收集数据但不展示。

**关键需求**：
- Phase 2收集社区旗帜数据（用户插旗时选"社区"权限即存储）
- 不做播报/展示，等算法成熟+法务确认后开放
- UI明确告知用户"社区旗帜"含义及暂不开放原因
- 同位置>5人聚合逻辑
- 投票机制（有帮助/没帮助），负面投票过多自动下架
- 危险警告disclaimer（NZ Consumer Guarantees Act法律免责）
- 默认不展示社区旗，需用户主动开启，有最高上限
- 举报机制 + 密度异常检测

### E-006: 旗帜查看和修改
**Phase 2**

用户可以在AR和MAP两个界面中查看、修改、删除旗帜，并调整旗帜的权限范围。

**关键需求**：
- AR界面修改旗帜（内容、权限）
- MAP界面修改/删除旗帜
- 权限范围可变更：个人→好友→社区（嵌套逻辑：社区⊃好友⊃个人）
- 社区旗帜修改保留audit trail
- 删除旗帜：如好友已关联该旗帜到路线，删除后通知

---

### E-007: 路线预定义
**Phase 2**

用户可以预先规划路线、关联旗帜和waypoint、跟踪历史跑步数据、与好友分享路线。

**关键需求**：
- MAP上自主绘制/添加路线
- 路线关联沿途旗帜，可选择哪些不播报
- Waypoint（临时点，非旗帜，到达时播报提醒，如"该补水了"）
- 预定义路线高亮显示在地图
- 历史路线查看 + 跑步次数统计
- 路线分享给好友 + "来自XXX"标签
- 好友推荐路线列表，可使用/隐藏/忽略
- 路线与偏离检测强关联（偏离→语音播报纠偏）
- GPX导入/导出

---

### E-008: 数据播报
**Phase 2**

高质量语音播报系统，涵盖旗帜信息、路线偏离、waypoint提醒、天气变化。不打断用户后台音乐。

**关键需求**：
- 英语为核心TTS
- Audio ducking（不打断后台音乐/电话，仅压低背景音量）
  - iOS: AVAudioSession `.duckOthers`
  - Android: AudioFocus `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`
- 播报频率控制：优先级队列 + 合并策略
  - 30秒内多个旗帜 → 合并播报
  - 优先级：danger > supply > junction > scenic
- 播报语言跟随设备语言设置
- 最小播报间隔：15秒（可在设置中调整10s-30s）
- P0（危险/偏离）可打断间隔立即播报
- 连续3个P0在60秒内 → 合并为"持续危险区域，请注意安全"

### E-009: NZ实时数据整合
**Phase 2.5**

接入新西兰实时天气、步道状态、路况数据，为用户提供环境信息播报。

**关键需求**：
- 数据源（全部免费）：
  - DOC步道状态（优先 — 路封、桥断、hazard警告）
  - Open-Meteo天气（城市级精度，山区显示"最近气象站数据，仅供参考"）
  - NZTA路况（公路覆盖，适用于自驾到步道口）
- 数据源冲突处理优先级：DOC > MetService(未来付费) > Open-Meteo > NZTA
- 用户可在设置中取消各类实时数据播报
- 天气恶化等变化主动推送播报

### E-011: 安全与紧急功能
**Phase 2**

户外安全核心功能：SOS一键求助、行程分享、离线位置上报。

**关键需求**：
- SOS一键求助：
  - 防误触：长按3秒 + 5秒确认倒计时
  - 触发后发送GPS坐标给预设紧急联系人
  - 无网络方案：SMS fallback（只需基站信号）+ 离线队列（回网后发送）
  - 引导用户了解设备自带卫星SOS（iPhone 14+）
- 行程分享："我要走XX路线，预计N小时。超时通知紧急联系人"
- 离线期间最后已知位置，回网后自动上报

## Non-Functional Requirements

### 性能
- 冷启动到可用 < 3秒
- GPS追踪精度户外开阔地 < 10米
- 语音播报延迟 < 2秒（从检测到事件到播报）
- 地图tile加载（缓存）< 500ms
- GPS fix < 5秒
- 离线模式切换 < 1秒

### 电池（极限省电）
- 徒步模式 < 8%/小时
- 跑步模式 < 5%/小时
- 模式互斥原则：AR和地图绝不同时运行
- 动态GPS频率：静止0.1Hz → 走路1Hz → 跑步2Hz
- 电量<20%自动降频+减少播报

### 离线
- 离线下全功能可用（除好友同步和社区数据）
- 数据同步：有网时增量同步，冲突解决"最近修改优先"
- 同步优先级：SOS > 新旗帜 > 路线修改 > 统计
- 离线时不发起任何网络请求（零网络功耗）

### 隐私（GDPR级别）
- 账户删除：30天冷静期后不可恢复
- 数据导出：GPX路线 + JSON旗帜/设置
- GPS轨迹默认仅本地存储，同步需明确授权
- 数据最小化：只收集功能必需数据
- 第三方共享透明列出 + 用户可关闭
- 社区旗帜匿名化

### 可访问性
- VoiceOver/TalkBack基础支持
- 所有按钮accessibility label
- 对比度达标
- 按钮点击区域≥44pt（手套友好）
- i18n架构就绪（仅英文内容，未来零重构加语言）

### 通知节奏
- 最小播报间隔：15秒（可设置10s-30s）
- P0（危险/偏离）可打断间隔
- P1（waypoint/天气）等间隔
- P2（好友/scenic）仅面板内软通知
- 连续P0合并为区域警告

### 视觉品质（美术标准）
- 所有浮层元素使用磨砂玻璃效果（backdrop-blur），非实心背景
- 多层阴影系统（4级elevation），交互响应有物理逻辑
- 一切动画使用spring physics，禁止linear动画
- 关键品牌位置使用自定义SVG（旗帜图标、空状态插图、活动图标）
- 地图标记升级为发光环+底座+阴影的多层视觉
- 暗色模式下玻璃效果同样保持（暗色半透明+blur）
- 视觉基准已确认（Natural Warm + Liquid Glass融合），无需再出style demo供用户确认
- 每个Sprint的UX Review包含Visual Quality检查，对比竞品（AllTrails/Komoot）不能明显低于
