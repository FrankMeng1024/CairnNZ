# PRD — Cairn

**Product Name**: Cairn
**Tagline**: Leave a mark. Guide the next.
**Version**: 1.0
**Created**: 2026-05-15
**PO**: User

---

## Vision

Cairn是一款面向新西兰和全球户外爱好者的安全工具App。用户在徒步/跑步时可以在地图上标记关键点位（危险、风景、补给、路口），与信任的好友协作共享路况，并获得官方风险预警和路线偏离纠正。

产品灵魂源自Death Stranding的异步社交哲学：不是社交app，而是"独处时感受到人类温度"的安全工具。

---

## Epics

### E-001: 账号与好友
用户注册、登录、好友添加/删除的完整流程。隐私优先设计。

### E-002: 地图与导航
离线地图展示、GPS路线追踪、轨迹记录、路线规划。

### E-003: 标记系统
地图pin标记（Phase 1），三级权限（Personal/Group/Public），标记附带短文本。

### E-004: 安全功能
官方风险数据图层（DOC）、路线偏离检测、语音播报纠偏。

### E-005: 运动模式
跑步模式（语音为主、锁屏）vs 徒步模式（地图为主、交互）。

### E-006: UI/UX
新手/老手双模式、旗帜类型视觉系统、播报密度控制。

### E-007: AR体验（Phase 2）
ARKit插旗视觉、AR发现体验、语音memo、感谢机制。

## Non-Functional Requirements

- 离线下全功能可用（除好友同步和社区数据）
- 语音播报延迟 < 2秒（从检测到偏离到播报）
- GPS追踪精度在户外 < 10米
- 电池消耗：徒步模式 < 8%/小时，跑步模式 < 5%/小时
- 冷启动到可用 < 3秒
- 数据同步：有网时增量同步，冲突解决策略为"最近修改优先"
