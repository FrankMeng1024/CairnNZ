Variant C v2 · 时间锚 (飘逸版)

基于 C 改2D icon光带循环呼吸

v1 → v2 改动 (按用户反馈):

  • type icon 完全 2D 化: 不再画三块石头堆叠的"cairn body" — type 视觉只在**地面阵图中心 SDF**, 看上去像烙印, 没有 3D 立体物 (PRD 真实形态: cairn 在 AR 里其实是阵图 + 光带)
  • 光带 = 最外层: 不再像绳索绑在阵图上方 — 现在从阵图**外缘**升起, 飘到 ~1m 高度后**自然断开 + fade 飘走**, 阵图边缘**持续生出新的一根**, 像烟囱冒烟 / 灯笼河里飘走
  • 循环节奏: 每根光带寿命 ~3s (升起 0.5s → 飘移 2s → 顶端 fade + 底端断开 0.5s), 阵图随时有 4-6 根处于不同生命阶段
  • 3D 文字标签: 保留 DS 卡片 + 时间戳 (Henare, 5 days ago), 视觉 anchor 不变

哲学: 时间的延续 + 信息的呼吸. 阵图永远在那里 (绝对世界坐标), 光带是它**对世界的低语**. 异步社交不是某一帧, 是连续的呼吸感.
